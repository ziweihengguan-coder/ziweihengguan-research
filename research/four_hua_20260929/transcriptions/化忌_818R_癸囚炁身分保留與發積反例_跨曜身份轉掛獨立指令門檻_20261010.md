# §818-R｜癸囚炁身分保留、囚星不必為禍與「發積」反例：跨曜年度身分轉掛仍須獨立指令（2026-10-10）

**本輪結論：** 《星學大成》同一四庫 WYG 傳本內，卷三十「癸炁過（化囚也）」、卷十九〈紫炁論〉「癸生人以為囚星」、卷一〈天囚星〉「紫炁木星為囚星……戊癸人見之減力終不為禍」、卷十〈步天經警句〉「癸丑生子上安命有炁化囚者在命發積」構成一組可操作的**同體身分／作用判斷負控**。在卷十具體例中，即使囚炁可論「發積」，文中仍稱其「炁化囚」，並**沒有**將囚身分改授貪狼或其他曜的指令。**這並不證明古法絕無轉掛**；它排除「囚炁並非必凶 → 必須由別曜承接化囚」這種沒有古文前提的推斷。§816／§817／§818皆 OPEN，癸年貪狼反證、1581年前證據門檻、G0/G1/G2、§810-A／§812-A與既有封存保持不變。

## 2. 演算型別與可否傳遞

- **F = 生年取角色**：`F(癸,囚) = 炁`，來源直接支持。
- **E = 臨局判讀**：`E(炁持囚, 癸丑、子上安命、其他盤局條件) = 可發積`，卷10例證；卷1指出囚炁不必定為禍。E改變的是作用**評價**，不是持囚曜的同一性。
- **R = 所求跨曜承接**：`R(F(癸,囚)=炁, 古書預先規定的轉換條件) = 貪狼承接同一癸年度囚身分`，在上述原文仍**無輸入指定、無「再取」指令、無新承接星名**。不得由E良性化逆推R已發生。
- **J = 成熟斗數直接按干化忌**：成熟癸忌貪狼是既有獨立下游驗收值，不是這四段已推出的古典中間結果。J也可能是另一路直定，必須作競爭解釋。

**新增強負控**：若有人提出「原囚炁因本性為吉／因命局轉吉，所以改掛貪狼」，卷十仍明稱炁化囚、卷一還稱炁為囚而可不為禍。若真的存在另一個 R，須另外指出其**何時啟動、何時優先於 E、究竟是否保留原炁囚標籤、能否全年癸干固定**，不能拿這幾句當 R 的證據。

## 4. 下一條真正值得查找的語法

古典文本須在**同一條算法**先指明「某年干 → 舊囚曜A」，接著明說「A既為囚，改由B／令B代A承此囚」的**身分接手方向**，並具固定的年干輸入與新星唯一性。尤其癸囚炁不得靠《紫微數》癸禍貪狼的獨立表欄補空。若只出現「炁囚可吉」「化囚為殺」「帝降七殺為權」「馬有代勞」「捨金從火」則屬不同 operator。
