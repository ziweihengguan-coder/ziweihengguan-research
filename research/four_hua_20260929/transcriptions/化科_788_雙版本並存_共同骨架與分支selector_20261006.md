# 化科 §788：雙版本並存原則與共同骨架／分支 selector 分層

日期：2026-10-06（臺灣時間）

## 一、方法決定

自本節起，成熟化科研究固定保留兩個古本支，不預設其中一支必須被另一支取代，也不以「通行表」自動升格為唯一正統答案。

目前兩個主要成熟支：

- 《捷覽／全集》支：庚太陰化科、壬左輔化科；
- 明刊《全書》支：庚天同化科、壬天府化科。

兩支都視為需要被解釋的歷史資料。

## 二、共同層與分支層嚴格分開

兩支十干化科的五行向量 10/10 相同：

【金、土、金、木、水、土、水、水、土、水】

按【水、火、木、金、土】計數：

【4、0、1、2、3】

因此目前可升為「成熟化科共同骨架」的只有：

1. 早期科／文星母骨架；
2. 成熟兩支共同的變動位置與元素層；
3. 戊、庚、壬三位置的共同重掛需求；
4. 科3／8循五名額候選及其古法同型語法；
5. element → carrier 以前的共同生成結構。

庚、壬實際承載星屬版本分支 selector：

- 庚水：太陰／天同；
- 壬土：左輔／天府。

不得把其中任一組事後硬定為另一組的抄誤。

## 三、後續模型的判定規則

A. 若一個算法能在不讀兩支最終星名的情況下推出共同元素向量、共同變動位置，定級為【COMMON GENERATIVE LAYER】。

B. 若一個 selector 只能解《捷覽／全集》支，定級為【JIELAN/JIJI BRANCH SELECTOR】。

C. 若一個 selector 只能解明刊《全書》支，定級為【QUANSHU BRANCH SELECTOR】。

D. 若一個模型以「全局整齊」「十星不重」「四吉完備」等條件強行裁掉另一個實存古本支，不得升格為成熟化科共同公式。

E. 庚科須與庚忌版本聯動研究；壬科須獨立研究左輔／天府兩種 carrier provenance。不得把庚、壬分歧合併成單一自由度。

## 四、目前兩支的結構意義

《捷覽／全集》支：

- 庚太陰科與庚天同忌聯動；
- 壬左輔有§413昌曲／輔弼2×2配對支持；
- 昌曲左右文章輔弼群完整。

明刊《全書》支：

- 庚天同科與庚天相忌聯動；
- 壬天府有土層、壬干關聯、可承科權祿等同書相容性；
- G1R1可補齊《全書》固定化氣十三主星池。

兩支顯示的是不同編整優先級，不宜簡化為「一真一偽」。

## 五、§788之後的研究目標

化科主線改為：

【EARLY KE / WEN mother layer】
→【COMMON POSITION SELECTOR】
→【COMMON ELEMENT GENERATOR】
→【BRANCH-SPECIFIC CARRIER SELECTOR】
→【VERSION REMOUNT / STEMMA】

第一優先先做共同層的 target-free 消融；確認不預餵戊庚壬與成熟星名時，是否仍能推出共同 element 需求。

第二優先才分支研究：

1. 為何《捷覽／全集》庚水取太陰、壬土取左輔；
2. 為何《全書》庚水取天同、壬土取天府；
3. 兩個分支 selector 是否各自有獨立古法來源，或來自不同編整目標。

除非取得直接版本祖先關係或明確改表自述，否則雙版本並存原則保持不變。
