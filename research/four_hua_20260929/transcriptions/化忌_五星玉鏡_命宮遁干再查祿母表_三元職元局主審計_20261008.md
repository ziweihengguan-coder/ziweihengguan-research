# 化忌續查：《五星玉鏡》命宮遁干再查祿母表

本輪承使用者「好，再試試看」。目標仍是古星命直接導出年干化忌；不以早期福欄、成熟權科作生成輸入，不用清《乾元秘旨》，不取新圖片、不做新OCR。

**結果：找到有具體算例的二次取祿指令及五合後再取祿指令，確實操作十曜祿母表；但原法皆須實際命宮。七法直接輸出都缺日，不能直接產生甲陽忌。十四條明列的代宮假說也沒有完整解。**

這補強「古人確會遁干後再查母表」的操作證據，尚未補上化忌採用這套操作的證據。§521已有「祿干化祿為天馬」登記，故不宣稱本輪首次發現二次查祿這種語法。

## 一、文獻與年代

- [《新刻五星玉鏡》序](https://www.shidianguji.com/zh/book/NA06419/chapter/1m451f5xggu1n)，署「萬曆丙申首夏武陵華善繼孟逹甫書」：序年為1596，晚於本研究1581成熟四化見證。這是晚明操作旁證，不能單靠此本證明具體公式在1581以前已存在；亦不反斷公式必創於1596。
- [卷一公開古籍轉錄](https://www.shidianguji.com/zh/book/NA06419/chapter/1m451g3115bu6)，本輪讀既有文字，沒有核原刻圖片。下列行號屬本輪網頁工具抽取定位，非葉碼。
- 本機《星學大成》卷二347–354行另明列年干配八卦，作卦氣分類互證；其傳本〈定三元星〉是命宮三合取天元印／地元祿／人元壽，**不是**本輪《玉鏡》的五虎取三元法，不以同名強合。

## 二、原書算例與輸出型別

|條目|卷一行號|原書計算鏈|輸出|
|---|---|---|---|
|天元|1045–1049|甲年卯宮命，五虎遁卯得丁，丁以金為祿|十曜化祿的金曜|
|地元|1049–1055|甲人卦氣亥，亥起甲逆至申得丁，丁屬火|干的普通五行火／五星|
|人元|1055–1061|甲／己年卯宮命，官祿午，五虎得庚，庚金受火克|克遁得干五行的五星火|
|職元|1090–1096|甲年寅宮命，亥起甲順至寅得丁，丁以金為職元|十曜化祿的金曜|
|局主|1098–1100|承前職元干丁，丁與壬合，取壬計|合干再查十曜化祿|
|天馬|1106–1120|己年卯宮命，官祿午，五虎得庚午，庚祿申，申金|祿支的普通五行金|
|地驛|同上|承前官祿午，寅午戌馬申，申金|官支驛馬的普通五行金|

卷一1068–1070行列出的天元祿主就是【甲火乙孛丙木丁金戊土己月庚水辛炁壬計癸羅】。天元／職元的丁金與局主丁合壬計彼此吻合，不能把丁普通五行火誤塞入查祿層。

**「化祿」與「祿居某支」是不同運算。** 天馬算例午火、亥水用的是普通地支五行，不是星宮主午日、亥木。因而不能擅以午取太陽來補甲日。

原OCR人元作「甲巳」、母表作「巳月」；按十干序與甲己同起丙寅的算例作有標記解讀，原字串完整留於結果登記。天馬甲寅例有「得巳巳以丁巳」等混亂，不默改後冒稱原刻已核；以後一己卯命→庚午→申金的清楚算例作驗算。

## 三、公式化；命宮是原法的必要輸入

干以甲為0，支以子為0；`mod`皆取非負餘數。`g`為年干，`m`為實際命宮，`L=火孛木金土月水炁計羅`。

```
卦氣宮 q(g) = 亥申寅酉子午卯巳亥申
五虎得干 T(g,m) = [2(g mod5)+2+((m−2) mod12)] mod10
卦順得干 Z(g,m) = [g+((m−q(g)) mod12)] mod10
卦逆得干 D(g,m) = [g+((q(g)−m) mod12)] mod10

天元 = L(T(g,m))
職元 = L(Z(g,m))
局主 = L((Z(g,m)+5) mod10)
地元 = D(g,m)的普通五行
官祿宮 c = (m+3) mod12
人元 = 克T(g,c)普通五行的五星
天馬 = T(g,c)的祿支之普通五行
地驛 = c的驛馬支之普通五行
```

卦氣宮對支採乾亥、坤申、艮寅、兌酉、坎子、離午、震卯、巽巳慣例；甲亥等有《玉鏡》原例與年表，干配卦有《大成》互證。完整q列明供覆核。官宮+3由原例卯命→午官及寅命→巳官定，不換成其他系統的宮序。支步先mod12、所得干再mod10，不能直接把兩種模數混成固定干位移。

程式驗回8項檢查（含甲己同組），再展開10干×12命宮＝120狀態、七法840輸出。固定每個年干，隨命宮改變：

|規則|每干可得的不同輸出數|
|---|---:|
|天元、職元、局主|各10|
|地元、人元|各5|
|天馬、地驛|各4|

所以這些原法都不是只依年干的常數表；必須另外證明「如何由年干決定應代入的宮位」或怎樣消去實際命宮。

## 四、兩個明列代宮假說，沒有完整化忌

僅測兩種自然錨點：以原年干祿支代命宮、以卦氣宮代命宮。**代入是研究假說，古文沒有叫人如此替換。** 各接七法共14條，未按成熟忌逐干反找宮位；目標只作事後比較，不稱事前盲測。

保留庚同忌G0與庚相忌G1。最佳都是祿支代命宮後取天元：

```
年干       甲 乙 丙 丁 戊 己 庚 辛 壬 癸
所取祿支   寅 卯 巳 午 巳 午 申 酉 亥 子
五虎得干   丙 己 癸 丙 丁 庚 甲 丁 辛 甲
再查祿曜   木 月 羅 木 金 水 火 金 炁 火
```

- G0同忌：乙己辛吻合，3／10。
- G1相忌：乙己庚辛吻合，4／10。
- 十四候選完整吻合均0。卦氣宮代命的職元原樣回到L、局主只是L位移5，亦無全中。

更直接的結構限制：七法所有120狀態的直接輸出都沒有日曜。故即使任意為各干選宮、選上述七法，仍不能直接產生甲日。此證明**只限這七法的直接曜體輸出**；不能擴張為所有古星命都無解，也不排除另有具古文觸發條件的跨曜體／固定星換掛。曜體字典亦屬本研究的表示層，不直接等於所有固定星的物理五行。
