3. `乙亥字紫微數_關鍵表與星義_人工校讀.txt`

   - 保存第21張七欄表的正確欄名與正規化表值，以及第34至43、88、90、128至129張已核關鍵句。
   - 表值採研究程式已使用的正規化星名，原書別名另列。

4. `挨次而化_平行文本摘錄_待原刻覆核.txt`
   - 保存《果老星宗》及清嘉慶十四年《選擇求真》網頁轉錄中的操作句。
   - 這是來源線索檔，不當作已核原刻；待取得古籍頁影後再升級。

5. `太乙人道命法_化曜關鍵摘錄_20260930.md`
   - 保存《太乙人道命法》的年干／日干／日支化曜、五合分組、功能槽→化曜兩段式結構。
   - 已明列現存編成層的年代限制；只作旁系操作語法證據，不作紫微四化直接祖本。

6. `太乙統宗寶鑑_卷帙與命法層校勘_20260930.md`

   - 專門防止把增廣支的陽九／百六人命法因卷首大德七年序而誤上推到1303年。
   - 其中約50MB PDF的命法文字目前採公開搜尋索引，已標記待原頁人工覆核。
