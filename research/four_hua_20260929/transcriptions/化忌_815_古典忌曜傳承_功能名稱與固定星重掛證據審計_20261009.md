# §815｜古典忌曜傳承：功能名稱來源與固定星重掛的證據審計（2026-10-09）

**狀態：第一輪來源／反證整理完成；古曜→固定星之逐干明文規則仍 OPEN。** 承接 §814；研究主線由「另找公式湊成熟忌表」改為「追古典忌曜的文本譜系與可實證的轉換動作」。本輪不變動 §810-A、§812-A 封存，也不把任意相似星名當成繼承事實。

## 1. 三個必須分開的歷史命題

1. **功能名稱先例（有直接舊文）**：《星學大成》四庫傳本卷30〈天元忌星惡曜〉十干舊曜【計、羅、火、孛、木、金、土、陰、 水、炁】；末註「化囚也」。對卷1十變「囚」槽（辛「陰」對「月」）10/10同位。這是同書角色對應，不能獨立證成斗數生年化忌。
2. **功能詞彙進入斗數固定星層（強文本見證，原葉待驗）**：1581《新刻纂集紫微斗數捷覽》底本繫聯的公開點校有「廉貞屬火化囚星」「陀羅屬火化忌星」，同書另列按生年干的四化；故星曜**固有化氣標記**與**年度干支四化承載**須分層。這支持術語群的跨體系共存，但不直接聲明「天囚轉生年化忌」。
3. **逐干固定星承載 remount（關鍵缺口）**：尚無經早期版本／原葉校驗、明確說「取天元忌曜後，依 X 規則改配紫微某固定星」的指令；也尚無完整等價十干轉換算例。

**版本警戒**：公開《捷覽》前言自述以萬曆九年（1581）明刊為底，曾參照《全書》《全集》，原本尾頁有補文，異體字改寫且網站有再修訂。故此處只稱「1581明刊底本繫聯點校」，不可稱已目驗1581年原刻第幾葉；需要按原刻的卷次、頁葉、欄位與附註逐項復核。

## 2. 最重要的負控：把「曜體同名」與「功能重掛」切開

以下左欄依卷30「天元忌星」十曜順序；中欄是《紫微數》乙亥字本原影人工校讀的星名／曜體標記，與§731所引同族表互參；「→」只表示**該條古文中的名稱或曜體附著**，不代表跨書、跨狀態的無條件恒等。右欄 G0 為既存早期固定化忌表，只作**反證揭答**而非調整中欄的依據。

**結果（限定於本表列出的 literal 體名／安星句）**：同位明確可達 **1/10（丁孛→巨門）**；丙「火」有多個受載，無法當單值函數。這否定「拿卷30十舊曜直接照字面翻成 G0 十固定星」的說法，**不否定尚待找到的另外一種歷史指定／條件轉換規則**。這是一個以既知目標核對既有舊文的 negative control，**不是新一輪事前盲驗或新公式**。

**須校正早期§365的口徑**：當時「丙火→天暴→廉貞」「戊木→天機」等稱為名稱橋，依§781後來的 strict-grammar 審計，多屬躔宿、變段等 **state-dependent name**；不同文獻的同名碰撞不足以成為曜體 identity。尤其《紫微數》已明把「天暴／廉貞」附於**計都**，而不是無條件「火＝廉貞」；「火躔某宿號某星」不可剝去宿位條件。因此舊「3/10」不得寫成三條已證物理曜體映射，應降為**帶條件之跨書詞名可達線索**。

另需注意：《捷覽》「廉貞化囚」是其**固有性質描述**；「廉貞化忌」（如同書談落水宮受制）可以是另一層變化。不能由一星同時可有兩類身份推出「凡囚皆忌」，也不能由「陀羅化忌」推出生年十干必取陀羅。

## 3. 證據梯級：何種新史料才足以推進 §815

| 類別 | 希望找到的明文 | 能證什麼 | 目前 |
| --- | --- | --- | --- |
| A：直接轉換指令 | 「某干天囚／忌曜，改取某紫微星」或有條件全干轉換算法，且有原刻實頁 | 最關鍵的年干輸入→固定承載橋 | **未見** |
| B：同一古本並列舊曜與紫微曜且有「從／取／即」的方向標記 | 排除單純同頁並列、按位配表 | 某些特定對應的歷史採用 | **未見具普遍性者** |
| C：同名／曜體身份 | 孛白衣巨門；水龍池文曲等 | 限於該文本的個別附著或星義 | **部分已有** |
| D：忌囚功能詞彙 | 天元忌星＝囚、廉貞化囚、陀羅化忌 | 名稱可跨體系存在的史料先例 | **已有，傳承方向未定** |
| E：後世論者的數學對位或詮釋 | 後人任意選用某宿／宮的別名 | 研究假說，非古人轉換自述 | **不可替代 A/B** |

可以驗證**歷史上的對應**，不等於有古文明說**逐年取用規則**：即便十顆星在一卷都有名字，仍須找 input declaration、哪一端為主、何時啟用、是否允許多值和選端優先順序。尤其早期文獻「忌」可能是（甲）年度囚變曜、（乙）星性惡曜、（丙）本性化忌、（丁）生年化忌、（戊）宮位條件禁忌；不得統一成同一 data type。

## 4. 優先追查的傳承鏈與版本關卡

**鏈一（古星命的角色名）**：《三辰通載》〈定十變星例〉（所引「天囚」須追其版本／紀年）→《星學大成》卷1十變囚槽及卷30〈天元忌星惡曜〉。先逐版確認「天囚／忌星／化囚」是否同時存在、是否註文後添，不能只靠四庫本倒稱宋代逐字證據。

**鏈二（舊曜名稱到早期固定星）**：以韓國國立中央圖書館乙亥字《紫微數》頁20–21、128–129及《玄藪》等獨立傳本為主，逐頁抄「某曜＝某星」與「某宿／宮／變段號某名」的**上下文及字型**，分類 global alias / contextual state / 祿位按列配對；特別查是否有“所忌者取…”之原訣。乙亥字本的刊行／成書年代需要館藏書目實證，不可直接由字型推單一年份。

**鏈三（早期斗數的功能層）**：1581《捷覽》卷一四化歌與卷二廟陷／諸星性質，追原刻影印頁，確認「廉貞化囚」「陀羅化忌」「廉貞化忌」是哪些不同操作；對《紫微斗數全集／全書》異本比對，不以後刻校文當原刻。

**鏈四（卷29來源枝節）**：《星命總括》〈論惡星〉與《星學大成》卷29〈論忌星〉只是「不用X」條件歌的平行傳本；重丁缺癸、戊巳仍待《永樂大典》輯佚底頁／早刻實物。此鏈暫不併到卷30「天元忌星」逐干表。

**旁證年代紀律**：2016年《新玄機》〈破解四化星的來歷〉已有相似的「天囚→四化」近代解說；它可列入學術見解史與待測主張，**不可當宋、明時古人明文轉換指令**。

## 5. 本輪結論／下一證據門檻

**已可優先提升：**「天元忌星／化囚」是古典凶用功能名稱來源的第一級候選；且早期斗數固定星文本確實並存囚／忌／十變化氣術語。

**仍不得閉合：**天囚十干舊曜如何經古人明確指定成固定的生年化忌十承載；目前的 literal-body crosswalk 不僅未補洞，反而揭示了不吻合與多值。

下一個決定性出土／搜尋目標是一句**帶類型、方向、輸入**的古文，例如明言「天囚／天元忌星之曜，依某祿／某宮／某原星轉取紫微星，年干如何逐一配定」。若只得星名對照而無取用令，只能把 remount 提升「partial lexical」，不能升「historical composition」。
