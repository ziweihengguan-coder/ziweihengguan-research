# §818-K｜《三辰通載》〈論有用無用〉延伸：同曜多角色的來源、優先序與可執行條件取用（2026-10-10）

**研究結論：新的選用機制內證成立，但尚未找到年干化囚舊曜轉換成熟紫微固定生年化忌星的專用 caller。** 本節僅用已存本機可讀《星學大成》卷二、十一、十二（四庫傳本）對《三辰通載》識典AI〈論有用無用〉提出嚴格交叉檢驗；《星學大成》對《三辰通載》平行文存在承用關係，不計作兩份獨立早期算法見證。§816、§817、§818 繼續 OPEN；§810-A與§812-A、癸年貪狼反證、版本與歷史年代限制、既有封存資料全部原樣保留。

## 1. 真正解釋「一星何以兼三用」的原文：四元身份不是星的固有別名

來源 `research/星學大成_Kanripo_002.txt` 第420–436行，WYG 24a–24b，〈論四元歌〉。四元是「仁元、壽元、祿元、馬元」，並有逐項輸入與算例：

- 「馬元又為貴元……申子辰馬在寅，寅屬木，即木星是也。」
- 「祿元者如甲生人，祿在寅，寅屬木，即木星是也。」
- 「仁元者以甲乙生人屬木，即木星是也。」
- 「此謂之木星得三用。」
- 「壽元者如甲子生人，納音是金，即金星是也。」

**可重跑的限定例**：甲子生人，`馬元(申子辰) → 寅木`、`祿元(甲) → 寅木`、`仁元(甲乙) → 木`，而 `壽元(甲子納音) → 金`。因此木是同時承載三個由不同算式取出的功能身份，不是「木天生就是三種星」；四元也不是把木變成金或成熟固定星。

同段明言「須看仁壽二元為先，貴祿為次」，這提供**身份優先分組**，但文中未進一步單排「仁與壽孰先」及「貴與祿孰先」，不得自行填表。此段「貴元」與「馬元又為貴元」的語言保留其文脈，不能直接拿年干十變的「貴」槽視作相同ID。

## 2. 「有用」還有可核對的兼任數／入格條件，不止吉凶形容

同卷第506–547行，WYG 28b–31a：

- 〈論垣局〉：「凡入垣皆須滿三用方為正垣，惟木星兩用便是垣也……三用則大貴，兩用則貴，有用則不賤。」**這是垣局／貴格的原文規範，不是適用各法的普遍加權公式**。
- 〈論臨駕〉：「一星作三四主者號受權臨駕，如為二主星號選職臨駕，為一主則無用。」同一星兼任的**角色數**觸發不同格局類別，不須把星換成另一物理曜體。
- 卷二〈入殿〉另有「須與日月為三元與太歲相攝」「又要是三元主，如不是三元主則無用」。**三元主、四元、十變福祿囚、十干化祿等名稱相近而輸入規則未必相同，必須分型別**。

重要性：已找到 `RoleSet(inputs, star)` 及 `Multiplicity(RoleSet)` 的完整可理解古典算法骨架，較僅據「當究其善惡之用」有具體進展。

## 3. 兼財兼刑時實際選何用：卷十一存在明確取捨與反向條件

來源 `research/星學大成_Kanripo_011.txt` 第443–468行，WYG 25b–26b，〈辰宮命〉發明注。

> 「又如火星在午是財星逢旺，亦是刑星逢旺……既看財元，不當以刑星論。」

同段給特定吉例：丁巳生人，祿在午、火為財元逢旺，又有土計祿權相助且行午限，作者據財、福、祿條件取吉。緊接着另設凶例：

> 「若火為財元逢旺，倘會刑囚難直在午，又是歲煞之所在，若更生於夏月之時火神用事……」

兩個例子同時保留火為財、火可能成刑之雙重身份，只是**論事主題、同宮遇曜、歲煞、時令、行限**決定取哪個作用及輕重。第一條「既看財元不當以刑星論」不可從情境抽走而提升為「凡火兼財刑，永遠只取財」。

同區有「卯為財帛，火星居之不為財元入廟，乃是刑曜入垣」，證明**位處財帛宮不代表星的功能自然改為財元**；要問具體命局、星位、星的身份。這是防止按字面同名誤換載體的強負控。

## 4. 同書確有「捨A曜，從B曜」的實際條件選星，必須釐清其輸入型別

來源 `research/星學大成_Kanripo_012.txt` 第182–221行，WYG 10b–12b，〈酉宮命〉：

- 「一木兩用，善惡當分」，連同晝夜／時令、直難等條件評估。
- 酉命以金為命主，金火月為三限主，金、火可能敵對。原文說「若火金相去隔遠，三合無相干犯，又可捨金星而從火用」。
- 緊接解釋：夏月「火秉令」及火同屬「金火月三限主」，因此在這種情境可以選取火的作用，而不是不問條件始終只執金命主。
- 隨後秋月金司令時另論金星得時；昴畢宿段又明說「太陰為先，金為次」，這是另一文脈的優先序，不可和卷二的「仁壽為先」合成無條件總排名。

**實際可見的操作**：`S(酉命, 夏令, 火金不相干犯, 三限角色, 星位) → 可優先從火用`。這不是單純替同一曜貼吉凶標籤，而是**在金、火兩顆不同古典曜體之間作有條件的取用**。然而古文沒有說「年干化囚曜先取金，滿足上述條件後改掛火」，更沒有把火指定為成熟紫微任一固定星。

## 5. 與 §818-J〈論有用無用〉異文的合併判斷

識典 `030.json`「六甲人以木為財、為權，又用以為綬」，WYG卷二29a則是「六甲人以木為財、為福，又用以為祿」。甲木按十變母環為「福」的源端正控已保留於§818-J。此處暫不裁判網站AI「權／綬」究竟原字何形；也不因四元的`甲→木祿元`而宣稱「十變化祿甲→木」，因十變甲年的祿曜本是火。**同一詞「祿」可能是四元祿元、某命局財祿功能，或十變祿角色，名稱碰撞不可直接等同**。

所以這裡不宜提出一條單一「用」算式，而至少分四層：
1. `F(生年干, 舊曜) → 十變角色`：宋元天囚的年干角色，已由§818-H／§814確認。
2. `M(年干/支/納音/宮位/出生時等) → 舊曜的功能身份集合`：四元與其他宮主星。
3. `P(M, 論斷對象, 時令/晝夜/星位/交會/限運) → 這次優先取哪個身份或哪個原始曜`：卷11、12文本支持。
4. `R(年干化囚舊曜, 古典選星條件, 版本) → 成熟紫微固定化忌星`：**仍未找到明文古典caller，也未證能消去生時、宮位、季節等分歧而保證每一干固定唯一星。**

即使P成立，也不表示R成立。尤其對癸干的`囚炁→成熟貪狼忌`，本輪仍無指定指令，原反證不可繞過。
