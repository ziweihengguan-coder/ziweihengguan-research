# 《太乙統宗寶鑑》卷帙與命法層校勘

更新：2026-09-30

## 目的

追查《太乙統宗寶鑑》中「五合化氣 → 五行數 → 陽九／百六命限」的人命法，究竟能安全上推到哪個年代。
本檔只做版本學分層；不把後出增補內容因書名或元代序文而直接前推至1303。

## 一、主要版本／支系

### A. 十八卷舊鈔本系

《皕宋樓藏書志》明載【《太乙統宗寶鑑》十八卷舊抄本】，並抄錄大德七年序，其中直接寫【集為一書，標類成目，凡十八卷】。
這與若干傳本「凡二十卷」不同，證明卷帙在傳承中已發生分歧。
來源：https://ctext.org/wiki.pl?chapter=718738&if=en

目前未知：
- 該十八卷舊鈔本是否保存人命法；
- 現代國圖編目為二十卷、且帶陸心源舊藏印的06612，與《皕宋樓藏書志》十八卷本的具體裝訂／補配關係仍需逐卷核對。

### B. 二十卷「軍國太乙」系

可全文檢索的CADAL／CTEXT二十卷支顯示：
- 卷十九：明太乙出兵舉事用日之術，以及用時、兵事等；
- 卷二十：明十精太乙所主術等。
亦即此支的卷十九、二十不是人命法。

### C. 二十二卷以上增廣支

識典另有一部同題《太乙統宗寶鑑》，可直接檢索到【太乙統宗寶鑑卷第二十二】；卷二十二為四計太乙紀元入局立成等。
但同一書系序文仍保存【凡二十卷】，因此【元序稱二十卷】與【實際傳本超過二十卷】可以同時存在，是後增卷而保留舊序的直接版本現象。

但目前尚未取得該影印本卷十九首頁作直接人工核對，因此【明抄二十卷】不等於【已證明明抄卷十九是軍事或命法】。

## 二、人命法目前可確認的核心操作

後出／增廣支的人命法寫：命法行陽九之限者，取當生之日干化氣五行，各從生方起，男順女逆而行。

日干五合化氣：
- 甲己化土 → 數五
- 乙庚化金 → 數四
- 丙辛化水 → 數一
- 丁壬化木 → 數三
- 戊癸化火 → 數二

結構：日干 → 五合配對 → 化五行 → 取五行數 → 由相生方起命限 → 男順女逆。

這證明【五合不只用來命名合化，也可以直接成為人命時間運算的前置選擇器】。
但目前只能稱【《太乙統宗寶鑑》增廣／命法支的明文】，不能直接稱【1303年曉山老人原書明文】。

## 三、與《太乙人道命法》的文本家族關係

《太乙人道命法》與此命法支都使用：命宮、身宮、十二宮、陽九、百六、流年、飛祿、飛馬，以及五福、君基、臣基、民基、文昌、主大將等太乙神。

十二宮次序亦高度接近：
- 人道命法：命、兄弟、妻妾、男女、財帛、田宅、官祿、婢僕、疾厄、福德、相貌、父母。
- 統宗命法支：命、兄弟、夫妻、子孫、財帛、田宅、官祿、奴僕、疾厄、福德、相貌、父母。

這種相似度足以把兩者列作【同一太乙人命傳統或高度近親文本】；但方向未定：統宗增廣支→人道命法、人道命法→統宗增廣支、或共同更早命法祖本，都仍需逐句校勘。

## 四、對紫微四化研究的證據分級

### 已能使用
1. 天干五合是古典真實結構。
2. 五合分組在旁系命法中可作功能／命限選擇器。
3. 功能槽→承載神／化曜的兩段式語法在太乙人命系存在。
4. 這些可作紫微七欄表「五合交換／功能重掛」的外部結構旁證。

### 尚不能使用
1. 不能說《太乙統宗寶鑑》元代原本已有這套人命法。
2. 不能說紫微四化直接抄自太乙命法。
3. 不能把太乙日干規則直接改成年干四化規則。
4. 不能用太乙神名逐格補成熟四化剩餘十格。

## 五、下一步版本學硬任務

1. 核國圖／國家圖書館中國藏二十卷抄本的卷十九首頁：是「出兵舉事」還是「命法」。
2. 核《續修四庫》明抄二十卷卷十九首頁。
3. 核韓國國立中央圖書館 CNTS-00076808056《太乙統宗寶鑑》卷18-20 的卷十九標題。
4. 在十八卷舊鈔系尋找卷末內容，確認人命法是否完全不存在。
5. 若人命法只在20卷後增廣／清增補支出現，則形成下限可明顯後移；若明抄二十卷已有人命法，再追其與1581《捷覽》的先後。

## 六、暫定判決

目前版本樹應先寫為：
大德七年序所代表的早期《統宗寶鑑》核心
├─ 18卷支
├─ 20卷軍國太乙支
└─ 後續增廣／重編
   ├─ 人命法層
   ├─ 22卷以上支
   └─ 與《太乙人道命法》高度近親的命法系

「人命法層」的最早實際年代仍待版本學確定。

## 七、2026-09-30 第四輪版本硬核：進度與新權重

### 1. 《續修四庫》明抄二十卷

《續修四庫全書》總目明確著錄：

【太乙統宗寶鑑二十卷　題（元）曉山老人撰　子部第1061冊　影印明抄本】

2025年魯楠、葉杰、李剛〈《太乙統宗寶鑑》中的天文數表校勘〉亦明列使用【中國基本古籍庫（明抄本）】作校本，並稱所比三本內容基本相同。

但該文研究卷一天文曆法，不等於已核卷十九。因此：

【明抄二十卷存在＝已證】
【明抄卷十九為出兵舉事＝尚待原頁】

### 2. 二十卷軍國主幹

可全文檢索的完整二十卷支明確為：

- 卷十八：七十二局陰陽立成；
- 卷十九：明太乙出兵舉事用日／用時等軍國術；
- 卷二十：明十精太乙所主術。

因此【二十卷軍國骨架】已屬強直接證據。

### 4. 十八卷舊鈔系

《皕宋樓藏書志》明載【十八卷舊抄本】，且其所錄大德七年序作【凡十八卷】。

可證：
【十八卷文本家族確實存在】

尚不能證：
【已親眼核卷十八末頁為全書終，且完全無人命法】

### 5. 對版本權重的更新

在尚未完成三件大檔原頁直核之前，不能宣告版本問題已結案。

但現有證據已明顯偏向：

【早期軍國太乙核心】
→【後續增廣／重編】
→【人命法層】

理由：
- 18卷舊鈔祖型；
- 完整20卷軍國主幹；
- 至少一件含人命材料的06613被館藏直接標【清人增補】；
- 《太乙人道命法》現存編成層本身又帶17世紀時間參照。

因此紫微四化研究中，太乙人命材料暫降回【操作語法旁證】；主線重新回到朝鮮前期乙亥字《紫微數》的七欄十干表。
