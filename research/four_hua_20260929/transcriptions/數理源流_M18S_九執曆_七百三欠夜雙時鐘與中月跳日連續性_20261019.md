# 數理源流 M18-S｜《九執曆》703欠夜進位與中月「12度×25取商」雙時鐘連續性（2026-10-19）

> **新發現是來源端的跨步結構性數學指紋，不是原字校刻成功。** 在M17-S兩處未校定運算假說「下位二十五餘之→25取商後加原位」「以十二除之→月內槽序數乘12度」之下，對703個連續tithi暫計槽作一個完整703餘數循環的型別壓力測試。每703槽恰11次欠夜進位、692次普通曆日候選進日；每次欠夜進位雖有12度基本步進，但小餘項恰抵消719或720角分，故同一候選積日D的兩個相鄰槽只差**1′（8次）或0′（3次）**；正常D進一日，中月則走**790′～792′**。原書〈推月域〉另明文以790角分為**定月**逐日行量替代算法的本位，提供獨立於現代天文擬合的相近尺度比較，**並非保證候選中月=原書定月**。新增JS **24/24 PASS**；歷史端仍PENDING，M09～M17-S舊檔不變，§816／§817／§818 OPEN。

## 2. 雙時鐘：30日槽N與候選普通曆日D不能混為一日

承M14～M17條件式模型，將每個暫計tithi槽標為 **N**；固定未校定常數c∈{169,429}：

```text
Q(N,c) = floor((11N+c)/703)             // 累積欠夜整數商
r(N,c) = (11N+c) mod 703               // 703制小餘
D(N,c) = N - Q(N,c)                    // 候選sāvana整日（未校曆元）
n(N)   = N mod 30                      // 來源例型30月槽內序數；非真月日
C25(r) = r + floor(r/25)               // M17尚未校字之商後回加
L(N,c) = mod_21600[Sun(D) + 720*n(N) + C25(r)] // 候選中月（角分）
```

其中Sun(D)僅是M15-S〈推中日〉先取整角分的條件算式，不是經觀測驗證的平太陽曆元位置；L亦不得轉換為真月／27宿。以N=21185、n=5，重算M17兩支：
- c169：D=20854，r=511，L=124°18′。
- c429：D=20853，r=68，L=115°38′。

703與11互質，因此任取連續703個N，r恰循環全部0～702、Q精確增加11、D精確增加692。這是**來源常數導出的整數算子恆等式**，不取決於在現代天象中選中哪個年代。

## 3. 最重要的新指紋：703進位與12度的量級抵消

每N前進1，通常r前進11、Q不變、D前進1。當r≥692，則：

```text
r' = r + 11 - 703 = r - 692
Q' = Q + 1
D' = (N+1)-(Q+1) = D          // 不是隔了一候選普通曆日！
```

月內n增加一槽，跨30槽時同樣按周天360°取模，所以720角分的月內基本步進仍存在。跨703回捲：

```text
ΔL = 720 + C25(r-692) - C25(r)       // Sun(D')=Sun(D)
   = 720 - 692 + floor((r-692)/25) - floor(r/25)
```

對r∈[692,699]，floor(r/25)=27，故 **ΔL=+1′**；對r∈[700,702]，floor(r/25)=28，故 **ΔL=0′**。由於11與703互質，703槽內11次欠夜回捲必分佈為**8次+1′、3次0′**，兩個c分支結果完全相同。

這是比「30×12=360度」更強的檢驗：**25取商回加的係數恰使703餘數回捲幾乎整整抵掉下一tithi的12度**。若把相鄰N錯認為相鄰普通曆日，會誤稱月亮停行；真正發生的是**兩個tithi槽落在同一個候選D**。時間標籤已重複，不能用普通曆日速度判定為偽。

## 5. 反證分支：哪些程序讀法不能維持同D的近等值

- 「二十五餘之」若粗糙當成 **r mod25後再回加**，在c169的N=21202→21203，跨餘698→6時不再保有0′～1′近等值。它不能通過本次雙時鐘特異性條件，但不能因此以數學反證直接把「餘」校成「除」。
- 「以十二除之」若在月內序數n=22→23直接取 **floor(n/12)**，遇c169欠夜時少了+720′補償，中月突然**逆跳至少719′**，不合此條候選算法鏈的雙時鐘連續性。
- 若另把n錯設為 **D mod30（普通曆日序數）**，在同一D欠夜進位時n不增加，C25回捲會直接造成約719′逆跳。這可說明〈推中月〉的「自入月已來所經日」所屬**計數日型**必須先核清。
- 請勿將「25餘數加原位」與「25乘後加原位」等負控理解成窮舉了所有合理古文句讀；古文中也可能存在尚未辨識的位值、分母或脫文。

## 6. 高月三常數的辨識能力——本次不能解決

〈推高月〉的FIRST=18相26°41′、SECOND=1相13°45′、BOTH=兩者相加仍只作**三個未校定的假設分支**。對欠夜回捲D不變的兩槽，任何依D計算且加上**固定常數**的高月分支都不變。因此〈推月藏〉中月減高月的三種月藏，同樣只呈現0′或1′差：

```text
D'=D     ⇒  高月(D',k)=高月(D,k)       （k任一固定分支）
        ⇒  Δ月藏(k)=Δ中月∈{0′,1′}
```

所以欠夜連續性**不能選出FIRST、SECOND、BOTH何者符合原文**，更不能藉本輪認定「十八相」是另一曆元或「一相」是旁註。要定奪須有版本分句、起點欄位、實例算式或獨立文獻；否則原M16-S 3×2候選月藏完整保留，不假裝已選唯一值。
