# 化忌上游續查：〈祿勳〉的十干取曜與十干取位同段並列（2026-10-09）

## 問題

承《化忌_四化落宮與安星訣_十二紫微位置及昌曲時辰反例_20261009.md》已跑通17項檢查、43200個形式安星狀態與182組主星D12負控。既然坐宮距離不足以生成指定星名，就尋找**祿母曜與年干安星宮位在古典星命中是否真有共同輸入結構**，不借成熟化忌答案設候選。

## 具體同段史證

《星學大成》（萬民英撰，1563自序為早期年代定位；這裡引用的是現存四庫本，**未證四庫所見每句都可推回1563原刻**）卷一〈論祿勳〉：

> 祿者天元祿甲火乙孛丙屬木丁是金星戊土求己是太隂庚是水辛炁壬計癸羅㬋是也勲者甲在寅乙在卯丙戊在巳丁巳在午庚在申辛在酉壬在亥癸在子星入垣廟即為崇

原文電子定位：https://zh.wikisource.org/zh-hant/星學大成_(四庫全書本)/卷01 ，「論祿勲」。

這是**同一題目內、同一原干索引的兩種輸出類型**，而不是把孤立的十變曜母環與後出斗數祿存碰巧同名。

- 天元祿（曜）甲至癸：火、孛、木、金、土、月、水、炁、計、羅：10個異曜、十干不碰撞。
- 勳（位置）甲寅、乙卯、丙戊巳、丁己午、庚申、辛酉、壬亥、癸子：只有8種不同宮支，丙戊、丁己各一組碰撞。
- 文本該句的「丁巳在午」照現存網頁原字記錄，依上下文及《捷覽》明確「丁己祿居午」推定丁己，但須另作版本校勘，不靜默改成原文。
- 這裡的「勳」與祿存位置同序是強烈的**位置取法平行**；**不等於**原文已把二者聲稱為同一後世星名，更不等於已指示化忌選某曜。

《捷覽》卷一〈安祿權科忌四化訣〉直接按年干列四星，解文稱在既有固定星「下安」祿權科忌；〈安祿存羊陀星訣〉則另列年干祿存宮與羊陀前後位。頁面順序是星系／昌曲安法→四化訣→魁鉞→祿存羊陀，不能把章序當上游生成順序。公開轉錄：https://shixingji.club/public/ziweidoushujielan 。整理本2015年重校、2025年網頁再修，沒有就本次直接驗1581刻頁，不提高原字可信級。

## 更強的「母環取功能角色」古文正控

同《星學大成》卷一〈論天嗣〉：「故欲推天嗣者即其變曜中化貴者是也。」原例甲以火為祿、己以月為祿，再取化貴。這是**明示年干→十變曜相對角色→具名功能星**的正控，不需星曜實際落宮，也不指定化忌。

〈論官星〉「官星者乃十干官星之祿星」，甲以辛為官，辛炁為祿，故甲官星炁；同樣是有清楚 input selector 的跨干 lookup 正控。這些例子的價值是提供如何認定「有古文指定輸入」，不應移植角色名便稱新化忌公式。

反面 namespace 提醒：同卷〈論文昌〉是按**年干取地支**的文昌位置；而《捷覽》卷一文昌是由**生時**自戌宮逆數。兩者同叫文昌，但輸入型別與對象未必相同，不可用字面同名自由跨接，正如獨立「印星」與斗數「天相又名印星」不能默認同一查表結果。

## 不被本輪史證跨越的硬門檻

1. 在十變曜母環取得 `L(g)` 後，**須找到一條非目標指定的取忌角色**，例如可審計之古文調用：`role(g,L(g),conditions)`。
2. 若走位置路線，需保留原干全資訊（不能僅以8個祿勳位置逆推10干），並證明所選星名在同干**所有出生月日時**保持恆定；真正安宮則依該星的出生參數另算。
3. 先封存 selector（例如原干、十變角色、星系類、取宮主函式）與 output universe，再比較 G0/G1/G2；不可看成熟忌後按干填不同的T/M常數。
4. 「祿勳同段」列為 **DIRECT shared stem input / parallel output witness**，不是 DIRECT Lu→Ji carrier selector。現有17項位置驗算的結果層級不變；§810封存不改。

**判語：早期星命系統確實具備『同干輸出祿曜＋祿位』的雙路型別，也具備『十變角色轉為具名功能星』的直接語法；二者與紫微化忌之間的專用 caller 尚未接上，從祿母表生成化忌仍 OPEN。**
