# 化權816最後缺口：1581《捷覽》稀疏閉環、朝鮮《玄藪》同構與日本藏《全書》異文（2026-10-04）

## 目的

接續研究紀錄 §702，專查以下形式是否在古代斗數文本內部直接存在：

【既定方向／次第】→【略過若干宮位、只在指定位置掛星】→【仍保持方向】→【最後回到起點形成閉環】

本輪不再把一般性的「循環」「周而復始」視為足夠證據；重點是找「稀疏取位仍閉合」的程序文字。

## 一、1581《新刻纂集紫微斗數捷覽》已直接給出「稀疏取位＋回首閉環」

公開點校本明示底本為萬曆九年（1581）金陵書坊王氏洛川刊本，且整理原則為最大程度保留、還原萬曆本正文：

- https://shixingji.club/public/ziweidoushujielan
- https://tianjihq.com/en/learn/books/ziwei-jielan/22

卷一〈布南北二斗諸星訣〉：

> 紫微天機星逆行，隔一陽武天同情。又隔二位廉貞位，空三便是紫微星。

其下立即用寅宮作例：

> 假如紫微在寅宮，則逆行丑宮安天機，隔子宮一位亥宮安太陽，戌宮安武曲，酉宮安天同，又隔申宮未宮二位至午宮安廉貞，又空巳、辰、卯三位便見寅宮紫微星矣，余仿此。

這不是抽象論命語，而是可直接執行的安星程序：

1. 固定起點：紫微；
2. 固定方向：逆行；
3. 中途明示「隔一」「隔二」「空三」；
4. 略過的宮位不掛本星組星曜；
5. 經十二宮一周後明文「便見寅宮紫微星」，即回到起點；
6. 「余仿此」把同一算法推廣到任意紫微起宮。

若把紫微起點記為0，逆行每過一宮記為+1，則六顆紫微系星的佔位偏移為：

- 紫微 0
- 天機 1
- 太陽 3
- 武曲 4
- 天同 5
- 廉貞 8
- 再空9、10、11三宮後，下一位12≡0，回紫微

所以其宮位集合是：

`{0,1,3,4,5,8} mod 12`

而相鄰掛星之間的步長為：

`1,2,1,1,3,4`

總和正好12。

這已直接證明：成熟斗數安星術允許在十二宮大環中「跳過非作用位置」，仍依固定方向運行，最後回到原始anchor閉合。

## 二、南斗一系更直接出現「次第排列＋跳位＋回到天府」

同一1581《捷覽》下一句：

> 天府太陰順貪狼，巨門天相與天梁。七殺空三破軍位，隔宮望見天府鄉。

寅宮例：

> 假如天府在寅宮，則順行卯宮安太陰，辰宮安貪狼，巳宮安巨門，午宮安天相，未宮安天梁，申宮安七殺，隔酉、戌、亥三宮，在子宮安破軍，隔丑宮一位，便是寅宮天府星也。余仿此。

後來《全集》系轉錄又把此意說得更白：

> 此八位星皆順行，以天府為主，在何主宮即太陰次第排列。

此處四個部件已同時出現：

- 局部星組；
- 固定方向「順行」；
- 星組內「次第排列」；
- 中途「空三／隔宮」但最後回到天府。

因此§702所要求的「局部取位仍沿原次第」形式，不再只是外部太一／遁甲類比，在斗數安星正文中已有直接同型程序。

## 三、《玄藪・中天太極紫微數秘訣》與1581《捷覽》幾乎逐字同構

本機：
- `CNTS-00047968254_玄藪.pdf`
- `玄藪_中天太極紫微數秘訣_網路轉錄校勘版.txt`

網路轉錄亦可核：
- https://ekachai.pixnet.net/blog/posts/11365237316

〈定極庫諸星例〉：

> 太極天驛星逆行，隔一常雷至鳳凰，又隔二位天暴位，空三便是太極星。

舊名對應：
- 太極＝紫微
- 天驛＝天機
- 太常＝太陽
- 天雷＝武曲
- 鳳凰＝天同
- 天暴＝廉貞

故其程序與1581《捷覽》完全同構：

`太極0 → 天驛1 → [隔1] → 太常3 → 天雷4 → 鳳凰5 → [隔2] → 天暴8 → [空3] → 太極0`

這不是只共享「隔一／隔二／空三」字眼，而是：
- 同一anchor；
- 同一方向；
- 同一跳位數；
- 同一六星角色；
- 同一閉環終點。

因此中、韓兩條文本鏈共同保存的是同一個「稀疏閉環安星算子」。

## 四、日本藏明刊《全書》保存更明確的「復見」異文

日本國立公文書館／舊內閣文庫藏：

- 書名：《新鋟希夷陳先生紫微斗數全書》
- 請求番号：子060-0001
- 明刊，七卷，二冊
- 公開書目：https://www.digital.archives.go.jp/file/1078787

本機對應：
- `新鍥希夷陳先生紫微斗數全書_七卷_明代南陽堂刊本.pdf`

公開文本可核：

> 紫微天機逆行傍，隔一陽武天同當，又隔二位廉貞地，空三復見紫微郎。

關鍵異文是：

- 《捷覽》：「空三便是紫微星」
- 日本藏明刊《全書》：「空三復見紫微郎」

「復見」比單純「便是」更直接表達：
【經過既定跳位程序之後，再次回見起點紫微】。

所以日本藏《全書》不是只證明同一安星序存在，而提供「復」這個閉環語義的獨立文字見證。

## 六、與§700「816 local-next」的關係：形式缺口大幅縮小，但仍未完成最後一跳

§700成熟化權模型需要：

1. 先由全域 `權(g)=祿(g−1)` 得7/10；
2. 廉退紫入；
3. 對殘差三carrier `8:紫、1:巨、6:梁` 使用同一next方向；
4. 但將作用域縮到816局部環：
   `8 → 1 → 6 → 8`；
5. 一次local-next即得成熟權10/10。

§702以前最大的形式疑問是：
「古代斗數是否會在十二宮大環中，只沿某些指定位置前進、略過其他宮，最後回到anchor？」

本輪答案已經是【會】：

- 1581《捷覽》紫微系：固定方向＋隔一＋隔二＋空三＋回紫微；
- 1581《捷覽》天府系：固定方向＋空三＋隔宮＋回天府；
- 《玄藪》舊名系：與紫微系同構；
- 日本藏明刊《全書》：直接作「空三復見紫微郎」。

所以「sparse orbit／跳位閉環」本身已是古代斗數內生操作，不需要再從現代Z12投影概念硬借。

### 仍未證明

但這一輪仍不能直接寫成「古文已證816三循環」，因為：

1. 上述閉環的作用域仍以十四主星安星序為對象；
2. 沒有一句古文說「取洛書8、1、6三位」；
3. 沒有一句古文說「紫微、巨門、天梁只在816三位互相輪流」；
4. 沒有一句古文把此算子明確掛到十干化權生成；
5. 1581《捷覽》四化表雖緊接安星訣之後，但「相鄰編排」不是生成關係的證明。

因此本輪提升的是：

【local sparse cycle 這種操作形式是否古典？】
→ 是，已可直接確證。

而最後唯一尚缺：

【為何成熟化權偏偏把local作用域選成816，並把紫／巨／梁放進這三槽？】
→ 仍待直接selector或更強的跨文本唯一性證據。

## 七、證據層級更新

A級：直接古文程序
- 1581《捷覽》「隔一／隔二／空三／便是紫微星」；
- 1581《捷覽》寅宮例「空巳辰卯三位便見寅宮紫微星」；
- 日本藏明刊《全書》「空三復見紫微郎」。

B級：跨文本同構
- 《玄藪》太極／天驛／太常／天雷／鳳凰／天暴六星與《捷覽》紫微系逐項同構。

C級：後出文本明文化
- 《全集》系「在何主宮即太陰次第排列」，把局部星組的保序說得更白；版本年代需分層。

D級：模型重建
- 把上述sparse-cycle形式用於816的三carrier local-next；仍是低自由度重建，不是古訣直文。

## 八、下一步

§704優先不再泛搜「循環」，而只做兩件事：

1. 追「816 selector」：在《捷覽》安星、三合、對沖、太極／主宰、四化前後頁尋是否存在能從既有星系結構自動選出8、1、6的古典規則；
2. 東洋文庫VII-3-157逐幅定位〈布南北二斗諸星訣〉與四化頁，核「次第排列」「便是／復見」「庚／壬異文」，看是否保存比清刊《全集》更接近1581的文字。

負控固定：
- 「古代有稀疏閉環」≠「古代明文816閉環」；
- 「8恰好出現在紫微系偏移」不得反向當成河洛816證據；
- 不得因《捷覽》安星訣與四化表相鄰，就把安星算子直接宣稱為四化生成法。
