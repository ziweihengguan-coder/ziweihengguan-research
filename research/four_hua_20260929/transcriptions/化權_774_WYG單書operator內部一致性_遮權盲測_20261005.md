## 二、卷一總公式的正確方向要分兩個視角

卷一先定：

【甲乙丙丁戊己庚辛壬癸】
→【火孛木金土月水炁計羅】

再用〈變曜歌訣〉按功能位次計數。

因此若以「固定曜」看：

> 同一 carrier 在某干為祿，下一干為權。

即：

`QuanStem(body)=LuStem(body)+1 mod 10`

若以「十干 row」看，方向反過來：

> 某干的權 carrier = 前一干的祿 carrier。

即：

`QuanCarrier(g)=LuCarrier(g-1)`

後面接《紫微數》祿row時必須使用第二種 row-centric 寫法，不能把方向寫反。

## 三、固定 offset 全枚舉負控

對十曜單曜章的實際【祿干→權干】枚舉所有10個 cyclic offset：

| offset | 命中 |
|---|---:|
| 0 | 0/10 |
| +1 | **8/10** |
| +2 | 0/10 |
| +3 | 0/10 |
| +4 | 0/10 |
| +5 | 0/10 |
| +6 | 0/10 |
| +7 | 0/10 |
| +8（-2） | **2/10** |
| +9（-1） | 0/10 |

所以：

> 沒有任何單一固定 offset 可以把十個單曜章全部吃掉。

但【+1】是唯一壓倒性主規則，8/10；【+8】只落在炁、計；其他全部0。

這比只描述「8新＋2舊」更強：整個十環沒有第三個競爭 offset。

## 四、卷一新掛名對完整功能row的誤差

用卷一新層模板：

【祿、權、囚、印、刑、貴、蔭、耗、福、暗】

逐曜比較：

- 火：0格差
- 孛：0格差
- 木：2格差（蔭／印仍舊）
- 金：0格差
- 土：0格差
- 月：2格差（蔭／印仍舊）
- 水：0格差
- 炁：4格差
- 計：4格差
- 羅：0格差

所以單曜章並不是「卷一錯兩曜」這麼簡單，而是明顯三層：

1. 6曜完整新層；
2. 木、月只剩蔭／印尚未重掛；
3. 炁、計四個重掛名全部未更新，完整舊層。

這是編纂層次，不是十個獨立亂錯。

## 五、關鍵新測試：遮掉「權」本身，仍能10/10預測權位

為避免用權位自己分類權位，本輪把每曜實際【權】那一格先遮掉，只看其餘九個功能標籤，分別與：

- NEW
- HYBRID
- OLD

三種模板比較。

結果：

- 火、孛、金、土、水、羅 → 其他九格唯一支持 NEW → 預測權 offset +1
- 木、月 → 其他九格唯一支持 HYBRID → 預測權 offset +1
- 炁、計 → 其他九格唯一支持 OLD → 預測權 offset +8

再把被遮掉的實際權位打開驗證：

> **10/10 全中。**

也就是：

> 炁、計不是因為「看到它們權在+8」才被叫例外；即使權位先遮掉，其他九個角色已經足以把它們識別成完整舊層，並獨立預測權應落+8。

這使「8新＋2舊」由描述性統計提升成同書內部可預測 dataflow。

## 六、《星學大成》自己的最小祿→權模型

本輪最小模型應分兩層寫，而不是硬造一條混合公式：

### A. 卷一 normative general operator

> 固定曜視角：祿干 +1 → 權干  
> 十干row視角：權(g)=祿(g−1)

這是《星學大成》卷一直接定義的主規則。

### B. 單曜章 editorial-strata override

單曜章並非同步改寫完成：

- NEW / HYBRID 層 → 權仍在+1
- OLD 層 → 權仍在+8

而層別可在遮掉權位後，由其他九功能獨立分類。

所以若只問「WYG現存單曜章資料本身」：

> 先由非權九格判層 → NEW/HYBRID 用+1，OLD用+8 → 10/10還原十曜權干。

但這個 mixed model 只用來描述／預測 WYG 單曜章，不應直接跨投影到成熟紫微。

## 七、紫炁／計都是否唯一異常群

答案現在可說得很準：

> **是，若「異常」定義為相對卷一新層仍完整保留宋舊四標籤的群。**

只有炁、計：

- 福仍在+1；
- 蔭仍在+3；
- 印仍在+6；
- 權仍在+8。

木、月不是同類異常，因它們已完成福／權重掛，只剩蔭／印尚舊。

所以真正的版本剖面是：

> 6新＋2過渡＋2舊。

## 八、對後續跨到紫微的約束

這一節反而讓下一步更乾淨：

1. 跨到《紫微數》時，不應拿「8新＋2舊混合單曜表」直接套；
2. 應先用卷一自己的 **general operator**：
   `Quan(g)=Lu(g-1)`
3. 因為這條是卷一明文、低自由度、target-free；
4. 單曜章8/10命中與兩個舊層，只用來證明此operator已大幅滲入固定carrier章節並留下編纂過渡，不是跨系統selector。

## 十、結論

《星學大成》內部現在已可分清兩件原本容易混在一起的事：

> 卷一有一條乾淨、普遍、可執行的【祿→權】主operator；單曜章則保存這條新規則逐步覆寫舊《三辰通載》標籤的編纂剖面。

單一固定offset最大只能8/10；但用同書其他九角色先判版本層，再預測被遮掉的權位，可達10/10。

因此下一步可以安全地只抽取卷一 general operator，接到《紫微數》固定祿row，做真正 target-free 的跨書生成與最後validation。
