## 二、真正應比較的三種運算型別

### A. 舊十曜循環：同一張模十母環

定甲～癸為 `g=0..9`，祿、暗、福、耗、蔭、貴、刑、印、囚、權為 `r=0..9`，母環 `P=[火,孛,木,金,土,月,水,炁,計,羅]`：

```
F(g,r)=P[(g+r) mod 10]
```

卷一29a〈祿勳〉保存天元祿十干序列。十變曜角色循環及其不等於成熟四化直抽，均早在§809及前例完成。本節再做100格的迭代步進／閉式公式內部一致性測試，**不是新發現100條古書證據**。

### B. 〈論官星〉：先取正官干，再取它的祿曜

同卷32a的來源明言：

> 甲炁乙水是官星，丙羅丁計戊孛成，己火庚金辛見木，壬陰癸土定功名。

並解釋「甲以辛為官，辛以炁為祿，則甲人用炁為官星」。把甲編0、乙編1，正官干選擇可以由**陰陽／奇偶分流**表示：

```
h(g)=(g + 7 - 2*(g mod 2)) mod 10
官星(g)=P[h(g)]
```

陽干 `g=0,2,4,6,8` 取向後 `+7`，陰干 `g=1,3,5,7,9` 取 `+5`，十干官星 10/10 與卷一歌訣符合。這是一項真正具有區別力的**條件選擇器指紋**，與直接平移十曜母環不是相同的算子。

**硬負控：** 不考慮陰陽，將 `官星(g)` 強行擬合 `P[(g+k) mod10]`，任何固定 `k` 最多只得 **5/10**。其中 `k=5` 與 `k=7` 各5/10，其餘8種全是0/10。先前腳本第一次運行曾不正確地預期每個位移都是5/10；已依反證實際值修復，最終才納入正式 PASS 結果。這表示不可以因十變曜整齊循環，就認為所有取曜也只要一個十位旋轉。

**第二型別閘：同書官星≠官星貴人宮位。** 同卷38a〈論官星貴人歌〉又說「如甲以辛為官，辛祿在酉是也」。這裡甲→辛仍用同一「正官干」上游，但查的是**正官干祿位／地支酉**；32a查的是**辛化祿古曜炁**。可寫成：

```
年干甲 → 正官干辛 → 變曜母表 → 古曜炁
年干甲 → 正官干辛 → 干祿位置表 → 地支酉
```

因此，**兩條程序共用中介值「辛」，但輸出型別不同**。這是檢索源流時比單一漂亮位移公式更有價值的模型：要找的是原文是否明文指定「選哪張輸出表」，而非事後把兩種表值任意拼接。

### C. 安紫微與天府：除法、奇偶、模十二及鏡射

既有安星公式仍可清楚記成：`d`＝生日（1..30），`b`＝五行局數（2..6），以**寅=0**：

```
q=ceil(d/b)
e=q*b-d
紫微宮=(q-1+(e為偶數?e:-e)) mod12
天府宮=(-紫微宮) mod12
```

對`5局×30天=150`種形式輸入，閉式公式與逐步起宮程序皆相等；水二局30項表、天府鏡射12項及固定點寅／申再核對。這主要屬**數學重算既有安星法**，沒有證明十變曜母環是安紫微數學來源。

嚴格區分：若把模十序位單靠**保加法群同態**的映射送入模十二序位，`f(1)=a` 必須滿足 `10a≡0 mod12`，故只有 `a=0,6`，不能把十位完整一對一嵌入十二位。這**只排除單一純加法同態**，並不排除先用五虎遁、生年干／宮位／五行局等輔助條件，再做有依據的跨表運算。

## 五、對成熟化忌唯一有效的下一個型別化問題

我們已見古書容許：

```
年干 g → 官干 h(g) → 查A表得「曜體」
年干 g → 官干 h(g) → 查B表得「地支」
```

這證明**共享中介參數、但由目標表決定結果型別**的程序真實存在；比「所有星曜都只做模十位移」精確。

但尚**未**見：

```
年干 g → 取已得年度囚身份的古曜 A(g)
       → [古文特定的表格選擇／跨曜承接指令]
       → 指定固定紫微星 B(g) 取得同一年化忌身份
```

尤其癸年仍有`囚炁→固定貪狼`的關卡；不准拿`同名`、`共享陰陽`、`宮位偶然同位`、`有條件吉凶評價`冒充該中介。
