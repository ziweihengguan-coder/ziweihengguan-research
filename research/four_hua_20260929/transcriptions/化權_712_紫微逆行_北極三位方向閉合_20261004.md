# §712 化權816：北極三位定scope，紫微逆行定方向——8→1→6的方向取得獨立古法來源（2026-10-04）

## 一、本輪問題

§711 已經把「洛書8條線」候選先驗整個拿掉。

現在三數集合不再由研究者先選，而是由前1581古文直接給出的北極作用域決定：

[
{亥,子,丑}
leftrightarrow
{6,1,8}
]

因此最後只剩一個問題：

> 在這三個位置上，為什麼是成熟權所需的 **8→1→6**，而不是反方向 **6→1→8**？

§705原本靠《捷覽》同行四化不重，從兩方向中只留816/right。

§712改查是否存在**獨立於四化輸出的古法方向規則**。

答案是：1581《捷覽》自己明文提供了「紫微系逆行」。

## 二、亥子丑的自然十二支方向

十二支正常次序：

[
子	o丑	o寅	o卯	o辰	o巳	o午	o未	o申	o酉	o戌	o亥	o子
]

所以北側連續三支若按正常順序，就是：

[
亥	o子	o丑
]

按九宮方位坐標：

- 亥＝乾6；
- 子＝坎1；
- 丑＝艮8。

故正常方向：

[
oxed{6	o1	o8}
]

其反方向則是：

[
丑	o子	o亥
]

即：

[
oxed{8	o1	o6}
]

所以816並不是任意把三個數排成漂亮順序；它就是北極三位的**逆向支序**。

## 三、《捷覽》對紫微系明文：「紫微天機星逆行」

1581《捷覽》卷一〈布南北二斗諸星訣〉：

> 紫微天機星逆行，隔一陽武天同情。又隔二位廉貞位，空三便是紫微星。

這裡「逆行」不是抽象吉凶象義，而是安星程序的實際方向：

- 紫微為anchor；
- 天機依紫微逆行；
- 後續太陽、武曲、天同、廉貞保持該方向；
- 經隔一、隔二、空三後回到紫微。

§702～§704、§709已證這整套是實際可執行的群組安星operator。

因此當§706已由「紫微＝北斗之主宰」與前1581北極古法把作用域鎖在亥子丑時，紫微自身的明文方向就是：

[
	ext{逆行}
]

套到北側連續三支：

[
亥	o子	o丑
]

之逆：

[
oxed{丑	o子	o亥}
]

換成九宮數：

[
oxed{8	o1	o6}
]

## 十、歷史證據邊界

§712很強，但仍不可偷跨最後一句。

可以說：

> **化權816的scope與orientation現在可以分別由古代文本中的北極三位與紫微逆行取得；不再需要先假定洛書8線，也不必依賴成熟權target選方向。**

可以說：

> **把上述古法operator套到§700的三carrier pool，一次局部循環便精確生成成熟權10/10。**

但仍不能說：

> **古書明文規定「四化依紫微逆行於亥子丑重掛」。**

因為「把紫微安星方向沿用到化權pool」仍是最後的跨技法應用橋。

不過這個橋的自由度現在已很低：

- scope不是猜的；
- orientation不是猜的；
- group movement不是新造的；
- local cycle不是target選出的；
- 成熟target只用在最後驗證。

## 十一、下一步§713

現在最值得做的是**最終消融矩陣**，不再繼續堆古文。

逐一拿掉：

1. 祿前移骨架；
2. 廉退紫入；
3. 北極亥子丑scope；
4. 紫微逆行orientation；
5. 主星帶整群operator；
6. cycle回首；
7. 同行四化不重。

量化每一層拿掉後剩多少候選、是否仍能唯一得到成熟權。

目標是回答：

> **究竟哪些條件是「生成必要條件」，哪些只是獨立驗證，哪些可以完全刪除？**

如果§713顯示最小充分鏈只需：

> pool更新＋北極scope＋紫微逆行＋local cycle

即可唯一生成成熟10/10，而同行不重與洛書8線都只屬validation／可刪先驗，那化權重建就可以正式進入最終總結階段。
