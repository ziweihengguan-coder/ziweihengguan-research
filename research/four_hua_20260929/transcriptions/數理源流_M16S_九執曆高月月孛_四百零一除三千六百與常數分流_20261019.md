# 數理源流 M16-S｜《九執曆》高月＝月球遠地點、九與六十的有理數速率及中月疑文守門（2026-10-19）

> **研究主線為 T1299《宿曜經》×《九執曆》月望宿的來源端算法。** 本輪獲得可明確辨認的後世專業術語旁證：《清史稿》顧觀光傳直指「高月者即月孛，月藏者即月引數，日藏者即日引數」。將卷104〈推高月章〉「積日除九得度」及「積日除六十得分」**按取整商、60分進度的條件讀法**，得到高月遠地點的日均運行**401/3600度／日**，相應有理數模型周期**1296000/401≈3231.92020日**；並以原文兩組差常數作三種未校定分支。新增JS **35/35 PASS**（計算、邊界與拒絕無證月宿之型別負控；非35份獨立史料）。**未完成**原書日期→中月→高月→月藏→定月→27宿的唯一校定復原，無T1299跨書承接明文；§816、§817、§818續OPEN。

## A. 原始證據與分級

2. **《清史稿》卷507〈畴人二·顧觀光〉**：[維基文庫](https://zh.wikisource.org/wiki/清史稿/卷507)、[識典古籍對應頁](https://www.shidianguji.com/book/LS0025/chapter/1kt9610gqmolo)，稱「其所謂高月者即月孛，月藏者即月引數，日藏者即日引數」。此乃**後世曆算家的直接文字解釋**（LATE_COMMENTARIAL_TERM_IDENTIFICATION），可以辨識高月為月球遠地點（apogee）參數、月藏為月球均近點角相關的引數；**不能用清代觀念代替唐代原文公式細節**，尤其不可因「月孛」一詞便認同七政星命的月孛曜和斗數化囚年度身份為直接同一運算。

## B. 〈推高月〉分解：兩道除法的月孛速度指紋

書的角度制是 **1相=30度、1度=60分、12相=360度**。令D是從本書「積日」取得、**但曆元與欠夜待校**的日數；依〈推高月〉將度／分進位，忽略細於一角分而未見明文處理的零頭，可寫為研究者候選：

```text
9除的度數    = floor(D/9)
9除餘數折分  = floor(60*(D mod 9)/9)
60除的角分   = floor(D/60)                [取商讀法；待校]
運行部分（分）= 60*floor(D/9) + floor(60*(D mod 9)/9)
               + floor(D/60)
             = floor(60D/9) + floor(D/60)
```

因此其**不先截分的有理數運行率**為：

```text
1/9 度/日 + 1/(60*60) 度/日
= (400+1)/3600 度/日
= 401/3600 度/日
= 401/60 角分/日 ≈ 6.6833333333 角分/日
360 / (401/3600) = 1,296,000/401 ≈ 3231.9201995 日/周
```

**證據定位**：卷104明見「9」「60」兩道運算；上式是對「六十除之得分」取**商而非餘**、把單位作角分後的**數學後果／條件復原**，不表示唐書逐字寫了「401/3600」或精確的3231.9202日。原文每次整除另有尾數處理不清，故候選逐日整分與不截分的理論值，可能相差0或1角分；本次對0–999日逐日驗證**差值必為0或1分**。

**負控**：若錯把第二道「積日以六十除」所得當D mod60角分，59→60日的高月運行部分就發生人為負跳；此與應連續緩行的遠地點不合。此**有力排除粗糙的錯誤程式讀法**，卻仍不是獨立史料的取商校刻。

## C. 高月「十八相二十六度四十一分，一相十三度四十五分」需逐項保留

現存電子字句同時列**18相26度41分**與**1相13度45分**，前者甚至大於12相一周。不能擅自選某一數字作唯一「原書高月初值」，也不能因後世天文吻合就指定合用。以周天360度／21600角分，作三個**純敏感度的假設讀法**：

| 未校定分支 | 角常數（周天歸一後） | 身份 |
|---|---:|---|
| FIRST：只加18相26°41′ | 206°41′ | 只是假設語句分層 |
| SECOND：只加1相13°45′ | 43°45′ | 只是假設語句分層 |
| BOTH：兩者相加 | 250°26′ | 只是假設語句可合加 |

**三個都是有疑候選**，不是三份傳本，亦不是可隨意選正解的三派古法；其校勘優先於天文擬合。

## E. 中月仍是無法跳過的缺口：不可將「高月」當「定月」

四庫系轉錄〈推中月〉可見「置小餘重張位下位二十五餘之」及「置自入月已來所經日，以十二除之，以三十除之，得相不盡為度」。兩句**不能無證改成研究者猜想的乘／除次序**：
- 「二十五餘之」的運算動詞不明，且小餘應採何基準日型尚待校；
- 對於例子自入月五日，「12除之」若孤立照字面即商0，與後續「30除得相」的輸出意義不明。可以列疑字待查，不可自行把「除」改作「乘」當定本。
- 〈推月藏〉明文要求**中月減高月**；兩者即使其中一方高月可作速率候選，依然不能計出**已核月藏**。
- 定月還需六段係數77／71／61／47／30／10與0–3相的折返、進分校核。未有可溯源唯一中月、月藏，不能跨過此關輸出月球定月與27宿。

**雙重來源邊界**：本書內部「置定月，通作分，以八百除之」→27等宿為**DIRECT_CALL（M13-S已核）**；T1299「先須知月望宿日」沒有指名九執，故《九執》宿→T1299望宿**NO_PROVEN_INTERTEXT_CALLER**。角度起點、望十五日所取時刻、曆首657／714的實時對接、宿界均有待校。
