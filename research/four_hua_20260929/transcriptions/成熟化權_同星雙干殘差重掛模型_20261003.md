# 成熟化權「同星雙干」殘差重掛模型（2026-10-03）

## 1. 問題

§503–505 已經證明：把穩定的成熟／早期祿欄

> 甲廉、乙機、丙同、丁陰、戊貪、己武、庚陽、辛巨、壬梁、癸破

依《星學大成》1563 已見的「祿→權前移一干」算子處理，可得到成熟化權 7/10：

> 甲破、乙廉、丙機、丁同、戊陰、己貪、庚武、辛陽、壬巨、癸梁

成熟實表則是：

> 甲破、乙梁、丙機、丁同、戊陰、己貪、庚武、辛陽、壬紫、癸巨

殘差只有乙、壬、癸。

本輪不再重做「祿→權」本身，而是專門問：

> **古／成熟文本中的星情年干語，是否留下足以描述乙、壬、癸三殘差如何重掛的語言痕跡？**

## 2. 成熟支星情存在大量「同一顆星綁祿干＋權干」的雙干句

以成熟祿／權表反向按星整理：

| 星 | 祿干 | 權干 |
|---|---|---|
| 破軍 | 癸 | 甲 |
| 天梁 | 壬 | 乙 |
| 天機 | 乙 | 丙 |
| 天同 | 丙 | 丁 |
| 太陰 | 丁 | 戊 |
| 貪狼 | 戊 | 己 |
| 武曲 | 己 | 庚 |
| 太陽 | 庚 | 辛 |
| 巨門 | 辛 | 癸 |
| 紫微 | — | 壬 |
| 廉貞 | 甲 | — |

目前已核的成熟支／平行文本中，有七顆星出現「恰好把祿干與權干綁在一起」的明確雙干句：

- 破軍：癸／甲
- 天梁：壬／乙
- 天同：丙／丁
- 太陰：丁／戊
- 貪狼：戊／己
- 太陽：庚／辛
- 巨門：辛／癸

其中天機、武曲目前只找到包含目標雙干的較大集合，不升格為「精確雙干」。

> 辰戌宮和平，丙丁生人利達。

《深谷秘訣》另有太陽午宮：

平行《春岡藏本－秘傳紫微》亦保存：

但 §79 已把《春岡藏本》年代降級，故它只能證文本平行，不可作早年錨點。

## 3. 不是所有「某星＋兩干」都能解作祿權：先做負控

這種配對極容易產生事後挑選偏差。

同一成熟支星情中，還存在大量因：

- 廟旺落陷；
- 祿存位置；
- 羊陀；
- 三方四正；
- 同宮星曜；
- 地支宮位

而成立的其他年干組合。

例如太陰另有丙、戊等宮位條件；武曲在不同宮位可見丁己庚、丁己甲庚、乙辛、壬戊等多組。

所以不能建立：

> 「只要某星條文同時出現兩個年干，那兩干就是該星祿／權。」

本輪只把「精確雙干且恰與同星成熟祿／權一致」列為**成熟支文本壓縮線索**，不把它當普遍規則。

其中太陰「六丁六戊生人，化科權祿吉」最有辨識力，因原句直接把雙干和化曜語彙放在一起，證明至少部分雙干句確實可能由四化條件壓縮而來。

反過來也正因如此：

> **這些雙干句有可能是成熟四化表的下游表述，而不是成熟四化表的上游來源。**

## 4. 真正有新信息的是兩個非一干平移殘差

七個正常位置本來已可由 §503 的祿→權一干算子得到：

- 癸破 → 甲破
- 乙機 → 丙機
- 丙同 → 丁同
- 丁陰 → 戊陰
- 戊貪 → 己貪
- 己武 → 庚武
- 庚陽 → 辛陽

所以破、同、陰、貪、陽等雙干句即使吻合，也只是在文本層重述既知算子，不解新的歷史問題。

真正重要的是：

### 天梁

祿欄：
> 壬祿＝天梁

一干平移預測：
> 癸權＝天梁

但《全書》天梁星情另把：
> **壬、乙**

綁在同一「財官格」。

若把「同星雙干」當作成熟支內部的 companion-stem 規則，則：

> 天梁：壬祿 → 乙權

恰好修正第一個殘差。

### 巨門

祿欄：
> 辛祿＝巨門

一干平移預測：
> 壬權＝巨門

但《全書》巨門星情反覆把：
> **辛、癸**

綁在同一吉格。

同樣採 companion-stem：

> 巨門：辛祿 → 癸權

恰好修正第二個位置殘差。

這兩次重掛聯立後，會發生一個很關鍵的結構效果：

1. 天梁由預設癸位移到乙；
2. 乙位原本由「甲廉祿→乙廉權」佔據，因此廉貞被擠出；
3. 巨門由預設壬位移到癸；
4. 壬位因巨門離開而空出。

於是不用另外指定「廉退」與「壬空」：

> **兩個殘差重掛本身就同時產生「廉貞退出」與「壬位空缺」。**

再把 §639 已獨立得到的 add selector：

> 太極／紫微＝主宰、權屬命／主事層

放入唯一空位壬，即得到：

> 甲破、乙梁、丙機、丁同、戊陰、己貪、庚武、辛陽、壬紫、癸巨

完整成熟化權 10/10。

## 5. 可重跑模型

新增：

- quan_same_star_stem_pair_textual_audit_20261003.js

模型規則：

1. 以穩定祿欄為母表；
2. 預設採 §503 的一干前移；
3. 若某祿carrier已有「精確同星雙干」文本，則以另一干為該星的 companion target；
4. 若 companion target 與純一干預設衝突，直接文本配對優先；
5. 被衝掉的預設carrier退出；
6. 唯一空位由獨立 add selector 的紫微補入。

實跑：

### 完整模型

精確配對覆蓋七星：

- 破軍 癸→甲 ✓
- 天梁 壬→乙 ✓
- 天同 丙→丁 ✓
- 太陰 丁→戊 ✓
- 貪狼 戊→己 ✓
- 太陽 庚→辛 ✓
- 巨門 辛→癸 ✓

天機、武曲因只見較大集合，保留基礎一干算子：

- 天機 乙→丙
- 武曲 己→庚

結果：

- 唯一 collision：乙位＝廉貞(default) vs 天梁(exact-pair)
- 直接配對優先後：廉貞退出
- 唯一空位：壬
- 紫微補壬
- 成熟權表：**10/10**

### 紫微加入前

結果已是：

> 甲破、乙梁、丙機、丁同、戊陰、己貪、庚武、辛陽、壬空、癸巨

即 9/10，唯一缺壬紫。

### 消融

移除「天梁壬乙」：
- 9/10
- 乙仍回廉貞
- 成熟乙梁失敗。

移除「巨門辛癸」：
- 8/10
- 壬仍被巨門佔住；
- 唯一空位改成癸；
- 若紫微機械補空位，反變成癸紫，錯兩格。

兩個殘差配對都移除：
- 回到完整十星的一干平移；
- 沒有carrier退出；
- 沒有空位；
- 紫微 add 無處可插。

因此兩個殘差文本條件都不是裝飾項，而是整個「廉退＋壬空」結構的必要項。

## 6. 年代追查：目前不能把這個模型前推成古代生成口訣

本輪專查較早／舊型《紫微數》《玄藪》：

- 白衣＝巨門：已有「獨守則主兵權為將」「白衣權柄發」等權柄資格；
- 進神＝天梁：已有「旺運加官進職」「官祿有名聲」等官權資格；
- 五鬼＝破軍：已有癸生人、癸甲庚等較寬年干組合。

所以舊型文本確實保存：

> **carrier為什麼有資格承權**

但全文搜尋目前沒有核到：

- 壬乙綁進神／天梁；
- 辛癸綁白衣／巨門。

公開《中天太極紫微數秘訣》轉錄全文檢索「壬乙」「辛癸」「癸辛」均無命中；本機乙亥字人工校讀與OCR亦未核到這兩組 residual pair。

《深谷秘訣》目前：
- 辛巨門化祿有直接句；
- 沒找到癸＋巨門的同型句；
- 也沒找到乙／壬＋天梁的雙干句。

《春岡藏本》有巨門「廟則癸辛生人吉」，但 §79 已降級為旁系傳本，不能提供前1581年代錨點；天梁條也未見壬乙雙干。

所以目前最嚴格的年代結論是：

> **「壬乙天梁／辛癸巨門」可以把成熟化權三殘差壓縮成極漂亮的文本化重掛模型，但目前只在成熟支／晚期平行傳本得到清楚見證；尚無前成熟表的獨立年代證據。**

因此不能寫成：

> 「成熟化權就是古人依這兩句生成。」

只能寫成：

> **成熟支內部存在與成熟權表完全同構的 companion-stem 語言；它可作 selector 的文本相容模型，並把 §503 的7/10、一出一入星池與 §639 紫微add 整合成10/10。**

## 7. 本輪真正的價值

此前成熟化權模型分成：

- 祿→權算子：7/10
- remove selector：廉退
- add selector：紫進
- position selector：全局約束唯一

本輪給出另一種更接近「古書語言」的壓縮方式：

> **祿母表一干前移**
> → **天梁用壬乙同星配對改掛乙**
> → **巨門用辛癸同星配對改掛癸**
> → **廉自然被擠出**
> → **壬自然空出**
> → **紫微依主宰／權屬命條件補壬**

這條鏈把原本看似獨立的：
- 乙梁
- 癸巨
- 廉退
- 壬空
- 紫進

連成同一個局部重掛事件。

但歷史證明仍差最後一塊：

> **找到可可靠定在成熟四化表以前的「壬乙天梁」或「辛癸巨門」同型年干語，或者找到直接說明「由祿星之某干轉權至配干」的操作句。**

這應成為下一輪最高優先級搜尋目標。
