# 化忌：年干功能主曜續查、催官取日與雙輸入路由

日期：2026-10-09。承接同日〈原干十變角色取主與犯受〉；依使用者要求，追年干獨立功能曜再接有據取犯／取受，不以等一條直接安忌口訣為唯一途徑。

**結果：年干功能錨可以明確登記，催官原文也確有祿主木配日的例；但本輪130條固定組合沒有完整化忌解。下一輪應保留「原干＋功能曜」雙輸入，不能只剩功能曜後再找一元換表。**

## 一、先查舊進度，來源與新測試分開

《星學大成》天元祿、天權、官星、催官、正祿神、喜神等列，前輪已見，不報成本輪新發現。§784–785及更前記錄也已知道權屬命宮及管庫事類；本輪沒有重新宣布破解一般角色轉掛。

10-08的24表×干操作／閉包，測過直接列與不同干再查表；本輪改做**功能錨接相對關係、同干角色篩選與催官配對兩端**，但仍有代數重疊：

- 天元祿接催官，化簡就是舊催官原列。
- 天權接催官，化簡是前一干查催官。
- 天官接催官，化簡是正官干查催官。
- 注文喜神接催官，化簡是逆讀催官列。

程式逐項驗證四種等價，故130條是本輪登記組合數，**不是130條全新或相互獨立的古算法**。

## 二、哪些功能曜可由年干獨立確定

| 功能錨 | 依據／算法 | 必須保留的限制 |
|---|---|---|
| 天元祿主 | 十干祿環L | 官祿功能曜，不等於實際命宮主 |
| 天權／命管庫 | `F(g,9)` | 原文屬命宮，不自動取代按命宮／宿度所定的主曜 |
| 天官 | 正官干再查L | 與官祿宮主分層，承前輪 |
| 催官 | 甲金乙水丙日丁羅戊木己炁庚孛辛土壬月癸計 | 古表及配對有文，未獨立推得整張催官表的唯一生成式 |
| 正祿神 | 甲兼木孛，餘干有原列 | 甲必須保留雙曜，不因目標要日便只取木 |
| 喜神 | 注文逆祿 `L(9−g)` | 歌辛水／注辛木分成兩支，不合併校字 |
| 仁元 | 甲乙木、丙丁火、戊己土、庚辛金、壬癸水 | 只有五種曜體狀態，原干不可丟掉 |
| 祿元：定宮度原列 | 木火水日水日水金水土 | 原列壬水；宿度仍是額外資料，僅取曜體會合併多干 |
| 祿元：寄祿宮主型 | 寄祿支後依七政宮主，木火水日水日水金木土 | 壬亥取木；是甲寅木原例連用宮主表的派生型，不能說卷二逐干原列如此 |

喜神兩支分列，合計10個來源分支。正祿神甲雙曜以集合保存，沒有為算分先拆出「甲木版」再挑較好者。獨立印星池不作本輪輸入。

來源：[《星學大成》卷一](https://zh.wikisource.org/zh-hant/星學大成_(四庫全書本)/卷01)、[卷二](https://zh.wikisource.org/zh-hant/星學大成_(四庫全書本)/卷02)。原段行號、節錄與全文檔SHA-256收入結果JSON。

不是年干單輸入的法，另列而未偷填：四元壽元須完整干支納音，馬元／地驛須年支，天乙玉堂型貴元另有晝夜規則，科甲須命宮及對宮，另一種祿元逆數法須太陽宮、生時、本年支。卷二三元法的「人元壽」與四元法的「壽元」也不能只因同字混為一表。

## 三、催官是有據的取日接點，卻不是已解的母環公式

卷一446–452行明舉四個祿主與催官配對：

`火 → 金；孛 → 水；木 → 日；金 → 羅`。

其後解釋催官表不取火，因有太陽。這足以說古星命功能表可以把日納入，不能再籠統說任何以祿主為起點的古法都絕不可能取日。

但仍須分清：

1. 原文給出催官表及四個具體配對。
2. 本輪可把它整理成 `Φ催(x)=C[L⁻¹(x)]`，定義域是祿環十曜；逆向為 `Φ催⁻¹(y)=L[C⁻¹(y)]`，定義域是催官表十曜。
3. **這是有原表依據的配對查詢，不是已從L單獨推得C。** 把另一種功能曜再解讀為祿主以查Φ催，還是明列跨功能連用假說，沒有古文指定它生成化忌。

「相為催剋」也不能直接定義成一律取剋我者：甲例火主配金，是主克催；丁例金主配羅，是催克主。兩個原例方向已相反。這排除了把催官全表簡化為同向五行克序的讀法，未排除仍保留原干、陰陽等資料的更深生成規則。

### 甲日的三條連用測試

| 研究連用 | 甲結果 | 乙結果／其他關鍵限制 |
|---|---|---|
| 年干仁元 → Φ催 | 日 | 乙也取木，因此也得到日，無法得到乙月 |
| 定宮度祿元曜體 → Φ催 | 日 | 乙火得到金；丙戊庚壬水、丁己日等仍合併或超出定義域 |
| 正祿神 → Φ催 | 日、水 | 甲原文兼木孛，兩端各配日、水，沒有依據只留日 |

仁元接Φ催的完整列是 `日日金金木木羅羅孛孛`。正祿神接Φ催是 `日水｜孛｜月｜計｜木｜金｜羅｜土｜∅｜炁`；甲格「日水」為雙解，壬原正祿神日不在L，∅保留為此讀法定義域未覆蓋，不擅拿火代日。

因此甲日已有局部有據連用入口，但**尚未唯一導出甲日，更沒有導出完整忌**。

## 四、同輸入異輸出的代數限制

若只留下功能曜P，再接一元單值函數h(P)，則相同P必須有相同輸出。以下四個來源分支都與兩版成熟忌的逐干差異衝突：

- 仁元：甲乙同木，丙丁同火等，共5狀態。
- 定宮度祿元只留曜體：丙戊庚壬同水、丁己同日，共6狀態。
- 寄祿宮主型：甲壬同木、丙戊庚同水、丁己同日，共6狀態。
- 喜神歌辛水：丁辛同水，兩干成熟忌卻不同；雖有9狀態，也不能單靠狀態數說G1九曜或可成功。

程式逐版列出碰撞組並驗證衝突。**此證明只排除丟掉g後的一元後處理。** 若算法仍接收 `h(g,P)`，或保留宿度／其他古文允許資料，不能用這個碰撞證明否定它。因此「保留原干」不是任意添加自由度，而是避免本來可用資料被提前抹掉；但h的條件仍須獨立古法支持，不能逐干照目標指定。

## 五、130條組合與結果

10個功能錨，每錨固定接13種終端，共130條：

- 本餘犯者、合日月放寬的餘奴犯者。
- 剋我難星、兼日月情境的難星。
- 我所克的仇、制難的用。
- 反取其所犯者。
- 忌化囚、忌化福、難化祿、刑星化暗四個同干角色條件。
- Φ催正向、逆向再讀。

恩難用仇忌術語據[《華天五星》卷六](https://www.shidianguji.com/zh/book/CADAL02093863/chapter/1lazcaf2v25of)及前輪登記。五行兼餘、跨書術語連用與不同日月觸發合圖皆明列研究假說；這些是部分古典關係，並非無例外物理定律或完整盤面凶吉法。功能錨作相對關係的「我」亦是研究連接，不默稱它就是實際命主。

沒有使用福欄、成熟權科、獨立印星池、清《乾元秘旨》，也沒有按答案挑分支、補空格或逐干換鏈。

最高可達的鏈是正祿神接放寬剋我者：G0含丁己辛壬癸的目標；G1另含庚。**該鏈只有辛唯一正確，其餘命中格仍多解**，所以不是5或6干已經導出，也不稱其為歷史來源。最多唯一正確2干出現在其他鏈，包括注文喜神再讀催官的乙丁；後者與舊逆讀催官族等價，不算新突破。

年干天官與衝干對祿的甲炁忌金、庚金忌羅另作來源正控，不把已知算式重新報成新發現。

## 六、接下來如何縮小問題

年干功能錨不缺，缺的是有依據的**雙輸入取法**：在保留原干g及功能曜P的情況下，如何選相對角色、取哪一端、何時容許日月。

較具體的兩個方向：

1. 追催官「相為催剋」的生成原理，尤其甲火金與丁金羅方向為何反轉，是否由原干陰陽、正偏身份或本餘區分固定，而非把催官現成表換成新終極母表。
2. 追年干天官／天元祿的制難、傷官、餘奴條件，尋找能固定 `h(g,P)` 的古例或通則；先驗正控與定義域，再比較成熟忌，不依命中決定條件。

四元壽元、貴元等多輸入法仍可查，但不能刪去納音、年支或晝夜後聲稱年干唯一。
