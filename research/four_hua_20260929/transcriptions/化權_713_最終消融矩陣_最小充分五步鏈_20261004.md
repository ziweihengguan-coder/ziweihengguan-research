# §713 化權最終消融矩陣：最小充分重建鏈收斂為五步（2026-10-04）

## 一、目的

§712後，化權816的scope與orientation已分別取得古法來源：

- scope：北極／拱北 → 亥子丑；
- orientation：紫微系 → 逆行；
- group operator：主星若動則眾星奔馳；
- cycle／回首：古典安星程序本身已有閉合回首語法。

§713不再新增古文，而是做最終消融：

> **逐一拿掉每個構件，看成熟權是否還能生成；並區分哪些是生成必要條件、哪些只是validation、哪些先驗可以完全刪除。**

新增：

`quan_713_final_ablation_evidence_matrix_20261004.js`

已實跑通過。

## 三、消融1：拿掉「祿母表前移」骨架

若不先做：

[
權(g)approx祿(g-1)
]

而直接從祿表出發，再照樣做廉→紫與北極816局部循環，成熟權匹配：

[
oxed{0/10}
]

這證明：

> 在目前這個模型類中，祿母表前移不是裝飾性的背景相關，而是提供整個成熟權七個穩定格的必要骨架。

---

## 四、消融2：拿掉「廉退紫入」

先做祿前移，但不把廉貞替換為紫微，再做同一816逆行cycle。

結果：

[
oxed{9/10}
]

唯一錯格是壬：

- 模型得到壬廉；
- 成熟表為壬紫。

所以「廉退紫入」的功能非常精確：

> 它不是重新改整張權表，而是把局部三carrier pool中的舊carrier廉貞換成紫微；經後續循環後，正好把成熟壬紫補上。

這也解釋為何單獨看pool update時仍只有7/10——它的效果要到局部cycle後才顯現。

## 五、消融3：拿掉局部cycle movement

做到：

1. 祿前移；
2. 廉退紫入；

但不執行816局部重掛。

結果停在：

[
oxed{7/10}
]

即既有baseQuan：

- 乙紫
- 壬巨
- 癸梁

而成熟需要：

- 乙梁
- 壬紫
- 癸巨。

所以局部cycle正好只處理最後三格。

## 六、消融4：同一北極scope，但把紫微逆行改成順行

[

=
6	o1	o8

若不用《捷覽》紫微「逆行」，而改採此順行方向，結果：

- 成熟權匹配：**7/10**
- 同干四化不重：**false**

所以：

[
oxed{
北scope本身不足
}
]

真正成熟方向必須是：

[
oxed{
丑	o子	o亥
=
8	o1	o6
}
]

這與紫微系「逆行」一致。

## 七、消融5：拿掉cycle回首

若只做開放路徑：

[
8	o1	o6
]

但不做最後：

[
6	o8
]

則三個carrier不再形成置換：

- 一個carrier丟失；
- 一個carrier重複；
- carrier multiset不保存。

實跑：

`carrierMultisetPreserved=false`

所以若模型要求：

> 三個既有carrier只重掛、不新增、不遺失，

則三位movement必須閉合：

[
8	o1	o6	o8
]

這與古典安星回首／閉環語法相容。

## 八、selector消融：洛書8線完全不需要

§711已把候選擴大為：

- 任意三數集合：84；
- 兩向cycle：168。

本輪再確認：

### 不限制任何三線

168個候選中，直接完整命中成熟權的輸出只有：

[
oxed{1}
]

注意這個1只是事後validation，不作selector。

### 只加古文北極scope

直接從168候選縮成：

[
oxed{2}
]

即同一{1,6,8}的兩方向。

### 再加紫微古文逆行

縮成：

[
oxed{1}
]

而該1正好成熟10/10。

所以：

[
oxed{
「洛書8條直線」不是生成必要條件
}
]

可永久從最小模型刪除。

洛書／九宮只保留：

> 亥、子、丑方位轉成6、1、8的座標字典。

## 九、「同行四化不重」也可從生成鏈降級

北極scope給兩方向後，有兩種不同的方法可以選出成熟方向：

### 方法A：紫微系逆行

[
亥子丑
overset{逆}{longrightarrow}
丑子亥
=
816
]

候選：

[
2	o1
]

### 方法B：《捷覽》同行四化不重

同樣：

[
2	o1
]

而兩者留下的是同一方向。

因此§712後，「同行四化不重」不再是最小生成鏈必需條件。

它更適合定級為：

> **獨立target-free validation。**

這反而提高模型可信度：

- 古文方向operator獨立選出816；
- 四化格式約束又獨立驗證同一方向；
- 成熟10/10再作第三層最終validation。

## 十、依賴分類

### A. 生成必要條件（在目前模型類內）

1. **祿母表前移一干**
   - 提供成熟權7個穩定格。

2. **廉退紫入**
   - 把局部pool的廉貞carrier換成紫微。

3. **北極亥子丑scope**
   - 將任意三數空間縮成實際古文三位。

4. **紫微逆行orientation**
   - 不靠成熟target，也不靠四化同行格式，直接決定816方向。

5. **閉合三carrier cycle／group movement**
   - 保存carrier集合並完成三格重掛。

### B. validation-only

1. **成熟權10/10**
   - 只在最後比對；
   - 不參與selector。

2. **《捷覽》同行四化不重**
   - 可獨立選到同一方向；
   - 但在有「紫微逆行」後，不再是生成必要條件。

### C. 可刪除先驗

1. **洛書8條直線候選宇宙**
   - §711已證完全不需要。

## 十三、下一步§714

現在最有價值的工作不是再加一層公式，而是做**化權最終證據矩陣／研究總結**：

把每個步驟分為：

- A：古文直接；
- B：跨文本同型操作；
- C：現代形式化；
- V：獨立validation；
- U：尚未直證。

並把：

> 舊七欄權 → 祿母表前移 → carrier更新 → 816局部重掛 → 成熟權

做成一張最終可審計鏈。

§714之後若沒有新的早期異本生成小註，化權主線可以暫時封板，把研究資源轉回「四化整體統一公式」或科／忌與權的共同operator比較。
