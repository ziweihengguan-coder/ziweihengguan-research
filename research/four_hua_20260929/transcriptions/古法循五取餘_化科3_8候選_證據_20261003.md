# 古法「循五取餘」與化科3／8候選：文本證據摘錄（2026-10-03）

## 一、研究問題

§656 的化科候選目前使用：

m(e) = (河圖生數(e) + 3) mod 5

並把結果【4,0,1,2,3】解讀成成熟化科五行十格的出現次數：
【水4、火0、木1、金2、土3】。

歷史上真正需要證明的不是「古人會除法」，而是分三層：

1. 古術數是否有【以五為週期取餘】；
2. 餘數是否能直接決定【五行類別／五位位置】；
3. 餘數是否曾被直接當成【某類的出現次數／名額】。

本輪找到第1、2層的強證據；第3層仍未找到。

---

## 二、北宋《武經總要》：五除取餘 → 直接作五宮循環的位置selector

來源：
- 《武經總要》後集卷十八／太乙十精。
- 作者：宋曾公亮、丁度等奉敕撰。
- 公開：
  - https://zh.wikisource.org/zh-hant/武經總要/後集/卷十八
  - https://www.shidianguji.com/zh/book/SK1390/chapter/1l94vald3plie

關鍵原文：

> 六曰五行，以五行小周法五除之，不盡者，命起一宮次八宮三九七算外，即五行所在。

操作可形式化為：

【積數】
→【除5】
→【取不盡之餘】
→【按五宮固定次序數到餘數】
→【決定五行所在】

這是高度相關的古代先例，因為餘數不是只作抽象標籤，而是直接成為循環步數／position selector。

證據等級：A（古籍明文算法）。

限制：
它決定的是【五宮位置】，不是五行在十格表中的【出現次數】。

## 三、南宋《紫巖易傳》：配數五而數之 → 餘1～5直接定五行

來源：
- 張浚《紫巖易傳》；四庫提要記第二稿紹興戊寅（1158）定本。
- https://www.shidianguji.com/zh/mid-page/7370076345235406898
- https://zh.wikisource.org/zh-hant/紫巖易傳_(四庫全書本)

關鍵原文：

> 以十干、十二支配數五而數之，餘一，火數也；餘二，土數也；餘三，木數也；餘四，金數也；餘五，水數也。

形式：

【干支配數】
→【以5為週期】
→【取餘1～5】
→【唯一映射五行】

這直接證明宋代易／納音數術中已有：

【mod 5 residue → 五行類別】

證據等級：A。

限制：
傳統餘數表述採1～5，不以0代表「無」；故不能直接替§656的火0次背書。

## 四、明萬曆六年（1578）萬民英《三命通會》：與成熟斗數定型時間幾乎同時，且作者正是《星學大成》萬民英

版本：
- 國家圖書館藏明萬曆六年戊寅（1578）刊本。
- 國圖書目：
  https://rbook.ncl.edu.tw/NCLSearch/Search/SearchDetail?HasImage=&SourceID=1&item=a8776bf009664f7a8de67d697186e322fDcyODE20.HwkhFZvyoK_b_gt8uDb5Xa7Nh9LYxzj5HEj4uWEtX6g_
- 卷一公開文本：
  https://www.shidianguji.com/zh/book/HY1521/chapter/1knwem2lozkty
  https://zh.wikisource.org/zh-hant/三命通會_(四庫全書本)/卷01

卷一納音法明載：

> 以五數除，不滿五者，作納音……

並逐列：
- 餘一水；
- 餘二火；
- 餘三木；
- 餘四金；
- 餘五土；
再依相生取最終納音。

原文還明確把這套算法解作：

> 此天地自然之數，河圖生數也。

這一點對本研究極重要：

1. 1578已有實體刊本，早於1581《紫微斗數捷覽》三年；
2. 作者萬民英亦撰《星學大成》；
3. 《星學大成》1563自序可核，且本研究已證其中保存【祿母環＋功能offset／十神selector】；
4. 同一萬民英文本群現在又能證明：
   【以5除 → 取餘 → 映五行】確實是他熟悉、保存並使用的古星命算法語法。

因此§656所用「循五取餘」不再是只有現代數學形式上的操作；在成熟斗數形成前後的同一星命作者體系中，已有非常接近的算法先例。

證據等級：A（算法存在）／B（與成熟四化創制可能共享語法）。

仍不能寫成：
【萬民英用此法製作成熟化科表】。

## 五、《星學大成》自身：餘數再用來決定行段

《星學大成》卷十五火星總龜算法有：

【以一終之數除之 → 不滿者為餘日 → 以餘日數去之 → 看在何段】

公開：
https://zh.wikisource.org/zh-hant/星學大成_(四庫全書本)/卷15

這不是除5算法，但它再次證明萬民英星學系統內：

【整週除去 → 餘數 → 進一步定位】

是正常的操作語法。

與《武經總要》太乙五行法、《三命通會》納音法合看，古星命／太乙常見的不是現代「mod」符號，而是：

【以某周法除之，不盡者為餘 → 以餘數定位／定類】。

## 六、對§656的證據升級與仍存缺口

### 已可升級

§656此前只敢說：
【m(e)=(生數+3) mod5 是現代數學候選；尚未找到古數法先例。】

本輪可改成：

> 【「循五取餘」以及「以餘數決定五行類別／五位位置」均已有宋、明古籍直接先例；尤其1578萬民英《三命通會》與成熟斗數定型年代極近，並明把除五取餘納音法連到河圖生數。】

因此：
- 「mod 5本身太現代」這個疑慮可以大幅降低；
- 「餘數作selector」已有A級古法先例。

### 仍不能升級

§656最關鍵的最後一步仍是：

【餘數值4、0、1、2、3】
→【解作水、火、木、金、土在十格中的出現次數】

目前尚未找到任何古書明文把一組循五餘數直接當成【五類名額／multiplicity】。

尤其：
- 宋、明納音法通常把整除5視作餘五／第五類；
- §656為了命中成熟科，需要真正的【0次火】。

所以【0作零名額】仍是目前歷史上最弱的一環。

## 七、目前最嚴格結論

可成立：

1. 北宋太乙已用【除5取餘 → 五宮位置】。
2. 南宋易／納音已用【五週期餘1～5 → 五行類別】。
3. 1578萬民英《三命通會》在成熟斗數定型前夕明用【以五數除 → 餘數 → 五行】，且稱其為河圖生數。
4. 萬民英《星學大成》另有【整週除去 → 餘數 → 行段定位】。

所以：

> 【§656的「循五取餘」具有強古法語法先例，不再是任意現代數學工具。】

但：

> 【§656把餘數直接解為五行在十干化科表中的出現次數，仍是本研究新增的橋接假說；目前沒有古籍直接證明。】

下一步只追最後一個缺口：
【古代術數是否曾把餘數／循環數用作五類的數量、名額或配置個數。】

## 八、南宋《周易輯聞》／朱熹《蓍卦考誤》：餘數本身就是實際配置的策數

本輪再找到比「餘數定類／定位」更接近§656最後缺口的古法。

### 1. 朱熹《蓍卦考誤》

原文明說：

> 歸奇於扐，言歸此餘數於指間也。

也就是揲蓍以四後留下的【餘數】，不是抽象標籤，而是實際把那麼多根蓍策歸置於指間。

形式：

【四揲】
→【得到餘1／2／3／4】
→【把該餘數所代表的實際策數歸置】

這是最直接的：

【remainder value → physical multiplicity】

證據等級：A（易學／筮法明文）。

公開：
https://www.shidianguji.com/zh/book/SBCK218/chapter/SBCK218_2923

### 2. 南宋趙汝楳《周易輯聞·易雅》保存楊忠輔筮法

其所錄算法更進一步：

> 餘一則歸以三，餘三則歸以一，餘二則歸以六，無餘則歸以八。

也就是：

- residue 1 → 取／歸3策；
- residue 3 → 取／歸1策；
- residue 2 → 取／歸6策；
- residue 0（無餘）→ 取／歸8策。

這是明確的：

【remainder state → quantity selector】

而且【無餘】被當成獨立條件分支，證明古筮法算法可明確辨識真正的零餘狀態。

《周易輯聞》為宋趙汝楳撰，附《易雅》《筮宗》；中國哲學書電子化計劃標成書年代為宋。

公開：
https://zh.wikisource.org/zh-hant/周易輯聞_(四庫全書本)/易雅
https://ctext.org/wiki.pl?if=gb&res=918442

證據邊界：
趙汝楳在文中對楊氏法有批評，所以這一條只能證明【宋代確實存在並被記錄的算法形態】，不能說趙氏認可其理論。

### 3. 元張理《易象圖說內篇》又保存同型規則

元張理《易象圖說內篇》明載：

> 餘一取三，餘三取一，餘二取六，餘四取四。

再次證明：

【餘數 → 實際取用數量】

在宋元易學／筮法傳統不是孤例。

公開：
https://www.shidianguji.com/zh/mid-page/7464335546140508199
https://ctext.org/wiki.pl?if=gb&res=7814331

## 九、對§656最後缺口再縮一層

此前§658仍缺：

【餘數是否能作數量／名額？】

本輪可把這個問題再拆開。

### 已證

1. 餘數可定五行類別（《紫巖易傳》《三命通會》）。
2. 餘數可定五宮位置（《武經總要》）。
3. 餘數本身可以是實際配置策數（朱熹《蓍卦考誤》）。
4. 餘數狀態可以決定另一路徑要取幾策（《周易輯聞》《易象圖說》）。
5. 【無餘】可以被古算法明確當成獨立條件分支。

所以：

> 【remainder → multiplicity／quantity】本身已有宋元古法先例。

### 仍未證

§656要求的不是任意quantity selector，而是更特殊的：

【河圖生數＋科3】
→【mod5 residue】
→【餘4、0、1、2、3】
→【直接等同水、火、木、金、土的出現個數4、0、1、2、3】

也就是：

> 【base-5 residue identity mapping → five-category multiplicity】

尤其要求：
【餘0 → 0個火】

目前仍未找到古書明文如此使用。

所以最後缺口不再是泛稱「餘數能否作數量」；它已縮成：

> 【古術數是否存在「模某數後，餘r就配置r個；若整除無餘則配置0個」的分類配置算法，最好恰為五類／五行。】

這是下一輪最精確的搜尋式。
