# §818-Y｜同年干化囚身份承接三步式：取代／複製及「取曜→判囚」逆向負控（2026-10-11）

**狀態：OPEN；本節僅為增量來源篩查，尚無同年 A囚→B囚 的人工確認例。** 不更動 §816／§817／§818（全部 OPEN）、§818-X 卷十二土主語強內證、癸囚炁→成熟貪狼必過反證、1581 年前獨立見證門檻、G0/G1/G2 分立或 §810-A／§812-A與其他封存。

## 一、唯一准入的歷史運算命題

1. **來源前提**：同一生年干 `g`，古文確定 `AnnualQiu(g,A)`，而非一般「休囚」、命局「忌曜」、支位「血忌」、命宮的「天囚」或別年干。
2. **獨立取曜**：原文以可執行的條件 `C` 指定**唯一** `B=S(g,A,C)`，且 `B≠A`。不能由成熟化忌結果反填 B；若 C 是生月／日時／宮位，須實際證明同一 g 的輸出不變，方可能解釋成熟四化固定年干表。
3. **身份指定**：原文須明示 `B` 承接**同一 g** 的年度囚述語，且辨別 `R_replace`（A 年囚撤銷）與 `R_copy`（A 留存且 B 新獲囚）。不明保留或撤銷時只記 `TRANSFER_MODE_UNRESOLVED`，不得偷判。
4. **負控**：`取星後遇囚`、`B增強A的囚惡`、`B代A執行某種宮位功能`、`別年干重算`、`多人多曜刑囚聚稱`一律不算成功。
5. **史料及驗算**：來源指令成立後，才檢1581以前可獨立定年文本、癸 `炁→貪狼` 與 G0/G1/G2 各版，不能混表過關。

## 二、本輪新加精確反向範例：先取星，後遇囚（非由囚取星）

**《星學大成》WYG 卷二 35b（本機 `research/星學大成_Kanripo_002.txt` 第626–631行，〈論管辰星歌〉及夾注）**：

> 本日生人推本宿，宿中算取甚星臨……值囚凶忌定邅刑。

夾注明定「本生月初一日屬亢星，十四日則屬奎星，看取奎星有何曜而斷人禍福」，再用積日、28宿輪起決定管辰宿。來源端操作為：
`生月日／積日→本宿→宿中臨曜→讀取既有吉凶／囚類情況→判斷`。

這是**有明文輸入、取宿、取臨曜、判斷**的古典 selector，卻與目標所需 `生年囚A→條件取唯一B→賦予B同年囚` **運算方向相反**。即使宿中選出 B，其已被判斷是否遇囚，並未因 A 既有囚身份而取得該身份；此式依生月日與天體位置變化，不是年干固定值的來源明文。此段另可在 [CTP《星學大成》卷二](https://ctext.org/wiki.pl?chapter=888933&if=en) 的〈論管辰星〉見到；是同支四庫電子文字互核，**不是**新增1581年前獨立見證。

本機識典 `M:/webbackup/ziweihengguan/output/shidianguji-sanchen/chapters/025.json` 的 `bodyText` 亦作〈論管辰星〉，有「宿中筭取甚星臨」及「值囚凶犯定遭刑」，與 WYG「值囚凶忌定邅刑」字面不同。**僅記 AI 轉錄差異，待原圖／同頁來源校字，不准推作另一本古代本系或承囚算子。**

**同卷 34a（第602–605行）〈論受職星〉**：「取本宮對宮上逆數至太歲……得庚以水受職星」。它確實示範取位→得干→取曜的另一 selector，但最後角色是**受職**，未把既有年度化囚從 A 搬到 B；與 §811 舊知相符，不當作新公式。

## 三、有限詞窗反查（非全書否定）

使用本機可讀 `rg`，在識典《三辰通載》`chapters/*.json` 的**原始 JSON 字元距離**搜尋「囚」與「代／替／取／改／令／承／傳／换／換」任一字前後100字的雙向詞形。命中檔案為 `001、002、025、076、199` 共**五個檔名**（每 JSON 的 `bodyText` 與 `text` 可能重複，絕非五條法則）。人工讀核代表片段：

- `025`：上列「本宿→宿中取星→值囚」；**選擇次序相反**，沒有 A 年囚輸入。
- `002`：八煞宮的「尋取生年何位終／宮主……囚犯倘然相克戰」；是另行取宮、宮主及遇囚相戰的盤面判斷。
- `001`：廟旺與休囚及「未中取」相鄰；「休囚」不是年度化囚述語。
- `076`：宿度凶曜「刑囚火土侵」與下文「法令」相鄰；不是承接指令。
- `199`：「如囚日圄」比喻與別句「交宮取定期」近鄰；不是星曜角色指派。

這只涵蓋**同 JSON 原文字符近鄰、指定詞形**。跨段隔更遠或不使用「囚」字的回指仍須另外研究；識典 AI 原文錯字與副本重複限制明列，沒有宣稱全 201 章逐句人工否證。另用本機 WYG 30卷近鄰搜尋「囚」旁替／代／傳／承／歸／取／擇／轉／變／改詞，最醒目的「論十干變曜所屬」「祿星變作刑星」仍屬角色分域／同曜變角色，見既有 §784／§818-V，不重報為新發現。
