# §711 化權816：取消「洛書8線」先驗的168候選壓力測試——816/right仍由古文作用域＋同行約束唯一選出（2026-10-04）

## 一、測試目的

§705原模型曾先限定：

> 洛書8條直線 × 左右兩向 = 16候選

再用《捷覽》同行四化不重壓成816/right與438/left。

這雖然已是target-free，但仍可能被質疑：

> 「是不是因為你先規定只能從洛書8條線挑，所以816才顯得特殊？」

§711直接把這個先驗拿掉。

## 二、候選宇宙擴大到九宮任意三數

九宮數：

[
1,2,3,4,5,6,7,8,9
]

任取3數：

[
inom{9}{3}=84
]

每個三數集合有兩個相反的三循環方向，因此：

[

]

這168個候選：

- 不限定洛書橫線、直線、斜線；
- 不限定三數和15；
- 不限定東西南北邊；
- 不讀成熟化權完整target；
- 只從§700「祿前移＋廉退紫入」後的baseQuan出發。

新增：

`quan_711_unrestricted_triple_stress_test_20261004.js`

## 三、第一層：只用《捷覽》同行四化不重，確實不能唯一

在168個有向候選中，只用：

> 每一干的祿、權、科、忌不重複

作格式約束，仍留下：

- **29個有向循環**

因此這一輪反而證明：

> §705的同行不重本身不是萬能selector。

如果沒有古文作用域，任意三數空間裡仍有很多合法解。

這是重要負控。

## 四、第二層：加入§706古文「北極＝亥子丑局部三位」

§706已直接核1563《星學大成》：

> 北辰所居乃天之北極子位

並以：

- 星曜居亥；
- 星曜居丑；
- 共同「以拱子一位」

構成實際局部三位。

所以古文scope是：

[
{亥,子,丑}
]

按既定九宮方位映射：

[
亥=乾6,qquad
子=坎1,qquad
丑=艮8
]

故：

[
{亥,子,丑}
leftrightarrow
{6,1,8}
=
{8,1,6}
]

注意：這一步不是先挑「洛書的一條線」。

而是：

> **古文先給出亥子丑三個方位，九宮座標才把它們翻成6、1、8。**

因此在84個任意三數集合裡，古文scope直接把候選集合固定為：

[
oxed{{1,6,8}}
]

只剩兩個相反循環方向。

## 五、第三層：《捷覽》同行四化不重只留一個方向

對{1,6,8}的兩個三循環都測同行祿權科忌不重。

結果：

- 一向淘汰；
- 一向保留。

唯一保留的規範化結果：

- 三數：1、6、8；
- 干：壬、癸、乙；
- base carrier：巨門、天梁、紫微；
- 旋後：紫微、巨門、天梁。

換回§705原本書寫順序【8,1,6】：

[
oxed{816/right}
]

完全同一個輸出。

也就是成熟重掛：

- 乙：紫微 → 天梁；
- 壬：巨門 → 紫微；
- 癸：天梁 → 巨門。

整個§711仍未讀成熟權全表作篩選。

## 六、最重要的新結論：洛書8線先驗不是必要條件

原§705可以畫成：

[
	ext{洛書8線}
ightarrow

ightarrow
同行不重
ightarrow
816/438
ightarrow
北方anchor
ightarrow

]

§711後可以把第一段整個刪掉，改成：

[
	ext{九宮任意三數}
ightarrow
	ext{古文北極作用域}{亥,子,丑}
ightarrow

ightarrow
	ext{兩個方向}

	ext{同行不重}

這個模型更簡單，也更不容易被質疑為先驗挑選。

甚至嚴格說，古文先給的是支位：

[
亥-子-丑

所以真正的核心不是：

> 「古人先挑洛書8-1-6這條線。」

而應改寫為：

> **古人已有北極／拱北的亥子丑三位作用域；把此三位映射到九宮方位時，自然就是乾6－坎1－艮8。**

這比「從八條洛書線中挑一條」少一層假設。

## 七、東木438仍可保留為控制，但不再是同等候選

{3,4,8}

即東木寅卯辰scope，仍有一個方向可通過同行不重。

- 816是【前1581北極／拱北古文實際指定亥子丑】時的合法局部循環。

因此真正selector不是「數學偏愛816」，而是：

	ext{紫微／北極角色的歷史方位scope}
]

這也解釋了為何單純數學會同時容許北與東。

## 十、研究結論應同步改寫

從§711起，不宜再把核心說成：

> 「在洛書8條線中，紫微北斗選中816。」

更精確應是：

> **前1581星命術已把北辰／北極操作成亥－子－丑三位。這三個方位轉成九宮座標就是6－1－8；成熟四化同行約束再唯一決定其局部循環方向，得到8→1→6。**

這一改寫的好處：

1. 少一個研究者自加的「8線候選」假設；
2. 先由古文定scope，再由數學定方向；
3. 816不是先猜數字，而是方位坐標結果；
4. 更符合§706～§710累積的文本證據。

## 十一、下一步§712：只攻「為何是8→1→6這個方向」

§711已把「為何是816這三個數」和「為何是這個方向」徹底拆開：

### 三數集合

由古文北極scope直接定：

[
{亥,子,丑}leftrightarrow{6,1,8}
]

### 方向

目前由《捷覽》同行四化不重唯一選：

[
8	o1	o6
]

下一步只查這個方向是否還有獨立古法旁證。

最值得驗的是：

> 《捷覽》紫微系明文「紫微天機星逆行」。

按十二支正常順行：

[
亥	o子	o丑
]

逆行就是：

[
丑	o子	o亥
]

而映成九宮數：

[
8	o1	o6
]

恰好就是成熟權所需方向。

若這一點在文本／座標審計中完全成立，則「8→1→6＋方向」兩部分都能分別得到獨立古法來源：

- scope由北極亥子丑；
- direction由紫微系逆行；
- 同行不重只作target-free驗證。
