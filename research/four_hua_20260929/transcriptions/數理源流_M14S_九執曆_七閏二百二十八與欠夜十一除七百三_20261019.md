# 數理源流 M14-S｜《宿曜經》上游候選《九執曆》：七閏二百二十八、欠夜十一除七百三的朔望月有理數指紋（2026-10-19）

> **主線仍為 T1299《宿曜經》及印度天文數學如何傳入漢文宿曜系統。** 本輪從《開元占經》卷104〈推積日及小餘章〉的兩組**原文已見運算參數** `7/228`（閏）與 `11/703`（欠夜）導出平均朔望月 **29.53058321479374日**，並結合得19年235朔望月、均年**365.2466871303436日**的條件式曆法數學指紋。新增可重跑程序 **18/18 PASS**；此乃18項程序斷言，**不是18條獨立史證**。原影像疑字「429／169」和《宿曜經》實際望宿跨書 caller 均尚未證成。

## 2. 第一個有理數指紋：每228個基準月恰好加7閏月

定 `M` 為距書定曆元所累積的**12月制基準月數**，僅就原文所列的閏月商數作形式模型：

```text
L(M) = floor((7*M + 132)/228)
L(M+228) - L(M) = 7       （任何整數M皆成立）
228 = 19*12
```

此結果等價於「每19年基準228個月補7個閏月」，故19年共有235個**暫計月槽**。132決定閏月商數的起算**相位**，不影響每228基準月恰增7的數學週期。這不是說古文此處寫了「十九年七閏」四字，也不是已證每個具體閏月的唐曆日期。

## 3. 第二個有理數指紋：30日暫值與十一／七百三欠夜

令 `D0=30*(M+L(M))+d` 為加入閏月後的30日暫計數，`d` 為指定月內累積日。若依來源語句把欠夜視為：

```text
Q(D0, c) = floor((11*D0 + c)/703)
D(D0, c) = D0 - Q(D0, c)
```

則對**任意固定c**（具體c尚有429/169疑字），`Q(D0+703,c)-Q(D0,c)=11`。長期每30個暫計日的校正平均值必為：

```text
mean_lunation = 30 * (1 - 11/703)
              = 30 * 692/703
              = 20760/703
              = 29.53058321479374 days
```

**重大限制**：此值是按「欠夜十一除七百三對30日暫計數線性作用」的**可驗數學後果**；不是古文用現代字句聲稱自己掌握「29.530583」朔望月常數，更不是已用歷元星表實算月球運動。若原影像證明算式關係與電子文本不同，模型必須更新。

作外部量級核對：[美國海軍天文台 *Explanatory Supplement to the Astronomical Almanac*, 第15章](https://aa.usno.navy.mil/downloads/c15_usb_online.pdf)列J2000均朔望月 29.5305888531 日，與上式差約0.487秒／月。**只能說此有理數平均值極接近當代參考平均月長**。歷史年代、日長尺度、天體擾動與實際逐次朔望月可相差數小時；不可從0.49秒便推「唐曆逐日預測誤差0.49秒」，更不可藉此聲稱唐人有現代天文物理公式。

## 4. 兩組參數連動：十九年、235月與長期平均年

把前兩節結果**明示為推算中的模型合成**：

```text
19基準年 = 19*12 = 228月；閏數=7；真月槽=235
19年平均日數 = 235 * (20760/703) = 6939.687055476529日
平均曆年 = 6939.687055476529/19 = 365.2466871303436日
```

它接近365.25日的理想歲長，但**並非完全相等**：每年相差約0.003313日（約4.77分鐘）；與現代常用回歸年約365.2422日也有約0.00449日差（約6.46分鐘）。這是從古文參數推得的**十九年有理數曆算格網**，既非「365.25已在古文證成」也不能推成全年準確天象。

注意：真正的`L`、`Q`都用整數商；某個具體228基準月視窗長度是**6939或6940整日**，而非6939.687個實際民用日。6939.687是長期平均量，不能當特定兩年之間的實際日數。

## 5. 可疑初值429與169：對具體日期構成「一整日」阻斷

依原M13-S可核前段例算：

```text
M=57*12+1=685
L=floor((685*7+132)/228)=21，餘139
D0=(685+21)*30+5=21185
```

若只是**研究者為測試歧文設置的兩種替代常數**：

| 試讀 c | `floor((11*21185+c)/703)` | 扣除後整日數 |
| --- | ---: | ---: |
| 429（未校定） | 332 | 20853 |
| 169（未校定） | 331 | 20854 |

兩者差**一日**，因而不僅積日不同，後續七曜直日、日月定位置亦可能不同。這是讀本忠實度的重要負控，不可藉現代吻合度挑選有利常數當成原書正確句讀。學術全文片段及其他網頁轉錄尚不足以完成原圖校字，**429/169 PENDING**。
