# §818-N｜《星學大成》當生變曜與流年飛星：冬至另起變曜的輸入型別審計（2026-10-10）

**本節：14/14 source-only 斷言 PASS；§816、§817、§818續 OPEN。** 接續 §818-M 實盤負控；保留 §810-A、§812-A、癸年貪狼、G0/G1/G2、1581年前證據門檻、全部既有封存。新證據是古書同名「變曜」實際指向不同時間與輸入算法，而非 R 已閉合。

## 一、卷十提出分層的古典觀念，不能見「飛星」便視為固定化忌

《星學大成》卷十〈天星標本序〉紀耶律學士星命十條，第八條為「當生變曜，流年飛星」。現有四庫轉錄可在維基文庫卷十或識典同篇核：https://www.shidianguji.com/zh/book/SK1609/chapter/1m1qpupdj084m 。

這是**區分當生和流年的文獻線索**，不等於已給出換曜公式；耶律傳說所繫年代也不能不經源流考證便當該訣確在遼代流行之獨立定年證明。

## 二、卷一：生年「十干變曜」是`年干→舊曜的功能`

本機 `research/星學大成_Kanripo_001.txt` 約第184–199行（WYG卷1 18a–18b）：

- 「甲乙丙丁戊己庚辛壬癸專配火孛木金土月水炁計羅」
- 「化囚者皆其梟印」
- 「變為囚者屬疾厄」

這三句的功能是年干十變身份及用於哪類宮職；**沒有任何句子明令重新選一顆紫微固定星**。數法的輸入類型為十干、曜體與所指功能，與下面的流年支煞明顯不同。

## 三、卷三：另有「年支→冬至開始的流年煞星／吉星」

本機 `research/星學大成_Kanripo_003.txt` 約第559–602行（WYG卷3 32a–34a）列申年、酉年、戌年、亥年等**年支**變曜，接着說：

- 「以上變曜或化為煞或化吉宿並從冬至日為始」
- 「乙酉年十一月冬至日始變丙戌年星煞」
- 「此變曜斷法先以命宮為主，隨以各宮所屬主星飛出在何宮……」
- 「將當生與流年兼推」

因此至少應分：

```text
F_natal(出生年干) -> 舊曜之十變角色（含囚）
F_flow(流年支, 冬至分界, 流煞配屬) -> 流年曜與凶吉稱號
P_chart(命宮, 原守, 流曜所在, 生剋衝照) -> 本命與流年合參
R_huaJi(年干化囚曜, source-side換曜條件) -> 成熟紫微固定生年忌星 [未找到]
```

**關鍵差別**：卷三流年法不只按生年干，尚有年支、冬至界限及命宮條件；不能拿這套`F_flow`未經證明直接改接`R_huaJi`。同一年干在不同甲子週期有不同年支，可能導致不同流年輸入；但這只證**必須提供消去分歧的指令**，不構成任何可能公式皆不成立的普遍否定。

## 四、卷十的癸炁實例：負控比純粹「囚忌對名」更具體

本機 `research/星學大成_Kanripo_010.txt` 約417、451行（WYG卷10 37a–39a）：

- 「以炁竊木之氣」，又舉「癸丑生子上安命有炁化囚者在命發積」；
- 另說「紫炁乃木之餘宿在天無象」，「癸丑生人炁在申遇此限亦有發者」。

這使「**癸年囚炁**」直接進入古典具體命盤語境，且**可發積**，不是把「囚」一律當定凶，也不是另取固定新星。炁與木同類／竊氣屬五行作用術語；若有人欲把「炁→木」接「貪狼氣木」，必須另找逐干專用、唯一且可驗的`R`，本段**沒有說**「癸炁化囚當改取貪狼」。
