## A. 《星學大成》對「權」的功能定義

本機：
- research/星學大成_Kanripo_001.txt

萬民英在十干變曜橫圖自注：

> 五陰雖有印綬相生，陰柔不能主事，故賴陽干比助而後有力，故謂之權。

同卷又說：

> 變為權者屬命宮。

所以1563這個已定年的理論化層，對權的辨識語不是一般「官貴」而是：

> 命宮／主體 → 主事 → 有力。

注意：萬民英自言十干變曜所以然「無可稽考」，因此這是1563明文理論化，不直接等於更早祖法。

### 卷三〈斗數指南總論〉

原文：

> 紫微，北斗之主宰，天府，南斗之令星。主星尊居其垣，莫可移動，令星專司財庫，最怕空亡。主星若動則眾星奔馳……

這一段把：
- 紫微 = 主宰 / 主星
- 天府 = 令星 / 財庫

直接分成兩個不同層級。

### 卷三〈斗數骨髓賦註解〉

原文：

> 太極星躔，乃群宿眾星之主……

所以紫微古名太極又被明確賦予：

> 群宿眾星之主。

### 卷三〈斗數準繩〉

又有：

> 紫微帝座……天府令星……

再次確認紫微/天府不是兩顆同級「王星」而已：
- 紫微 = 帝座
- 天府 = 令星

### 卷一成熟四化表

同一《捷覽》卷一：
> 甲廉破武陽，乙機梁微月……壬梁紫左武……

並明解甲年第二星為化權等。

所以成熟四化表與「紫微主宰／太極眾星之主」確實共存於同一1581刊本的文本結構。

## C. add selector 消融

早期祿十星池外四顆：
1. 太極/紫微
2. 天庫/天府
3. 天相
4. 暗金/七殺

只用廣義「官權貴」：
- 四顆都能通過。

加入較嚴格、且獨立來自舊十變曜的目標功能：
- 權屬命宮
- 權的理論化語義 = 主事而有力

再看1581《捷覽》的角色層級：
- 紫微 = 北斗之主宰 / 群宿眾星之主 / 帝座
- 天府 = 南斗令星 / 財庫
- 天相 = 印星
- 七殺 = 軍事/殺將角色（得地可掌三軍）

此時只有紫微同時落在：
> 主體 / 主事 / 全局主宰

這個層級。

## D. 證據定級

可以說：

> 在「權屬命／主事有力」這個功能約束下，1581《捷覽》自己的星曜角色層級足以把早期祿池外四顆候選唯一壓到太極／紫微。

不可以說：

> 已找到古人明文寫的「化權遇太極取紫微」生成口訣。

因為：
1. 《捷覽》已是成熟結果層；
2. 尚無1581以前過渡表直接顯示編者使用此 selector；
3. 萬民英1563的主事理論是他的解釋，不能無條件上推宋代。

因此目前定級：

> add selector：文本功能唯一重建已閉合；歷史生成鏈仍缺過渡證據。
