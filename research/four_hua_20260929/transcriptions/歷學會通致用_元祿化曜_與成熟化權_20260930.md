# 《曆學會通致用》元祿化曜與成熟化權

更新：2026-09-30

## 一、史料定位

薛鳳祚《曆學會通致用》〈命理叙〉明署：

【康熙三年歲次羅侯季夏海岱後學薛鳳祚識】

即1664年。

同序說世傳琴堂諸書保存：

【祿、暗、福、耗、蔭、貴、刑、印、囚、權等十干化曜】

但原理久已闕略，後由【張莊愚】表明其法。

來源：
https://www.shidianguji.com/zh/book/CADAL02034245/chapter/1l6wsk3q0gdgu

年代界線：
- 1664晚於1581《捷覽》成熟四化見證，因此不能把薛書作為紫微四化直接祖本。
- 張莊愚相關《元象易覽》《周天宜覽》見於清初／時憲曆語境；目前沒有證據可把其元星法壓到1581以前。
- 所以本檔用途是「操作語法見證」，不是祖本年代證明。

## 二、最關鍵原文：化曜須從原祿來

《曆學會通致用》元星條直接寫：

【化曜須從原祿來，化爲福貴乃奇哉。刑囚暗耗如臨命，任是榮華不暢懷。】

又明寫：

【元祿星過流年，化爲刑囚暗耗則不爲，化爲貴蔭福權則玅甚。】

所以這套法不是：
【每個功能各自先有一張獨立承載曜表】

而是：

【本命年干】
→【先定元祿承載曜】
→【遇另一流年干】
→【同一顆曜在流年中改取得祿／暗／福／耗／蔭／貴／刑／印／囚／權之一】

來源：
https://www.shidianguji.com/zh/book/CADAL02034245/chapter/1ljpfu8wyc3si

這是「功能槽」與「承載曜」分層，以及「同一承載曜可跨時間重新取得功能」的直接古法例。

## 三、元祿基本序列

元星直指十干元祿：

甲火
乙孛
丙木
丁金
戊土
己月
庚水
辛炁
壬計
癸羅

即：
【火、孛、木、金、土、月、水、炁、計、羅】

十功能次序：
【祿、暗、福、耗、蔭、貴、刑、印、囚、權】

按固定循環形式化：

當本命干為 a，
其元祿曜為 L[a]。

若流年干為 g，
同一曜所取得的功能由 g 與 a 的相對位置決定。

## 四、最重要的數學結果：下一干必化權

可重跑：
yuanlu_transformation_audit_20260930.js

結果對所有十個本命干都完全一致：

- 流年干 = 本命干 +0 → 祿
- +1 → 【權】
- +2 → 囚
- +3 → 印
- +4 → 刑
- +5 → 貴
- +6 → 蔭
- +7 → 耗
- +8 → 福
- +9 → 暗

也就是：

【同一元祿承載曜，只要流年干前進一位，就統一取得「權」功能。】

如果改用「現在的流年干 g」作索引，該承載曜來自前一個本命干：

【權(g) = 祿(g−1)】

這正是本研究此前從乙亥字《紫微數》表值獨立發現的：

【祿欄前移一干 → 成熟權】

的操作骨架。

## 五、套入早期固定紫微祿欄

乙亥字《紫微數》祿欄：

【廉貞、天機、天同、太陰、貪狼、武曲、太陽、巨門、天梁、破軍】

成熟化權：

【破軍、天梁、天機、天同、太陰、貪狼、武曲、太陽、紫微、巨門】

依元祿語法取：

【權(g)=祿(g−1)】

預測：

【破軍、廉貞、天機、天同、太陰、貪狼、武曲、太陽、巨門、天梁】

與成熟權逐位：

甲破軍 ✓
乙廉貞 × 梁
丙天機 ✓
丁天同 ✓
戊太陰 ✓
己貪狼 ✓
庚武曲 ✓
辛太陽 ✓
壬巨門 × 紫微
癸天梁 × 巨門

即：

【7／10】

而且殘差只集中：
【乙、壬、癸】。

因此目前可以非常精確地寫：

> 【成熟化權的主要干位骨架，與元星法「化曜從原祿來；元祿跨一干為權」完全同型。】

這不再只是數學位移巧合。

## 六、但承載星池已被紫微系重新固定

必須防止過度推論。

元星舊元祿承載曜是：

【火孛木金土月水炁計羅】

乙亥字《紫微數》早期祿承載星則是：

【廉機同陰貪武陽巨梁破】

兩者不是逐曜一對一的同一星池。

所以不能寫：

【薛鳳祚元星表直接生成紫微化權】

比較合理的是：

【舊星命保留一種「先祿、再跨干取得權」的操作語法】
→
【早期紫微固定星系重新定義祿的十星承載池】
→
【成熟權仍大量保存同一跨干位移語法】
→
【乙、壬、癸再局部重掛】

也就是：

【操作語法可能保留】
≠
【承載星池直接繼承】。

## 七、對早期七欄的反證：不是所有欄都能由祿移位生成

可重跑：
early_columns_from_lu_shift_audit_20260930.js

把早期祿欄做十種整體循環位移，對早期七欄：

- 祿：shift 0 = 10/10
- 禍：shift 5 = 【10/10】
- 權：最佳僅4/10
- 科：最佳2/10
- 魁：最佳2/10
- 馬：最佳2/10
- 福：最佳2/10

所以「化曜從原祿來」不能被機械擴大成：

【七欄全都是祿欄不同位移】

實際上早期七欄中，只有：

【祿】
【禍】

是祿欄的完美固定移位。

而成熟權則不是早期同名權欄的延續，反而重新接近：

【祿的跨干派生狀態】。

這非常符合「不同功能欄在成熟化時重新整併」的總模型。

## 八、祿／禍的+5與元星功能標籤不同，不能混名

早期《紫微數》：

【禍 = 祿 shift 5】

元星語法對同一元祿曜：
【跨干+5 = 貴】

所以不能因操作位置相同，就說：
【早期禍＝古天貴】

這正好提醒：

【位移算子】
與
【功能名稱】

必須分開。

同一個+5結構在不同文本層可以被掛上不同功能名。

這也是「位置骨架可保存、功能名可重掛」的重要實例。

## 九、1563《星學大成》已經把同一「祿→權跨干」算子寫在表內；1664只是把動態語義說白

第九節以前若只看《曆學會通》，會有一個年代問題：

【「化曜須從原祿來」1664才明說，晚於1581《捷覽》。】

本輪回到萬民英《星學大成》卷一。

其原序明署：

【嘉靖四十二年歲次癸亥十月朔日】

即1563年，早於1581《捷覽》18年。

卷一變曜歌訣直接給：

【祿、暗、福、耗、蔭、貴、刑、印、囚、權】
【火、孛、木、金、土、月、水、炁、計、羅】

並以甲生人求化貴、乙生人求化福作「同位數過去」的明文示例。

來源：
- 原序：
  https://yimatrix.com/th/academy/books/29/chapter/11392
- 卷一變曜歌訣：
  https://zh.wikisource.org/zh-hant/星學大成_(四庫全書本)/卷01
  https://ctext.org/wiki.pl?chapter=216616&if=en

若把十干各自的【天祿】排成一欄：

甲火、乙孛、丙木、丁金、戊土、己月、庚水、辛炁、壬計、癸羅

再依同一1563規則取【天權】：

甲羅、乙火、丙孛、丁木、戊金、己土、庚月、辛水、壬炁、癸計

即可直接看到：

【天權(g) = 天祿(g−1)】

10／10成立。

所以：

- 1664《曆學會通》第一次找到的是【直接語義說明】：
  「化曜須從原祿來」。
- 1563《星學大成》則早已提供【可運算表值與計數法】，
  且其表本身10／10包含同一祿→權跨干算子。

這使年代分級應改為：

### 1563以前後已證
【祿→權跨干算子存在於十變曜表本身】

### 1664再證
【後來元星傳統明確把這個算子理解為「先有原祿，再跨流年干化成權等功能」】

因此「祿→權」的操作骨架不再只能算17世紀後出旁證。

它已經有：

【1563前1581的直接表值證據】
＋
【1664直接動態解釋】

兩層。

仍然缺的是：

【1563作者是否已把這個表理解成與1664完全同一套「原祿跨流年再化」語義】

萬民英卷一只給計數法，沒有找到同一句「從原祿來」。

所以最嚴格判決是：

> 【算子本身可安全上推到1563；動態“原祿→流年功能”的明文解釋目前最早仍是1664。】

## 九、張莊愚年代目前不能上推1581以前

薛鳳祚1664序稱：
【自張莊愚表明此法】

但目前可檢到的張莊愚著作線索：
- 《元象易覽》
- 《周天宜覽圖》

都出現在清初「本朝／時憲曆」語境。
地方志又以順治十二年（1655）《周天易覽》曆元作比較。

所以目前不能把張莊愚視為明代1581以前人物，亦不能用他把元星法上推成《捷覽》祖本。

最安全定位：

【17世紀中葉保存／重釋的一套琴堂五星元星法】

它可能承受更早星命傳統，但更早文本鏈尚未找到。

## 十、目前判決

這條材料對四化來源研究的價值很高，但價值在「語法」，不是年代祖本。

目前可升級的結論：

1. 「先有祿承載曜，再由另一干轉成權等功能」是歷史上真實存在的星命操作，不是現代研究者抽象發明。
2. 成熟化權最強的7/10祿欄前移，與這個古法語法精確同型。
3. 因此成熟化權不必承接早期《紫微數》同名【權】欄；它完全可能在成熟編表時重新由【祿】槽派生。
4. 這使「四化四欄各有不同來源機制」模型再獲一個強旁證：
   - 祿：基礎承載池
   - 權：可由祿跨干派生
   - 科：文星／正魁／科名功能模組
   - 忌：福槽位置骨架＋印星曜池重組候選

尚不能寫：
【這就是1581四化的原作者公式】。

真正下一步：
尋找1581以前是否已有「化曜從原祿來」或同義的琴堂五星／元星文本。
