# §731 《紫微數》同頁 operator × carrier dictionary 審計：材料10/10共存，但 physical-body literal join 僅2/10

日期：2026-10-04

## 目的

承接§730。

§730已證，在固定星層直接做：

【早期祿row × 十變曜權的前一干operator】

可得到Q0：

【破、廉、機、同、陰、貪、武、陽、巨、梁】

並對1581成熟權達7/10，只差乙壬癸。

但§720曾把另一條模型寫成：

【十曜physical slot → 早期紫微祿carrier字典 → 固定星Q0】。

這裡有一個必須嚴格拆開的問題：

> §720所稱「carrier字典」，究竟真的是《紫微數》明文保存的【曜體身分→固定星身分】字典，還是只是把「十變天祿列」與「早期固定星祿欄」按相同十干位置配成的一個 positional codebook？

本輪專門做這個反證。

新增並實跑：

- `quan_731_same_page_operator_carrier_dictionary_audit_20261004.js`

## 一、文本鄰接其實非常強：十變曜與固定星舊名真的排在一起

公開《中天太極紫微數秘訣》同系轉錄在同一表區直接作：

【十干變曜】｜【十五星次第】

十變曜權列：

【羅、火、孛、木、金、土、月、水、氣、計】

右欄同時列：

- 進神＝紫氣星＝天梁
- 太常＝日＝太陽
- 天宜＝月＝太陰
- 白衣＝孛星＝巨門
- 天驛＝火星＝天機
- 鳳凰＝木星＝天同
- 天雷＝羅喉星＝武曲
- 天暴＝計都星＝廉貞
- 喧蛇＝土星＝貪狼
- 五鬼＝火星／大耗星＝破軍
- 天庫＝南斗星＝天府
- 太極＝北斗星＝紫微

來源：
https://ekachai.pixnet.net/blog/posts/11365237316

本機《紫微數》人工校讀亦已獨立確認這批固定星舊名：
【天暴廉貞、天驛天機、鳳皇天同、天醫太陰、嚴蛇貪狼、天雷武曲、太常太陽、白衣巨門、進神天梁、五鬼破軍、太極紫微】。

因此「十變曜operator材料」和「固定星材料」在同一文本傳統、甚至同一技法表區共存，這點可以保留。

但共存不等於它們按字面曜體身分直接一對一join。

## 二、第一個結果：Q0十顆carrier在右欄詞彙上10/10閉合

Q0：

【破、廉、機、同、陰、貪、武、陽、巨、梁】

這十顆在右欄全部找到對應條目：

| Q0 carrier | 右欄舊名／身分 |
|---|---|
| 破軍 | 五鬼；公開轉錄作火星又大耗星 |
| 廉貞 | 天暴＝計都 |
| 天機 | 天驛＝火星 |
| 天同 | 鳳凰＝木星 |
| 太陰 | 天宜＝月 |
| 貪狼 | 喧蛇＝土星 |
| 武曲 | 天雷＝羅喉 |
| 太陽 | 太常＝日 |
| 巨門 | 白衣＝孛 |
| 天梁 | 進神＝紫氣 |

因此：

【Q0 carrier lexical presence = 10/10】

這是一個真實升級：

> 不需要跨到後來《星學大成》單曜章，Q0所需十顆固定星材料在《紫微數》同一文本家族內已全數存在。

但下一層反而出現強負結果。

## 三、Q0的字面曜體身分不是十變曜十body的雙射

十變曜的十body domain：

【火、孛、木、金、土、月、水、氣、計、羅】

Q0十顆按右欄字面身分得到：

【火、計、火、木、月、土、羅、日、孛、氣】

其結構為：

- 缺【金】
- 缺【水】
- 多【日】
- 【火】重複兩次：天機、破軍

所以不可能形成：

【十變曜十body ↔ Q0十固定星】

的一對一physical-body字典。

這直接排除一個過度強的說法：

> 不能說Q0只是把十變曜權列每一顆physical body按同名星體身分翻譯成斗數固定星。

---

## 四、§720「carrier字典」逐項核對：只有2/10是字面身分

§720使用的映射是：

- 火→廉貞
- 孛→天機
- 木→天同
- 金→太陰
- 土→貪狼
- 月→武曲
- 水→太陽
- 氣→巨門
- 計→天梁
- 羅→破軍

這個映射怎麼來？

它其實是把：

十變天祿列：
【火、孛、木、金、土、月、水、氣、計、羅】

和早期紫微祿欄：
【廉、機、同、陰、貪、武、陽、巨、梁、破】

逐十干同位配起來。

所以它本質上是：

【Lu-row positional codebook】

不是從右欄「火星／孛星／木星……」字面身分讀出的dictionary。

逐項與右欄literal identity比較：

| body | §720 positional star | 同頁literal候選 | 是否同一 |
|---|---|---|---|
| 火 | 廉貞 | 天機／破軍 | × |
| 孛 | 天機 | 巨門 | × |
| 木 | 天同 | 天同 | ✓ |
| 金 | 太陰 | 無主星直接對應 | × |
| 土 | 貪狼 | 貪狼 | ✓ |
| 月 | 武曲 | 太陰 | × |
| 水 | 太陽 | 無主星直接對應 | × |
| 氣 | 巨門 | 天梁 | × |
| 計 | 天梁 | 廉貞 | × |
| 羅 | 破軍 | 武曲 | × |

結果：

【2/10】

只有：

- 木→天同
- 土→貪狼

與文本字面身分一致。

因此§720的用語必須校正：

> 「早期紫微祿carrier字典」  
> 應改成  
> **「由十變天祿列 × 早期固定星祿欄同位配對誘導的 positional codebook」**。

它是一個數學上完全合法的codebook，但不能冒充古文明寫的physical-body identity dictionary。

## 五、決勝負控：同一權列用兩種projection，10/10 vs 2/10

十變曜權列：

【羅、火、孛、木、金、土、月、水、氣、計】

### A. 用§720 positional codebook

得到：

【破、廉、機、同、陰、貪、武、陽、巨、梁】

即：

【Q0 10/10】

### B. 用同頁literal physical-body identity

可選固定星集合依次為：

【武】
【機／破】
【巨】
【同】
【無】
【貪】
【陰】
【無】
【梁】
【廉】

拿它對Q0逐位比：

【2/10】

對1581成熟權逐位比：

【2/10】

因此Q0真正成功的原因不是「曜體身分翻名」，而是：

> **十干位置／祿row codebook＋權operator。**

## 六、這會不會推翻§720？

不會全部推翻，但要把兩段拆開。

### 仍成立

1. 宋《三辰通載》天福slot與1563萬氏天權slot：
   【physical body sequence 10/10身份同一】。
2. 十變曜功能名稱的版本重掛：
   【宋天福 → 萬氏天權】仍成立。
3. Q0對成熟權：
   【7/10】仍成立。
4. Q0→成熟權只差乙壬癸：
   【S(2,1)】仍成立。
5. §730：
   【固定星祿row × 十變權stem-index operator → Q0】
   完全不依賴physical-body dictionary，因此不受本輪反證影響。

### 必須降級

§720中這一句型：

【同一physical body slot → 早期祿carrier字典 → Q0】

不能再描述為文本直接保存的「曜體→固定星」轉譯。

更準確應寫：

【同一physical slot歷史版本鏈】
＋
【另一路固定星祿row × 十變權index operator生成Q0】

兩者是**平行收斂**，不是已證一條physical-body translation pipeline。

## 七、§731後的更穩主鏈

目前最穩、最少跨層假設的生成鏈應改成：

【《紫微數》早期固定星祿row】
→【十變曜「權」的前一干／stem-index operator】
→【Q0 7/10】
→【廉退紫入】
→【乙壬癸三carrier局部閉合重掛】
→【1581成熟權10/10】

而宋→1563版本鏈改作平行歷史旁證：

【宋天福physical slot】
＝10/10同一body sequence
→【1563改名天權】

它證明「為什麼這個index offset在1563叫權」，但不再硬說它逐顆physical body直接翻成Q0固定星。

這比§720舊寫法更乾淨，也更符合§730的同冊證據。

## 八、證據分級

### A/B級可保留

- 《紫微數》同一表區並列十變曜與固定星舊名材料。
- Q0十carrier在同頁右欄詞彙上10/10存在。
- 多個body identity可直接由本冊OCR／公開同系轉錄交叉，如：
  天機火、天同木、太陰月、貪狼土、武曲羅、巨門孛、天梁氣、廉貞計、太陽日。

### C/V級

- 早期祿row施作權的stem-index operator生成Q0。
- §720 positional codebook本身。

### 已反證／不得再用

- 「§720映射就是《紫微數》明文physical-body→fixed-star字典」。
- 「十變權body row按字面身分逐顆翻星即可生成Q0」。

## 九、下一步§732

現在最後真正值得追的橋已更精確：

> **不是找body→star翻譯，而是找《紫微數》自身有沒有『對一張十干row施作另一個十變功能位次／前一干』的操作語法。**

優先檢查：

1. p.128–129表格本身的讀法、欄列方向；
2. 本冊「從祿上」「從某星起」「順數／逆數」「挨次／次第」一類操作句；
3. 是否存在【先取祿row，再依功能位次取前後一干】的同型例；
4. 與1563萬民英已明說的十變曜計數法做最小交叉，不再使用physical-body identity bridge。

若能找到這種同冊row-operator語法，§730的「祿row × 權operator」就可從C級結構重建再向B級同型古法提升。
