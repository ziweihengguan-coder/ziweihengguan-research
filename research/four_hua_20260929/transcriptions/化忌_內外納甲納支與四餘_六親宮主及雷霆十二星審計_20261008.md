# 化忌：內外納甲、納支與四餘接入審計

日期：2026-10-08。承接使用者「試試看」，檢查同納乾的甲壬、同納坤的乙癸能否由內外／爻位區分，再接計孛羅。

## 本輪結果

**內外區分找到直接文字，完整取忌仍未接通。** 保留同干所納爻的上下位置及支序，可保留十種不同狀態，不再受前輪只留八卦的容量限制。但接「納支→七政宮主」無法產生計孛羅，甲干原有三支也不含太陽宮午。另找到《道法會元》十二星飛九宮的完整操作，能驗回五組表，惟其輸入、星系與用途不同，不能據同名直接升為化忌母層。

驗收持續為：九干各自唯一；庚允許天同忌／天相忌兩說。分流依據獨立，不能依成熟答案追加條件或刪解。以下是來源操作的事後審計，並非預註冊盲測；不以早期福或成熟祿權科作輸入，不用清《乾元秘旨》、圖片或新OCR。

## 一、內甲外壬、內乙外癸，有具體文字

[《周易參同契考異》傳本中篇注](https://zh.wikisource.org/zh-hant/周易參同契考異)明載重卦上下三爻納干支，可整理為以下次序。作者／附錄層依網頁所標宋朱熹、黃瑞節附錄保存，不聲稱已核宋刻或每句親筆。另以[明姚際隆《卜筮全書》〈納甲歌〉](https://www.shidianguji.com/zh/book/HY1394/chapter/1l3wdoooujbqs)核各卦內外起支，具體刻年本輪未核。

| 純卦 | 初、二、三爻 | 四、五、上爻 |
| --- | --- | --- |
| 乾 | 甲子、甲寅、甲辰 | 壬午、壬申、壬戌 |
| 坤 | 乙未、乙巳、乙卯 | 癸丑、癸亥、癸酉 |
| 艮 | 丙辰、丙午、丙申 | 丙戌、丙子、丙寅 |
| 兌 | 丁巳、丁卯、丁丑 | 丁亥、丁酉、丁未 |
| 坎 | 戊寅、戊辰、戊午 | 戊申、戊戌、戊子 |
| 離 | 己卯、己丑、己亥 | 己酉、己未、己巳 |
| 震 | 庚子、庚寅、庚辰 | 庚午、庚申、庚戌 |
| 巽 | 辛丑、辛亥、辛酉 | 辛未、辛巳、辛卯 |

這是標準重卦納甲，不混洪範的壬離癸坎，也不混堪輿四隅納干表。甲壬、乙癸可由內外直接區分；其餘六干各跨內外六爻，**古文未指定只取其中哪一爻**。保留同干的有序「爻位、支」列，十列全異；全異只是資訊足夠，不是已找到十曜分派公式。

原例正控：乾甲子／壬午、坤乙未／癸丑四項；朝屯震下坎上，初庚子、四戊申兩項；暮蒙坎下艮上，初戊寅一項，均可驗回。

**傳本文字疑點保留：** 同段暮蒙六四寫戊戌，而按其艮外卦表應為丙戌。戌支一致、干不同，程式明列兩讀，不擅改字，也不稱全部原例通過。此前《漢上易傳》蠱／巽16正控是另一批原例，不受此新疑點影響。

## 二、同干納支接宮主，仍不足

《星學大成》四庫卷二〈論食邑星歌〉給出七政宮主：子丑土、寅亥木、卯戌火、辰酉金、巳申水、午日、未月。本機來源`星學大成_Kanripo_002.txt`第607–608行，程式保存檔案SHA-256；[公開傳本](https://zh.wikisource.org/zh-hant/星學大成_(四庫全書本)/卷02)。這是宮主曜，**不能與普通支五行午火、未土混用**。

研究組合假說A：年干→該干所納全部爻→各支宮主；來源各自存在，古文未命令這樣組合取化忌。

| 干 | 全部可取宮主，依同干爻序去重 | 成熟兩版目標是否在內 |
| --- | --- | --- |
| 甲 | 土木金 | 否，缺日 |
| 乙 | 月水火 | 是 |
| 丙 | 金日水火土木 | 否，缺計 |
| 丁 | 水火土木金月 | 否，缺孛 |
| 戊 | 木金日水火土 | 是 |
| 己 | 火土木金月水 | 是 |
| 庚 | 土木金日水火 | 是，木／火均在 |
| 辛 | 土木金月水火 | 是 |
| 壬 | 日水火 | 否，缺羅 |

兩版最多各6／10格「可達」，每干仍3–6個候選，沒有單格唯一解。這是可達性上限，不是六格已導出。

代數界限：宮主輸出字母表只有日月五星；計孛羅不在其中。因此無論前面加多少改干、爻變、六親選位，**只要最後仍單靠這張七政宮主表輸出，就不可能生成完整忌**。這不否定宮主參與，只要求有獨立的四餘取代／分派操作。

## 三、統一用六親選爻，不能補成唯一

[《京氏易傳》乾卦](https://zh.wikisource.org/zh-hant/京氏易傳)古注明列甲子水子孫、甲寅木財、甲辰土父母、壬午火官鬼，四項計算可驗。網站現代虎易注不混為古注。六親以純卦五行為「我」、納支普通五行為對象；取曜時才讀支的七政宮主，兩層分開。

研究組合假說B：在A全部同干爻中，統一只取同一六親，再取宮主；未將六親直接等同化忌。五種功能全部展開，無一完整：

| 共同功能 | G0庚同忌：目標可達干／唯一吻合干 | G1庚相忌：目標可達干／唯一吻合干 |
| --- | --- | --- |
| 官鬼 | 戊辛／辛 | 戊辛／辛 |
| 父母 | 無／無 | 無／無 |
| 妻財 | 無／無 | 庚／無 |
| 子孫 | 無／無 | 無／無 |
| 兄弟 | 乙己庚癸／乙己庚癸 | 乙己癸／乙己癸 |

官鬼具體輸出甲至癸為【空、火、木、水、金或火、木、水、金、日、空】。只有辛唯一正確，戊雖含火仍雙解，甲癸無官鬼同干爻。不得以答案挑戊火、再另補甲日癸土。官鬼在卜筮中還能作官貴，不能僅憑名稱就宣布它是化忌原義。

## 四、找到納甲飛宮取太陽／月孛，惟為雷霆十二星

[《道法會元》卷79〈雷霆契勘〉公開古文轉錄](https://ichingtrilogy.com/post/dao-fa-hui-yuan-79/)有天干起例、五組干日表、十二宮永定星辰及日支表；[Ctext同卷轉錄](https://ctext.org/wiki.pl?chapter=150122&if=en)搜尋索引亦可核部分段落，本輪直接讀取遭403。兩個轉錄不視為兩份獨立古刻見證，未校《道藏》原頁，網頁文字有士／土、末／未等疑字。

它確有完整共同運算：甲己日置燥火中五，按五六七八九一二三四順飛九宮，星依十二名環逐一前進。五組中星依次為甲己燥火、乙庚太陽、丙辛天罡、丁壬月孛、戊癸紫炁。由同一十二星次序飛排，五張九宮表45格全可重現，程式作5項整列正控。

但是它的十二名是太陽、月孛、金水、台將、天罡、土溽、奇羅、燥火、丙乙、水潦、紫炁、血刃；不是我們的十一曜表。文本還把太陽配木、月孛配火、紫氣配木。**金水是列名，不擅拆成金、水兩曜；奇羅不擅等同羅睺；未見本段取太陰、計都、羅睺的完整橋。** 相同名稱只構成待核線索，不足證這套分派就是四化上游。

再設明列假說：用本段自身的干位查所在星，甲乾、乙坤、丙艮、丁兌、戊己中、庚震、辛巽、壬離、癸坎。所得依甲至癸為【丙乙、奇羅、燥火、台將、紫炁、燥火、燥火、太陽、土溽、台將】，甲未取太陽。這是日干晴雨星表的自查假說，不將其強行換成成熟曜體來評分。

本段日支起中星亦隨十二日支變化。不能把依日干、日支、時方的輸入無條件換成年干，或從十二時方中挑吻合成熟忌者，否則只是藏入另一組自由參數。
