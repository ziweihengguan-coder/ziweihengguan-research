# 四化指定星與安星訣十二宮位置之耦合審計（2026-10-09）

## 研究問題與結論級別

使用者的新提問是：與其把化忌視為祿母表之外另一張母表，可否反過來檢驗「四化所指定的固定星」和「安星訣中的宮位／順逆／主星星系」具有共同算子，並藉此重新接通祿母表？

**結論：有確定的安星幾何耦合；尚無源流上能從祿母表生成化忌的 selector。** 本輪只能排除若干簡單的位置生成說，不能排除帶條件、帶星名轉換的複合上游算法，也不因失敗便認定化忌必然獨立於祿母表。

清楚分開：
1. 七政十變曜祿母環：L(甲…癸)=火孛木金土月水炁計羅，屬舊曜／功能身份。
2. 安祿存：甲寅、乙卯、丙戊巳、丁己午、庚申、辛酉、壬亥、癸子，屬生年干定位。
3. 四化：以年干指定**哪一顆固定星**化祿權科忌；安星法另依生月、生日、生時、五行局決定該星落在何宮。
4. 「祿隨忌走」：本輪查得現代飛星論述中作論斷／體用語，未驗到1581年前可充「祿生成忌」的取曜口訣。不能拿後世判語當古代編表算法。

文本位置：研究已保存的 §759 對1581《捷覽》、全集、全書總括歌「天馬天祿帶煞神，前羊後陀并四化」及章序作跨本校讀，確認**同屬生年干 cluster，但正文排列不一致，無法推成先安祿存後造四化的程序**。公開《全書》全覽： https://zh.wikisource.org/zh-hant/紫微斗數全書/全覽 。祿存安法及安四化轉錄亦見此頁；今次只把文字當索引證據，古籍版本年代承先前專題，不重新定年。

## 1. 獨立於出生年月日的十四主星骨架

承現有 `heluo_mainstar_coupling_audit_20261007.js`，令十二宮座標為 Z12，紫微落點 z、天府落點 f：

- `f = 4-z (mod 12)`。
- 北系：紫微 z、天機 z−1、太陽 z−3、武曲 z−4、天同 z−5、廉貞 z−8。
- 南系：天府 f、太陰 f+1、貪狼 f+2、巨門 f+3、天相 f+4、天梁 f+5、七殺 f+6、破軍 f+10。
- 昌曲依生時、左右依生月；不能當僅由 z 或年干決定。

因此，任取兩顆**主星**，在全部十二種 z 下，`y=+x+c`（同系）或 `y=−x+c`（異系）都成立。這是**安星訣已知幾何的恒等式**，不是證明四化來源的新史料。鏡射截距 c 會隨座標原點變更，不可把 c 的絕對值稱為古法常數；兩列 c 是否相同則不受共同原點平移影響。

## 2. 成熟 G0（庚陽武陰同）化祿→化忌，逐干驗回位置

以已知成熟 G0 星名作**事後 target／分類**，不把結果當預測。12 種 z 全部代入；昌曲列需再容許生時逐宮循環。設化祿所在宮為 x、化忌所在宮為 y：

|干|祿→忌|位置映射|旋轉型距離 y−x（mod12）|說明|
|---|---|---|---|---|
|甲|廉貞→太陽|`y=x+5`|5|同北系|
|乙|天機→太陰|`y=−x+4`|0,2,4,6,8,10|跨北南|
|丙|天同→廉貞|`y=x+9`|9|同北系|
|丁|太陰→巨門|`y=x+2`|2|同南系|
|戊|貪狼→天機|`y=−x+5`|1,3,5,7,9,11|跨南北|
|己|武曲→文曲|依生時，非單一 z-isometry|0…11|時系獨立輸入|
|庚|太陽→天同|`y=x+10`|10|同北系；G0|
|辛|巨門→文昌|依生時，非單一 z-isometry|0…11|時系獨立輸入|

類別：**旋轉5干、鏡射3干、生時獨立2干**。尤其戊、壬都為同一 `y=−x+5`，屬可保留的幾何重複，但兩者都跨南北系，本身不能證明由同一祿母算子編定。

**G1/G2 庚支敏感性**：G0 庚太陽→天同為 `y=x+10`；G1 庚太陽→天相是 `y=−x+5`，旋轉宮距為1,3,5,7,9,11；G2 庚太陽→太陰是 `y=−x+2`，旋轉宮距為0,2,4,6,8,10。版本異文不僅改星名，也改變位置算子類型。這可作版本的可檢查結構後果，但不能單憑幾何判定哪個版本年代最早。

## 3. 祿存、羊陀位置負控

安祿存與四化共享年干，但**祿存位置本身不是祿母表，且不是四化的完整索引**：丙與戊同在巳、丁與己同在午，卻各有不同四化星名，故 `四化=g(祿存宮位)` 的純函數不可能。

在完整可達的主星落點 z∈Z12、時系落點 h∈Z12 狀態空間中，固定年干時化忌星本身仍可遍歷十二宮，祿存則固定。因此，不存在一條對所有命盤均成立的「化忌總在祿存／祿存前後一宮／固定三方／固定沖宮」規則。相對祿存的任一固定宮距都不能當作年干忌星 selector。羊陀隨祿存左右一位，不增加年干資訊。

但這只是排除**只看祿存宮位**、不看星身份與完整出生狀態的公式；不是排除更高階的 `h(年干,祿母曜,主星系,動態安星位置)`。

## 4. 全四化關係的順帶負控

既知 G0 四化表10×4=40個指定 carrier，十干各有6對四化，總60對；僅含十四主星的46對可在12種 z 下用固定 D12 isometry 表示，另14對牽涉昌曲／左右（月時條件），無法只以 z 表示。各干固定D12主星對數為：

`甲6 乙6 丙3 丁6 戊3 己3 庚6 辛1 壬6 癸6`，合計46/60。

尤其**癸祿破軍、權巨門、科太陰、忌貪狼全部屬南系**，所有六對宮距固定。這是成熟四化選星後的結構特徵，不可先驗解讀為選星古訣；對任意同系星曜四元組，本來也會得到同類結果。
