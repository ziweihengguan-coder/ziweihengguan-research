# A先科後忌與B科忌聯派：文本／版本窄查

日期：2026-10-08。配合本輪分工，只整理文本與版本；不修改既有計算 audit。

## 結論先列

- **A「成熟祿權科先定，再選忌」：** 有模型依賴與讀表欄序，未找到特定生成次序、占位或避重的直接古文指令。
- **B「祿權＋共同科五行／候選池先定，科忌聯合分派」：** 庚科忌的成對版本表值及共同固定星水層支持把它保留為競爭模型；未找到聯合選擇、同時改掛或先後選位的直接指令。
- **A與B目前無法由這輪文本裁勝。** 四化歌可依序讀取，並不意味歌訣編表時由前欄生成後欄。科、忌在同一句保存兩個表值，也不意味以聯合最佳化產生它們。
- **祿→早期福不是本輪強制必經路。** 早期福可作資料見證或候選來源；已核成熟四化段沒有命令先取福欄再算忌。
- **循環硬閘門：** §790以庚天同忌鎖出G0科的鏈，不能再將該科當作不依賴忌的輸入反推忌。這是資訊流限制，與文本是否古老無關。

## 3. A需要的次序：目前只有讀表與對固定星加標記

南陽堂原刻既有校讀：

> 安祿權科忌四星變化訣
>
> 論生年干　挾火而化
>
> 如甲生人廉貞化祿、破軍化權、武曲化科、太陽化忌是也，餘仿此。

§757已核《捷覽》例：

> 天機下安祿，天梁下安化權，紫微下安化科，太陰下安化忌，餘仿此。

**直接內容：** 生年干作索引；四星依祿、權、科、忌欄序解碼；在已安好的固定星下加四化標記。

**未交代：** 先算科才算忌、以科作忌的輸入、忌讓位給科、不能重星、跨前二干檢查權科占用。例句沒有這些依賴動詞與條件。

南陽堂的「挾火」不能無原件異文就校作「挨次」。即使得到可靠「挨次」字形，若只解釋四欄次序，仍不能證四個選星算式的生成依賴。

正控可同段對讀：公開《全書》〈安擎羊陀羅〉明說：

> 此二星隨祿存安之，祿前安擎羊，祿後安陀羅。

這才有「前一步結果作anchor→指定後一步相對位置」的明確算法語法。它的輸出是羊陀宮位，**不能跨命名空間套成化忌算式**。

公開平行：[識典古籍《新鍥希夷陳先生紫微斗數全書》安星段](https://www.shidianguji.com/mid-page/7356346222820769842)。該頁作者元資料題「北宋陳摶」，只屬題署／網站標籤，不採作此四化歌的刊年。

## 4. §806的數學次序不是古文次序

§806既有候選為：成熟Q/K的本干及前二干占用，與六吉可改位置交集。四個witness依次為：

| 福槽候選 | 占用來源 | 所需資料 |
|---|---|---|
| 甲太陰 | 癸科太陰 | 保留的早期科 |
| 乙巨門 | 癸權巨門 | 成熟權 |
| 丁天梁 | 乙權天梁 | 成熟權 |
| 戊右弼 | 戊科右弼 | 成熟共同科 |

這說明**該候選模型**要讀成熟權，並讀戊科已改成右弼後的狀態；未證古人選了這個窗口。

原§806已把庚科遮掉，這是必要的防循環設計。新的A／B比較應續保此資訊邊界，不可把G0太陰科無條件灌入。

窄查結果：未取得「權科既定，次取忌」「先安科，再避其星安忌」「前二干權科占用」等特定指令。

## 5. 庚：最強判語支持G0存在，不給生成順序

《精詳集》卷二〈十二宮太歲流年吉凶星論〉，公開第102章申宮：

> 同庚貪癸丙為忌
>
> 如天同在申宮守命，庚生人逢忌悔吝。

同段也有庚天相吉：

> 如紫貞相破在申宮守命，庚甲癸生人發福。

未宮有庚天相凶，卯宮有庚太陰凶，戌宮有庚天同不順。此種吉凶關係帶宮位條件，不能抹去條件後當成「庚三顆水星專用候選表」。

公開定位：[《精詳集》第102章](https://tianjihq.com/zh-TW/learn/books/ziwei-jielan/102)，申宮歌與解說；現代轉錄包含點校註，註文與據義補字不列作古代指令。本機定位：主紀錄§677（第37436–37464行附近）、§790專題第三節。

**可直接支持：** 庚天同忌的關係已在《捷覽》所收判語層存在，與G0表值同向。

**不能支持：** 先選天同忌所以太陰科、先選太陰科所以天同忌，或天同由忌移科、天相補忌。§790的日月配對、重用早期carrier與固定化氣覆蓋都是另加selector。

§680的既有逐格比較又沒有證出《全書》太歲判語朝G1R1定向同步重寫。故「G1在歌訣層變動、舊判語多留G0」可作編纂層分離線索；不能斷言已查到一次具體聯合改表事件。

## 7. 壬：土層與分支表值直接；排除及pair completion是重建

## 8. 元素型別：固定星共水，不等於旧曜共水

§789程式第18–23行使用固定星字典E：廉貞火、天同水、太陰水、天相水、左輔土、天府土等。早期七欄先正規化成固定星名，再用E取元素。

| 名稱／位置 | 舊曜層 | 固定星五行層 |
|---|---|---|
| 天暴／廉貞（早期庚科） | 計，土 | 廉貞，火 |
| 鳳凰／天同（早期庚福） | 木 | 天同，水 |
| 天醫／太陰 | 月，水 | 太陰，水 |
| 天驛／天機 | 火 | 天機，木 |
| 八座／右弼 | 水 | 右弼，水 |
| 三台／左輔 | 土 | 左輔，土 |

所以§789「庚火→水」只在其固定星五行表示層成立。不能用它宣稱舊曜庚科的計土直接變水；更不能把天同忌的木曜輸出偷換成水曜再反推來源。

《精詳集》72章已有固定星五行例：天機木、廉貞火、文昌金、破軍水；這支持固定星元素有傳本文字基礎，但該章不是十干科忌元素分配算法。[公開原文](https://tianjihq.com/zh-TW/learn/books/ziwei-jielan/72)

角色化氣五行、宮位五行、曜體五行、固定星五行也必須各存欄位，不因都名五行就共用字典。

## 9. 對新計算的文本邊界

| 要比較的條件 | 可怎樣使用 | 不能怎樣使用 |
|---|---|---|
| 祿權共同表 | 兩版共用的已知資料 | 稱已由此古文生成全部科忌 |
| §789共同科元素／pool | 既登記假設下的共同層輸出；注明E字典、quota、最少改寫及paired gate | 稱古訣直接給科3配額或戊庚壬改掛 |
| 庚天同忌判語 | G0歷史驗證；或明列已透露忌的條件解 | 聲稱完全遮忌輸入後又使用它選科 |
| G1庚同科／相忌表 | 版本驗證目標 | 用它指定重用天同與補天相規則，再稱新盲測 |
| 同干四星互異 | 觀察結構／候選公設，做消融 | 稱古代明令避重 |
| 權科局部占用 | A的待驗模型；全方向與寬度應競爭 | 因§806恰合就稱古文規定先科後忌 |
| 同元素科忌聯派 | B的待驗模型，分版本驗證 | 因兩版庚各成水水配對就稱已找到聯派原訣 |

依已核文本，A與B都可繼續比較；最合適的結論層級是「給定哪些明列條件後唯一」，而非文本已裁定歷史編表次序。

**本輪特定生成指令命中：A＝0，B＝0。** 這是所查見證的命中數，不是證明歷史上不可能存在。暫不需要增加清代材料、把早期福強置中間層，或用新故事填入缺失的dispatch。

## 10. 同輪新增的「科定後修復忌衝突」候選：文本覆核

計算側另提出一條更具體的共用後處理。此處只記其輸入條件與文本級別，不將尚待驗算的候選數冒稱本輪獨立計算結果。

候選流程為：R4與水讀、原名保留先產生不讀科的暫定忌B（庚天同）；若庚科沒有撞B，保留B；若庚科＝天同撞B，固定其他九忌，並要求忌欄十星互異及科忌同干不重，在{太陰、天同、天相}重選庚忌。太陰已被乙忌使用、天同已被庚科使用，條件內只餘天相。若把候選放寬到全部固定星水星，計算側指出右弼、破軍、天相均可能留下，故三顆scope是實際假設。

| 候選中使用的條件 | 本輪直證 |
|---|---|
| 已占則重選／讓位換掛 | 未見科忌生成指令 |
| 同干科忌不重 | 兩版表值符合；未見明令禁重 |
| 全忌欄十星各一次 | 兩版表值符合；未見全欄配額指令 |
| 其餘九忌／原名保留 | 保存現有格的模型prior；未見原名保留指令 |
| 庚只從三水候選重選 | 《精詳集》有三者庚干關係；沒有三顆專用候選清單或封閉排他條文 |
| 科確定後才修復忌 | 與候選資訊流相符；沒有古文指定該先後 |

此候選比「先用庚忌鎖庚科，再用科回推忌」更容易保持資訊流清楚，但必須另外確認輸入科的來源也未使用忌。若G0科仍採§790的Gate A，依然不能視為忌盲輸入。

新增窄搜詞：已占、占用、不重、重複、避重、讓位、原名保留、改掛／換掛；查本機全部`星學大成_Kanripo_*.txt`与已核人工校讀，外部只找四化相同詞組。未取得上述特定指令。局部詞面近命中例：卷23第321行「甘石已占之矣」，其中「占」是占驗，不是某carrier已被一欄占用；卷19第340行「體不重肥」是相貌，不是星名不重。兩者均排除。

原始OCR雖可讀到化科／化忌角色屬水的線索，這是**角色化氣**，不能替代carrier水星的封閉候選表。新候選的算法可行性與文本採用證據仍須分報。

6. 固定星後處理與舊曜R4是兩個層次；G1最終結果不能繼續宣稱守原舊曜十體各一次。不能省略轉換表示層的新增階段。
7. 科未知時，純全局最少忌改動會淘汰G1。因此改以§790既有的日月配對、同干舊星重用，加忌改動數作**新增現代多目標比較**。8個聯合配置留下兩種庚配對：太陰科／天同忌成本(0,1,0)，天同科／天相忌(1,0,1)。兩者互有取捨；沒有權重時，不能說它們是同成本平手。
8. 壬仍左輔／天府兩選，故共有4種G×R組合；兩主要古本只驗證G0R0、G1R1。不得將另兩種結構組合宣稱為已見古本。
