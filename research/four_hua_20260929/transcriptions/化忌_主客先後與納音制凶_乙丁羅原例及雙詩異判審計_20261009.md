# 化忌：主客判斷先後與納音制凶，乙丁羅原例及雙詩異判

日期：2026-10-09。承接聿斯三方主／十變連用續查。追甲火、戊土、乙孛的祿曜忌害限定語，再對讀乙羅化囚、丁羅化刑。此次沒有把判吉凶的公式冒充取化忌星的公式。

**結果：補得明確的主客判斷次序與可執行局部作用表；納音克凶曜可為乙卯、乙酉羅囚反吉提供可檢驗解釋。但仍未指定只由年干選哪一個主曜及取哪一端。不同章句的條件與異判必須保留。**

## 一、找到明寫的判斷先後

卷十〈雜論倒限〉本機第761–765行：

> 為主之星不論化氣，會主之星復論化氣。煞星若化吉為禍亦輕，若化凶尤緊；母星化吉為福大，化凶為凶亦緩。照命限者生剋至緊。

這段給出的次序是：先有主曜，識別會主之曜的煞／母作用，再論化吉化凶。本段所說「本主不論化氣」不等於本主必吉，也不能擴成全書所有用途均禁論本主化曜。

卷一第259–263行〈天刑星與奴僕同〉另說：若是命主星又不妨，無自刑之理。這提供一個具體條件：本主化刑不應被簡化為另有刑曜來傷本主。與前輪「有用刑囚」相接，但不把所有刑囚都免害。

按卷十本段字面登記局部作用表：

| 會主身份 | 化曜判別 | 本段結果 |
|---|---|---|
| 煞 | 化吉 | 禍輕 |
| 煞 | 化凶 | 禍緊 |
| 母 | 化吉 | 福大 |
| 母 | 化凶 | 凶緩 |

程式只輸出這些判辭，不自行賦數值，不稱它已選出某顆忌曜，也不把「化吉／化凶」無據縮成唯一一套十變分組。

## 二、不能把局部作用表拼成全書唯一公式

卷十一寅宮段第258–264行另有：恩星雖化刑囚仍吉，化福祿愈佳；難星雖化福祿仍凶，化刑囚尤酷，接著列季節、混曜、生泄及職元等條件。

若研究性地將「母」與「恩」跨段對接，母化凶的卷十字面為緩凶，卷十一恩化刑囚則仍吉。不能忽略段落條件強併成一張全書真值表，也不能先判某句誤。其間可能有術語範圍、宮位、季節及注釋層差別，須再辨。

卷二十八第154–157行切勿單以化氣取捨，前輪§808等已知；本輪作正控，不重報新發現。

## 三、乙丁羅的原例應讀成作用與身份疊加

卷十第208–209行先定火主、羅奴、木母，條件是木不生火而反生羅；乙丁人再添刑囚身份。由既有母環逆查：

`role(g,x)=T((L⁻¹(x)−g) mod10)`

其中L為火孛木金土月水炁計羅，T為祿暗福耗蔭貴刑印囚權。乙羅為囚、丁羅為刑，原例可重現。但其作用條件不是單有乙／丁就一律選羅：主、奴、母與分生已先成立，角色再加於其上。

卷二十九〈又六十年詩〉也提供相反控制：

| 生年／篇章 | 曜與年干角色 | 原判及保留條件 |
|---|---|---|
| 乙未／又詩 | 羅囚 | 亦凶；孛祿反無功 |
| 乙卯／又詩 | 羅囚 | 不可以囚窺，命限相逢有福權 |
| 乙酉／又詩 | 羅囚 | 土木羅吉，另有其他曜位限制 |
| 乙亥／又詩 | 羅囚 | 羅會孛，不可以凶名；非凶不強改為必吉 |
| 丁酉／第一詩 | 羅刑 | 限行羅計俱為禍 |
| 丁酉／又詩 | 羅刑 | 羅刑與計貴，命限福重 |
| 丁巳／又詩 | 羅刑、孛囚 | 皆有用，限行從容 |
| 癸卯／又詩 | 羅祿 | 非吉，不擅改成必凶 |
| 癸亥／又詩 | 羅祿 | 不背祿，另火孛有福 |

程式登記15個摘錄案例，角色全部驗回。案例為事後人工摘錄，不是盲測或全書統計。非吉、非凶、無功、有機權保留原判語，不全強壓成吉凶二值。

## 四、納音制凶是一條真口訣，但它輸出制伏關係

卷二十九第100–101行的分欄題為刑囚暗耗宜納音克他，詩說我克他時反是權。配合既已核實的納音計數法，可以提出：

`R(g,b)={x∈十曜：role(g,x)∈{暗,耗,刑,囚} 且 納音(g,b)克x的古曜五行}`。

R是「被納音克制的凶角色曜集合」，不是成熟化忌表。原文的反是權也不能自動改讀為十變環的正式化權；例如乙羅仍是囚，不能因此把角色表改成權。

乙卯大溪水、乙酉泉中水，皆能克屬火的羅；乙未沙中金則反受羅火克。故這個古典算子為部分羅囚反吉例提供了可驗解釋，**但詩未明註原因就是納音，本輪接用屬研究假說**。乙亥與羅同屬火而詩仍說非凶，亦保留，不能將沒有納音制克反推成必凶。

使用10-08已核《三命通會》卷一引六微旨論的計數，不報新納音算法：子午數至庚等，含首尾計數，7金、3火、9木、1土、5水。六十甲子計算全部對合一般納音參照。四餘五行與月水精只供此處五行比較，不擴成無條件命盤害曜規則，更不改固定紫微星五行。

同干六種合法年支有三種納音態，本輪十干的R集合皆會隨年支變動；且有空集與多曜。例：

| 生年 | 納音 | R：被制的暗耗刑囚曜 |
|---|---|---|
| 乙丑／乙未 | 金 | 木、炁 |
| 乙巳／乙亥 | 火 | 空 |
| 乙酉／乙卯 | 水 | 羅 |

這解釋了為何不能讀完口訣就刪去年支，拿R當只由乙干固定取羅的公式。若日後找到有據的固定功能柱或消去年支操作，可再接入；不因本輪依年支便斷所有重建無解。

## 五、兩個文本界限不能藏掉

1. **同丁酉兩首相反。** 年干、年支、納音與羅的角色全相同，第一首說羅計為禍，第二首說羅刑計貴有福。只輸入這些欄位就不足以重現兩段字面判辭；篇章與盤面條件仍缺。不能按目標挑一首，也不能僅憑此斷言古法不存在或作者自相矛盾。
2. **甲子孛化祿的字面張力。** 第一首第299行作甲子生人孛在寅、化為祿主；按出生年干的母環，甲孛應暗。前段第86行另作乙丑孛在寅化祿，則與母環相合。識典電子平行本也保存第一首甲子字樣，但不代表更早獨立見證。可能涉及訛字或另層取祿，未核原刻前不默改，也不把它當同一年干十變的強制方程。

## 六、這輪對取曜問題的實際推進

已找到兩類可執行古法：先分主客再評化氣的作用表，以及納音克制凶角色的集合算子。它們主要決定某曜在某情境的作用，**沒有因此指定年干唯一主曜或取犯／取受**。所以本輪不再把作用判辭強轉成另一張取忌母表，也不重跑舊族後包裝成新10／10搜尋。

下一步應把「原干定哪個功能主曜」與「主定後取其生者、克者、餘奴或受者」分別追證；已有明確算例即可重建，不必等到一句明寫化忌。但需找到實際取星動作，不能僅以強凶判辭決定誰當忌。
