# 化忌：四化落宮與安星訣的關係（2026-10-09）

使用者指定：不要因現有模型依賴早期福，便斷言不可能由祿母表導忌；改查四化所在位置與安星訣的位置是否相互制約，並核對「祿隨忌走」。

**本輪結果：安星提供了精確的平移／鏡射表達，但尚未提供獨立選忌的年干規則。找到己干兩個合法安星輸入：祿權科同位、文曲忌異位，證明僅用三者落宮不足。這不是祿母表的一般不可能證明。**

## 1. 本輪與既有研究的區別

§809-C2的「geometry」主要是七欄對十干的循環移位；本輪檢查實際十二宮安星。2026-10-04主星三合研究、§705、§757／758章序研究及10-07昌曲輔弼配對鏡射研究均已存在，本輪不將其重報為新發現。

本輪以已知紫微固定星祿欄為位置入口，不以早期福、印星池或《乾元秘旨》生成候選。仍須區分：

- 十變曜祿母環：火孛木金土月水炁計羅。
- 紫微固定星祿欄：廉機同陰貪武陽巨梁破。
- 安星程序：決定固定星在各出生輸入下的宮位。

第二層不能無證當作第一層的直接星名映射。本輪驗證第二、三層的幾何關係，沒有補證兩張祿表的歷史橋。本輪已知成熟答案，是事後檢驗，不冒稱遮答案重建或新封存。

## 2. 文本與座標

[《捷覽》公開繫聯點校轉錄](https://shixingji.club/public/ziweidoushujielan)卷一〈安紫微天府訣〉、〈布南北二斗諸星訣〉、〈安祿權科忌四化訣〉有完整起點、隔位、順逆與四化掛星解文。此網頁是現代點校轉錄，本輪沒有重新目驗1581原頁。

取子=0……亥=11，紫微位置z、子時起算h、正月起算m0，均模12：

| 星系 | 位置公式 |
|---|---|
| 紫微、天機、太陽、武曲、天同、廉貞 | z − {0,1,3,4,5,8} |
| 天府、太陰、貪狼、巨門、天相、天梁、七殺、破軍 | 4−z + {0,1,2,3,4,5,6,10} |
| 文昌、文曲 | 10−h、4+h |
| 左輔、右弼 | 4+m0、10−m0 |

兩種位置操作明確另命名：平移T_k(p)=p+k，鏡射M_c(p)=c−p。它們作用於十二宮，**不是十曜母環的R₄**，不能因數字相同便混用。

G0取《捷覽》庚科太陰、庚忌天同、壬科左輔。G1另取既有[南陽堂刊本人工校讀](南陽堂紫微斗數全書_四化訣_PDF151-152_人工校讀.txt)：庚科天同、庚忌天相、壬科天府。兩支分開計算，不混拼最好答案。

## 3. 逐干祿→忌：關係可精確寫出，但操作選擇尚未導出

以下是G0，對全部十二種紫微位置成立；昌曲另保留時辰輸入：

| 干 | 祿→忌 | 已知安星公式所給關係 |
|---|---|---|
| 甲 | 廉貞→太陽 | T₅，即位置+5 |
| 乙 | 天機→太陰 | M₄，即位置和=4 |
| 丙 | 天同→廉貞 | T₉，即位置−3 |
| 丁 | 太陰→巨門 | T₂ |
| 戊 | 貪狼→天機 | M₅ |
| 己 | 武曲→文曲 | 無不借時辰的固定T／M |
| 庚 | 太陽→天同 | T₁₀，即位置−2 |
| 辛 | 巨門→文昌 | 無不借時辰的固定T／M |
| 壬 | 天梁→武曲 | M₅ |
| 癸 | 破軍→貪狼 | T₄ |

G1的庚改為太陽→天相，關係M₅。故G1中戊、庚、壬共用M₅；G0只有戊、壬。這是值得記錄的版本差異，**不能據三格共式就排除G0或宣告G1原始**。

關鍵負控：十四主星全部182個異名有序星對，各自都恰有一個T或M的全盤恆等式。原因是每顆主星的位置都是+z或−z加常數。因此「已知兩個星名後，寫出一條漂亮的幾何公式」並非化忌專有證據。

若按十干各填一個已配好的T／M常數，八個主星忌自然可被編碼，卻只是把忌表換成操作表。真正要導出，仍需**不看忌答案，就由原干決定星系方向與步數**。若找到有據的這一步，安星幾何仍可能成為不借福的生成途徑。

## 4. 有界公式檢驗

每格「吻合一干」要求在所有相關安星輸入下恆等，不是選一張有利盤，也不是若干樣本宮位碰巧相同。

| 候選族 | 候選數／版本 | G0最高吻合 | G1最高吻合 | 完整10干 |
|---|---:|---:|---:|---:|
| 同干祿位置接一個共同T／M | 24 | 2 | 3 | 0 |
| 陽干、陰干各接一個共同T／M | 576 | 3 | 4 | 0 |
| 既有16干算子任意深度閉包100映射，再查紫微祿位置、接共同T／M | 2400 | 3 | 4 | 0 |
| 同干祿權科位置aL+bQ+cK+d；a,b,c∈{-1,0,1}、d∈Z12 | 324 | 2 | 3 | 0 |

候選族間有重疊，不把數量相加宣稱獨立試驗。上述閉包僅是既有登記語法，未涵蓋所有古代操作，也未涵蓋任意條件選擇；不是「數學證明從祿不可能」。低係數三位置式只是明列試驗族，不宣稱古文已指定此式。

驗算同時展開十干×十二月×三十日×十二時，共43200個安星規則輸入。各干均覆蓋十二種紫微位置，已宣稱的逐星關係全部逐盤驗回。這是算法輸入域，並非轉換為歷史年曆的43200筆真實出生紀錄；不假定每個歷史月都有三十日。

## 5. 更強的具體反例：三個落宮相同，忌不同

己年正月初一，兩個時辰：

| 輸入／落宮 | 丑時 | 寅時 |
|---|---|---|
| 命宮 | 丑 | 子 |
| 命宮干支 | 丁丑 | 丙子 |
| 納音五行局 | 水二局 | 水二局 |
| 紫微 | 丑 | 丑 |
| 武曲祿 | 酉 | 酉 |
| 貪狼權 | 巳 | 巳 |
| 天梁科 | 申 | 申 |
| 文曲忌 | 巳 | 午 |

甲己丙寅起，丑宮丁丑、子宮丙子皆澗下水；水二局初一紫微在丑。兩盤主星一樣，文曲依辰宮起子時順數而變。

所以，即使允許任意非線性函數，**只把「原干＋祿權科三個落宮」作輸入，仍不能決定全部忌宮**：己干這兩盤輸入相同而輸出不同。此證明限於這組輸入，沒有排除加入時辰、命宮、完整安星規則，或先由年干選出固定星名再按時辰定位。

安星候選若要接通，至少必須保留曲昌入口，不能把它們當主星位移的普通終端。曲昌互為M₂是舊已知正控；它能把已選定的文曲換成文昌，尚不能自動說明己何以取曲、辛何以取昌。

## 6. 「祿隨忌走」的證據層級

本輪檢索到的[吉多多2023-11-01本人教學](https://jidoudouziwei.com/祿隨忌走是什麼？祿權科忌知多少？四化的-│-紫微/)將此語用於已知祿忌落宮之後的解盤：祿宮的資源投入忌宮的需求。它是現代實踐者對自身用法的第一手說明，不是四化表創製史證據，也沒有給出由祿星計算忌星的安星步驟。網頁其他未考據的歷史說法不採入。

因此，這句話可啟發祿忌關係研究；單憑這句話，還不能推出「忌星必由祿星固定移幾宮得到」。本輪也沒有證明所有流派都只用同一解釋，或古代絕無生成含義。

## 7. 下一步與保存

現在更具體的待找程序是：

**原干／十變角色 → 決定取主星系或時曜系 → 決定順逆、步數或取對偶端 → 安星定位／固定星名。**

這可以與古文搜索並行重建；不必等一句直接宣告「化忌取某表」。但每個分支要有原干可獨立算出的依據，不能按成熟忌答案挑八個常數，再以唯一位置冒充唯一上游公式。
