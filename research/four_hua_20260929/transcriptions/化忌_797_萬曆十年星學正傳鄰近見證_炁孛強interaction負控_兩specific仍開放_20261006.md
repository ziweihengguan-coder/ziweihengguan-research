# 化忌 §797：萬曆十年《星學正傳》鄰近見證與炁孛強interaction負控；兩條specific接線仍未出土

日期：2026-10-06（臺灣時間）

## 一、研究問題

承接 §796，本節仍不擴題，只追兩個孔：

1. 丁位：是否能找到【炁作 action source → 孛作唯一 target】的前1581／萬氏同時代古文？
2. composition：是否能找到【福 position／福 role → 印星 pool】或直接把甲乙丁戊四 relation 接成成熟化忌欄的古文？

本節不再把一般「古人會不會 source→target、role→slot、carrier↔role 分離」列為待證問題。§796 已以萬氏本系直接正控把這些 general operator grammar 壓實；本節只看 specific 接線。

---

## 二、1582《新刊京本釐正總括天機星學正傳》：距1581僅一年，平行保存兩個關鍵 primitive

### 2.1 版本層

公開書目著錄：

- 書名：《新刊京本釐正總括天機星學正傳二十一卷》
- 楊淙輯
- 版本：明萬曆十年（1582）聚奎齋刻，清康熙間印本
- 館藏：上海圖書館

公開書目：
https://m.guoxuedashi.com/shumu/gj-1586094uw.html

這個見證晚於1581《捷覽》僅一年。它不能自動前推成「1581以前已證」，但可作非常接近的 contemporaneous parallel witness。

版本界線要保留：目前公開可檢全文頁與上述館藏書目是兩個網路入口，本節尚未以物理原頁逐葉證明公開全文正好來自該1582聚奎齋刻本，因此只定級為【1582著錄版本＋同題公開全文平行文本】，不把它寫成已核1582原刻頁。

### 2.2 「權印相從」平行出現

公開全文〈十二／望斗經〉可見：

> 千倉萬箱田財化義一富二壽官福生仁有犯刑囚掌握又加  
> 權印相從决有星纛朱幡之貴斷爲一呼百諾之人

公開全文：
https://www.shidianguji.com/zh/book/NA09025/chapter/1m6t73e2nd6ab

這與 §796 萬氏《星學大成》卷十三【有用刑囚掌握，又加權印相從】高度平行。

意義只到：

> 【transformed-role pair composition 不是萬氏四庫本孤立晚出措辭】

不能升成：

> 【福印相從】

因為文本仍是【權／印】，不是【福／印】。

### 2.3 「炁孛對身」平行出現

同一公開全文後段又見：

> 炁孛對身兄弟怡如秦楚，計羅蔽日父子一似華夷。

這與 §794／§796 萬氏卷十三【炁孛對身，兄弟恰如秦楚】同型。

因此【炁—孛 pair／adversarial pairing】至少不是目前所見萬氏四庫傳本中的孤立句。

但仍只能證：

- 炁、孛直接成 pair；
- pair 帶對立／相沖突語義；
- 不能證【炁為 source、孛為 target】。

故丁位 directness 不升級。

## 三、1611《星平總會》：出現「炁孛逢冲」，是更強 interaction，但仍是對稱關係

公開《新刻欽天監正星平總會全編》所收〈琴堂五星五言獨步斷法〉有：

> 用孛爲宫星，炁孛逢冲。土計如限遇，灾禍忌難容。

公開全文：
https://www.shidianguji.com/zh/book/HY1442/chapter/1kzxvbi3nedr8

現存刊本層為萬曆三十九年（1611）《新刻星平總會命海全編》系統，因此不能用來前推1581以前；且〈琴堂五星〉雖可能承載較早材料，本節沒有獨立證據把該句精確斷代到1581以前。

就句法而言，【炁孛逢冲】比單純同宮／並列更強，直接證兩曜可進入衝突型 interaction。

但「逢冲」是 reciprocal / symmetric relation：

> 炁 ↔ 孛

不是：

> 炁 → 孛

因此它是很好的【near-hit negative control】，不是丁位決勝句。

## 四、《古今圖書集成》所收平行星命語：相犯也不能誤讀成炁→孛

公開《古今圖書集成》星命部所收〈鎮星照宮〉平行材料有：

> 孛炁忽來相犯著，男孫疾患半成空。

就語法位置看，這裡是【孛、炁共同來犯該宮／該題】，不是【孛與炁彼此相犯】；更不是【炁犯孛】。

這類結果說明 strict gate 必須同時檢查：

1. source；
2. action；
3. target；
4. target 是否就是孛；
5. 是否其實存在省略的第三 target。

所以今後不能只因【炁孛】附近出現「犯／冲／尅」就升級。

## 五、composition 窄搜：1582平行文本仍只回到「權印相從」，沒有「福印相從」

本輪用以下 specific 變體再搜公開可檢語料：

- 福印相從；
- 福印相隨；
- 福印相兼；
- 福印相生；
- 體為福、用為印；
- 體為印、用為福；
- 福位取印；
- 從福取印；
- 以福取印；
- 福變印。

回收結果仍只有：

- 福、印並列；
- 權、印相從；
- 福 role／印 role 各自使用；
- 一般 role／carrier／target composition。

仍未回收：

> 【福 position／福 role → 印星 pool】

也未回收：

> 【甲月→日、乙孛→月、丁炁→孛、戊水→火】  
> → 【成熟十干化忌欄】

的古代編表句。

因此 composition directness 仍不升級。

## 六、本節真正新增的是「近同時平行見證＋negative control」，不是 closure

§797 後可把證據層再分得更乾淨：

| 層 | 狀態 | §797變化 |
|---|---|---|
| 成熟化忌 lookup | DIRECT | 不變 |
| 下游 Ji fingerprint | DIRECT / SUPPORTIVE | 不變 |
| 四個 relation primitive | 4/4 | 不變 |
| 萬氏本系 target-directed relation | 3/4 | 不變 |
| 炁作 action source／單一target grammar | DIRECT | §796既有 |
| 炁—孛 pair／adversarial relation | DIRECT | **1582近同時平行見證補強** |
| 炁↔孛 conflict interaction | DIRECT IN LATER PRINT WITNESS | **1611「炁孛逢冲」新增** |
| 炁→孛 target-specific | **OPEN / 0 direct hit** | 不變 |
| two-role→體／用 composition | DIRECT | §796既有 |
| 權印相從平行見證 | DIRECT PARALLEL TEXT | **1582補強** |
| 福position→印pool | **OPEN / 0 direct hit** | 不變 |
| 四relation→成熟Ji row | **OPEN / 0 direct hit** | 不變 |
| specific mature-Ji adoption | **OPEN** | 不變 |

最重要的研究判斷是：

> §796已證「一般古法操作能力」；§797又證這些 primitive 在1582近同時平行文本中不是孤立現象，並以1611「炁孛逢冲」證明炁孛確可進入強衝突 interaction。可是越把 general grammar 與 pair interaction 補滿，最後缺的越只剩【source恰為炁、target恰為孛】以及【福slot恰取印pool】這兩條 specific wiring。

## 七、strict admissibility 再收緊

後續任何新命中，只有符合下列條件才可關閉丁位：

### 丁位

必須能正規化成：

> subject = 炁／氣／紫炁／紫氣  
> action = 犯／克／尅／侵／制／取／化／等價有向操作  
> object = 孛／月孛

而且 object 必須真的是語法 target，不可只是：

- 並列 partner；
- 「炁孛逢冲」這類 reciprocal relation；
- 「孛炁來犯某宮」中的共同 subject；
- 同宮／對身／相會；
- 一次作用於計孛火土等多target集合。

### composition

必須能正規化成任一：

> 福 role／福 position → 取／從／變／掛 → 印 carrier pool

或：

> 甲乙丁戊四條 relation → 明確生成成熟十干化忌欄

單純【福印並列】、【權印相從】、【印星十干pool】、【role→domain】都不再計為決勝證據。

## 八、§797後停止條件

本節沒有找到能關孔的新 direct connector。

所以狀態仍是：

> **丁【炁→孛】target-specific = NOT FOUND IN REVIEWED SEARCHABLE SOURCES**

> **【福position→印pool／四relation→成熟Ji row】specific composition = NOT FOUND IN REVIEWED SEARCHABLE SOURCES**

這兩句只表示「目前已核本機與公開可檢材料未見」，不表示歷史上邏輯不可能存在。

下一步仍不擴題，只允許：

1. 新的前1581／萬氏同時代 target-specific【炁→孛】原句；
2. 新的【福→印】或四relation→成熟忌欄 specific composition 原句。

在沒有這兩類新材料前，不用再為一般炁孛共現、一般福印並列、一般role composition另開研究支線。

## 九、補做指定書名＋指定句法窄搜

為避免一般搜尋引擎只回收同義共現，本輪再把書名與句法綁死，逐組查：

- 《果老星宗》：炁犯孛／炁克孛；
- 《三辰通載》：炁制孛；
- 《星命溯源》：炁侵孛；
- 《新刊京本釐正總括天機星學正傳》：炁＋孛＋犯／克；
- 〈琴堂五星〉／《星平總會》：炁＋孛＋克；
- 星學古籍：福印相從／福位＋印星。

結果沒有新增合格 direct connector。

《星學正傳》卷十三公開文本仍只回到【木炁】、【水孛】等群組喜忌與一般犯克；《星學大成》卷二十一雖在同一曜章內可同見某干【為印星】、某干【為福星】，並另有【命宮福位】等語，但語法上是各自獨立的十干角色與宮位判斷，並沒有【福位→印星】資料流。

所以這輪 source-bounded 搜尋的結論仍是：

> **specific 丁 edge = 0 新命中；specific 福→印 composition = 0 新命中。**

不另開 §798，因為沒有足以改變證據矩陣的新材料；搜尋結果併入 §797。
