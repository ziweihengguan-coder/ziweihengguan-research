# 十四主星安星公式重審與816閉環交叉檢查（2026-10-04）

## 一、回收早期「延續古典紫微研究」公式

以子=0、丑=1、寅=2……亥=11。

紫微位置為 z，天府位置為：

```
f ≡ 4 - z (mod 12)
```

故紫府同宮固定點須滿足 z=f：

```
2z ≡ 4 (mod12)
```

解為：
- z=2（寅）
- z=8（申）

這次審計特別校正：不能把 z=0 當作紫府同宮基準盤；正確做法是取寅2或申8，再整體平移為相對0。

### 紫微系
依紫微逆行步數：

```
P = {0,1,3,4,5,8}
```

星序：
紫0、機1、陽3、武4、同5、廉8。

### 天府系
依天府順行步數：

```
F = {0,1,2,3,4,5,6,10}
```

星序：
府0、陰1、貪2、巨3、相4、梁5、殺6、破10。

古訣所見「隔一、隔二、空三」正是這兩組偏移的文字算法形式。

## 三、新的結構性進展：紫府同宮基準盤完整分成四條三合軌道

取寅宮紫府同宮 z=f=2，再整盤減2化為相對座標0。

十二宮按 mod4 分組：

### C0 = {0,4,8}
- 0：紫微＋天府
- 4：廉貞＋天相
- 8：武曲

### C1 = {1,5,9}
- 1：太陰
- 5：天梁
- 9：太陽

### C2 = {2,6,10}
- 2：貪狼
- 6：七殺
- 10：破軍

### C3 = {3,7,11}
- 3：巨門
- 7：天同
- 11：天機

因此紫府同宮基準盤不是只有「兩組三合」值得看，而是整個12宮主環本身恰好分成四個三合餘類：

```
Z12 / <4>
```

其中：
- C0承載兩個雙星節點；
- C1、C2、C3各為一宮一星的完整三星三合；
- 只有「紫武廉」與「殺破狼」在 z 改變後仍保持全域固定；C1、C3只在紫府同宮基準盤呈完整固定三合。

這一點過去雖已有「紫府同宮十二宮主環」與「唯一兩組全域固定三合」，但未明確把基準盤寫成四個 mod4 三合餘類。

## 四、安星公式可再壓縮為同一特殊槽 x=2 的二分／三分算子

令：

```
H={0,1,2,3,4,5}
x=2
K=H\{2}={0,1,3,4,5}
```

則：

### 紫微系
對特殊槽x取對宮：

```
P = K ∪ {x+6}
  = {0,1,3,4,5,8}
```

### 天府系
對特殊槽x取完整三合軌道：

```
F = K ∪ {x,x+4,x+8}
  = {0,1,2,3,4,5,6,10}
```

因此兩系共用同一普通骨架K，只在x=2發生分岔：

- 紫側：二分對宮算子 +6
- 府側：三分三合算子 +4，形成3階閉環

```
2 → 6 → 10 → 2
```

這是目前最緊湊的共同生成式之一。

重要限制：
這仍是對成熟安星模板的數學壓縮；古文已明示隔位與三方殺破狼，但尚未找到古人以「H、x、二分／三分」這種抽象方式自述創制原理。

## 五、對816研究的直接影響

此前816最後缺口被描述為：

「是否存在把完整九宮巡行投影到{8,1,6}，略過其他宮位、保序並閉環的古法？」

本輪安星重審後，這個缺口要更精確地改寫。

成熟紫微自身已存在：

1. 十二宮大環；
2. 從大環中抽出固定三點；
3. 三點形成閉合子軌道；
4. 古文甚至直接把其中一組叫「三方殺破狼」；
5. 安星口訣又明用「隔一／隔二／空三」跳過非取用宮位。

所以「大環內存在局部三點閉環／跳位子結構」在紫微本身已有直接結構先例。

這表示816的 projection 不應再被描述成「完全沒有斗數內部先例」。

但兩者不能混同：
- 紫微主星三合是 Z12 中固定步長 +4 的子軌道；
- 816是洛書九宮中8、1、6一線，現階段方向由8→1→6古文支持，6→8局部封口仍需直接依據。

因此新的搜尋目標應分成兩路：

A. 找「投影／隔位保序」古文；
B. 找「由某個古典算子直接生成816三點軌道」的可能性。

若能找到B，就不必強迫把816解釋成「先走完整九宮再投影」；它可能像殺破狼一樣，本來就是由較高層算子產生的局部3階軌道。


只是作三循環重掛。

在紫府同宮基準盤的四條三合類中，它們恰分屬：
- 紫微 C0

這是新觀察，但目前只列【結構提示】：
尚無古文證明化權刻意選「四條三合類中的三類代表」來做816輪轉，不可升格為生成公式。

## 七、目前公式審核結論

已確認：
- f=4-z mod12 正確；
- 紫府同宮固定點只有寅、申；
- P與F偏移公式正確；
- 364組檢驗仍只有紫武廉、殺破狼兩組全域固定三合；
- 「特殊槽x=2 → 紫側對宮／府側三合軌道」完全重建成熟模板；
- 紫府同宮基準盤可整體分解為四個mod4三合餘類；
- 紫微安星法自身提供「局部三點閉環＋跳位」先例，故816研究應同時搜索「投影型」與「軌道生成型」古法。

尚未證明：
- 古人先以x=2創制兩星系；
- 紫武廉／殺破狼一定是設計原因而非結果；
- 816由主星三合公式直接導出；
- 紫微／巨門／天梁的三類分布是化權選星原理。
