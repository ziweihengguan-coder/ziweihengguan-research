# §810-A｜化忌上游候選：不看目標的原始十干封存（2026-10-09）
**封存性質：pre-target lock；此稿僅登記古書規則、公式、甲至癸的原始星曜，未取用任何紫微化忌各版本答案。**
**核查限制：古籍線上轉錄及《星學大成》本地古文轉錄可用；尚未逐頁比對明刊原刻。十神→十曜的接線屬公開且先封存的額外映射，不是「七殺本身就是某顆星」。**

## 一、封存以前已宣告的運算輸入
- 干序：甲乙丙丁戊己庚辛壬癸；干五行：木木火火土土金金水水；陰陽：甲丙戊庚壬陽、乙丁己辛癸陰。
- 古十干祿元星對照：甲火、乙孛、丙木、丁金、戊土、己月、庚水、辛炁、壬計、癸羅（不含日）。
- 《星學大成》「祿暗福耗蔭貴刑印囚權」逐干順數；暗=從祿順移1、耗=3、刑=6、囚=8（模10；以甲為0）。
- 《星學大成》卷一獨立「論印星」：甲木乙日丙火丁月戊土己羅庚金辛計壬水癸孛（含日、不含炁）。古書的「印星」≠十變曜的「化印」；不得偷換。
- 標準十神：七殺（克我且同陰陽）；傷官（我生且異陰陽）；偏印／梟印（生我且同陰陽）；劫財（同五行且異陰陽）。先求「對應他干」，再依上述古十干祿元星對照回填原始星曜。採年干為「我」乃本輪實驗接線假設；子平論命常以日干為我，必須列為 domain adaptation。
- 名稱對照僅限同名展開：日＝太陽、月＝太陰、火＝火星、木＝木星、水＝水星、金＝金星、土＝土星、炁＝紫炁、孛＝月孛、計＝計都、羅＝羅睺。**不得**在揭答後自由重掛為紫微十四主星；若欲跨星命體系映射，須另有揭答前指定且具文本出處的 correspondence table。

### 完全不靠紫微目標的内部交叉檢查
- 七殺→祿元星 **恒等** 十變曜「刑」（10/10），這不是兩個相互獨立的證明。
- 偏印→祿元星 **恒等** 十變曜「囚」（10/10），同理。
- 傷官→祿元星：陽干（甲丙戊庚壬）＝「耗」5/5；陰干（乙丁己辛癸）＝「暗」5/5。

「祿暗福耗䕃貴刑印囚權　火孛木金土月水炁計羅」；演算例以乙年取福，孛起至金；卷首按六親區分：「化刑者皆其七煞，化囚者皆其梟印；化暗者五陽干皆是陽刃、五陰干皆是傷官；化耗者五陽干皆是傷官、五陰干皆是正財」。因此十神與四凶欄在**本書**有規則性關係，而不是本研究事後想像。

## 四、先封存評分規則，後揭答不得更動
四個維度完全分開，不加權合成虛假的歷史確證：
1. **十干載體吻合**：先報逐干嚴格同名（可作已封存「日／月」等同名展開；不准映射木到天機之類跨星系重掛）；候選比對每個具體早期化忌版本，報 x/10；若古表系與紫微主星系不通約則另記「NA／不同 namespace」，不把0/10寫成其算法證偽。
2. **額外轉換**：十變曜四欄原始取欄 0（但「哪一欄」的 selector **缺**）；獨立印星查表 0（但「為何取印星」的 selector **缺**）；十神先配干再轉古祿元星 1 個預先聲明跨表橋（但「為何是該十神」selector **缺**）。若再將任一原始曜換掛紫微主星，額外算 1 或更多，必須指出實際換掛表、其年代、獨立證據。
3. **最早文獻年代**：各記「古書主張之原始年代（待證）／文本自序年代／此輪核驗的實存版本或電子底本」三欄。不能把宋代十神背景當作明代星名映射表的年代。
4. **直接輸入指定口訣**：只有清楚「化忌以 X 起／化忌取 X 星」或無歧義等價古文可評為「直接」。單獨「四凶」＝極性，不是 operator selector；「印乃印星也」是**印**的 type declaration，不是「化忌應取印星」的 caller statement。候選無則一律「未見」。

## 五、揭答前預註冊的失敗準則
- 任一候選即使後續10/10，也不得自行升格為歷史來源；必須同時交代其他候選、隱含轉換、來源年代與 input declaration。
- 刑 vs 七殺，囚 vs 偏印之間的10/10恒等不等於額外一個獨立實驗。
- 如早期不同版本出現矛盾，按版本分別計分，不准先挑有利版本；不存在可事後特定干修改的自由補丁。
- 不得把「禄暗福耗䕃貴刑印囚權」這個化曜功能序列自動與紫微「化祿權科忌」的相同字直接等同。**尤其本輪查證目的只是候選來源，不是預設同一學派。**
- 當前暫定結論：星命古書有可複核的凶性算子候選；**不存在已核實能唯一決定紫微化忌 caller 的古文**。後續以封存文件雜湊驗證先後次序。
