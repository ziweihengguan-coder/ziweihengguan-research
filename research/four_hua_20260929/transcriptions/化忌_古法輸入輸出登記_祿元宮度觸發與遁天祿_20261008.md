# 古法輸入輸出登記：祿元宮度的實際觸發與遁天祿

日期：2026-10-08。承接使用者「繼續，記住都要寫入進度檔案」；沿古星命直導成熟忌主線，不以早期福為輸入。

## 1. 本輪新增與既有結果的界線

前一輪24來源×200干映射的4,800候選，是既登記操作族的直接測試，沒有覆蓋所有古天干算法。本輪追到《三命通會》〈總論祿馬〉實際使用的**年干＋祿支→遁得干支**。其天干映射有7個不同輸出，確實不在前輪100映射閉包，因此不能把前輪負結果擴張成「古干操作全已排除」。

另一條補測使用《星學大成》〈定祿元宮度〉，保留原文每干指定的曜體、宮支與宿度，再按那個實際宮宿觸發名稱。這與上輪把14條名稱橋不分觸發地全部放開的相容檢查不同。

兩條均未導出完整化忌。新增的是可執行的古法入口、輸入資訊限制與可重跑的直接負控，不是新的化忌唯一解。

引擎先通過古文算例：甲官辛→辛祿炁；甲食丙→丙祿巳、乙食丁→丁祿午；甲年寅遁丙、下一月卯遁丁、申遁壬；天馬地驛四組的反查與曜集合也逐組核對。前四項只作已知正控，不記成新史證。

注意：有些欄位同寫「天祿」，輸出卻不同。《三命通會》這裡的「丙為天祿」先得到**干丙**；《星學大成》祿母環得到**曜木**。干丙再接七政表可以作組合假設，但不是名稱相同就已證古人如此採用。

號名從各曜章按**同一曜體＋同一宿**抽取，沒有拿其他宿的名字補上；璧／壁作文字正規化，原行保留。這裡的度數帶入來源，但號名本身按整宿稱呼，本輪不虛構度內細分規則。

曜體列為 **木火水日水日水金水土**，與庚同忌、庚相忌兩版的舊曜體目標都只有 **2/10**（辛、癸）。來源本來含太陽，不必經福欄補日；但含日並不等於已算出甲日。

再依祿支查同曜的實際變段主名／又名：10干都有宮段文字，9干有上述正式宿號。在現有已核星名字典內，宿號只接出**乙天梁**，宮段只接出**庚紫微**；兩者都不符合該干化忌，兩版已核橋的命中均 **0**。其餘號名目前未接入既有紫微字典，不能把「未接出」誇張為已證歷史上毫無關聯。

卷十七130行另有「水入雙女巳上名為文昌玉堂星」。它在現有14條正式號名／變段邊的抽取格式之外，是需要另記的名稱成分線索；本輪沒有擅拆複合名稱當成已證固定紫微文昌。即使暫作候選，它對丙、戊同為水居巳都成立，仍無法單靠此宮級判法區分丙廉與戊機。

## 4. 遁天祿：新操作確有原句，但必須保留干支

《三命通會》卷二〈論遁月時〉先明示甲年正月丙寅、二月丁卯及五組寅月起干。卷三〈總論祿馬〉則直接給：

> 甲祿在寅，甲干寅上遁見丙，申上遁見壬，則以丙為天祿，壬為天馬。

所以把原干自己的祿支交給遁法，在這個「天祿」語境已有算例；不必另假設任意拿某宮代入。通用公式可以寫為（甲、子均零起算）：

`Tiger(g,b) = [2(g mod 5)+2+((b−2) mod 12)] mod 10`

令 `b = 普通祿支(g)`，算出的完整干支為：

| 原干 | 遁得干支 |
|---|---|
| 甲 | 丙寅 |
| 乙 | 己卯 |
| 丙 | 癸巳 |
| 丁 | 丙午 |
| 戊 | 丁巳 |
| 己 | 庚午 |
| 庚 | 甲申 |
| 辛 | 丁酉 |
| 壬 | 辛亥 |
| 癸 | 甲子 |

只保留遁得干時，列為 **丙己癸丙丁庚甲丁辛甲**，僅7個不同值：

- 甲、丁同得丙；
- 戊、辛同得丁；
- 庚、癸同得甲。

因此任何後續只吃這一個查得干的單值查表串，輸出最多7種曜體；同忌目標有10種，相忌依現字典也有9種。這是資訊合併的下界，與再接哪張古表無關。不能把被丟掉的原干資訊偷偷放回例外選星。

實測這個新干操作後接原登記100干操作與24古表，共 **2,400候選**：同忌版最高 **4/10**，相忌版最高 **5/10**，完整吻合均0。這是新操作接既有表的假設驗證，不是古代已證採用的2,400個公式。

但若保留原法的**完整干支**，上述10組全部不同，並未合併。故本輪不能否定「遁天祿干支→二輸入星命規則」；反而精確指出：這條路若有解，就不能只拿遁得干再作一元查表。

## 5. 天馬地驛與祿支單獨索引的兩個負控

卷二328–336行的「驛馬支→反查祿干」確有原句；尤其馬在巳，原文明取**丙、戊**，輸出木、土兩曜。本輪保持集合值，沒有按成熟忌指定其一。

放入六十甲子，同一個年干的六種合法年支都不能得到相同的天馬曜集合。因此**此法原樣仍依年支**，不能直接把出生年支路徑冒充十干固定忌表；若要轉成只依干，必須找到合法消去年支的古法。

反過來，單用普通祿支（甚至加原干陰陽）也不夠：

- 丙、戊同為陽、同祿巳，忌卻分廉貞、天機；
- 丁、己同為陰、同祿午，忌卻分巨門、文曲。

兩個庚版本都保留這兩組差異。故任何只吃「祿支＋陰陽」的單值星名分派都無法全中。〈祿元宮度〉本身保留軫／翼、張／星的差別，顯示古法確能帶入更細狀態；本輪只證資料結構可保留差別，尚未證它就是化忌所用selector。
