# 紫微斗數安星與四化研究

本專案整理紫微斗數安星公式、四化古籍材料，以及成熟化權、化科表與化忌的生成重建，以古文、數學公式與逐步解說呈現研究結果。

研究中區分古籍明文、數理重建與待證假說，保留推導過程及後續修正。
